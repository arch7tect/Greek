# Аудиоприложение к шестому улучшенному изданию

Источник: <https://drive.google.com/drive/folders/18SejqvsGM6xKXpsGCzbn3E5bWq5nt41Z>

В исходной папке файлы назывались по шаблону
`NN - Unknown - Track N.mp3`. Локальные имена приведены к единому шаблону
`track-NN.mp3`; содержимое файлов не изменялось.

- 57 дорожек;
- общий объём — 74 244 222 байта (70,8 МиБ);
- общая длительность — 1:17:09;
- формат всех файлов — MP3, 128 кбит/с, 44,1 кГц, стерео.

## Учебная обработка

- `track-01.mp3` — урок 01, упражнение 8;
- `track-02.mp3` — урок 01, упражнение 9;
- `track-03.mp3` — урок 01, упражнение 10;
- `track-04.mp3`–`track-57.mp3` скачаны и технически проверены, но пока не
  сопоставлены с конкретными упражнениями. Их следует привязывать к урокам по
  мере фактического прохождения или назначения материала.
