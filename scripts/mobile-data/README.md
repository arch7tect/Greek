# Источники мобильных карточек

`lesson-01.json` и `lesson-02.json` — текст утверждённых А4-памяток
`docs/assets/print/lesson-01-alphabet-card-a4.pdf` и
`docs/assets/print/lesson-02-phonetics-card-a4.pdf`, сохранённый из их генераторов.
Алфавит включает названия и звуки всех 24 букв; словарь урока 01 — 26 основных слов.
Исходные формулировки, примеры и множественное число сохранены.
Мобильная версия опускает повторяющиеся инструкции по повторению.

Сборка: `python scripts/build_themed_mobile_cards.py`, затем
`python scripts/build_mobile_pdfs.py` с Pillow, ReportLab, pypdf и шрифтами DejaVu Sans
из настроенного локального runtime (пути указаны в скрипте).
Результат — `docs/assets/mobile/`, PNG 1080 × 1920, текст 40 px.
`--extract-a4` нужен только для обновления данных из локальных А4-генераторов в `tmp/pdfs/`.

`lesson-03.json` — содержимое компактного прототипа из А4, до группировки.
Тематический генератор задаёт явные границы карточек и сохраняет размер текста.
Первая карточка урока 03 сохраняется как утверждённая таблица местоимений.
А4-источник:
`docs/assets/print/lesson-03-study-card-a4.pdf`.

## Урок 04

`lesson-04.json` — общий проверенный текст для двух форматов: 8 тем,
переводы, транскрипция, пояснения и ссылки на диапазоны источников.
Источники перечислены на `docs/lessons/lesson-04-current.md`.
Сборка отдельно: `python scripts/build_lesson04_cards.py` (тот же runtime).
Получаются 2 страницы А4 и 8 страниц PDF для телефона, PNG и галерея.
Генератор не меняет уроки 01–03; изменение текста переносится сразу в оба
формата. Проверки запрещают переполнение. После сборки визуально проверить PDF.
