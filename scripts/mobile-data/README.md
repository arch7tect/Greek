# Источники мобильных карточек

`lesson-01.json` и `lesson-02.json` — текст утверждённых А4-памяток
`docs/assets/print/lesson-01-alphabet-card-a4.pdf` и
`docs/assets/print/lesson-02-phonetics-card-a4.pdf`, сохранённый из их генераторов.
Алфавит включает названия и звуки всех 24 букв; словарь урока 01 — 26 основных слов.
Исходные формулировки, примеры и множественное число сохранены.
Мобильная версия опускает повторяющиеся инструкции по повторению.

Сборка: `python scripts/build_mobile_cards.py` с Pillow и шрифтами DejaVu Sans
из настроенного локального runtime (пути указаны в скрипте).
Результат — `docs/assets/mobile/`, PNG 1080 × 1920, текст 40 px.
`--extract-a4` нужен только для обновления данных из локальных А4-генераторов в `tmp/pdfs/`.

Комплект урока 03 — утверждённые пользователем 10 PNG из компактного прототипа;
публикуются без изменения оформления. А4-источник:
`docs/assets/print/lesson-03-study-card-a4.pdf`.
