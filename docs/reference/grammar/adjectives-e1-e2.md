# Прилагательные: род и модели Ε1 / Ε2

Прилагательное описывает признак и **согласуется с существительным**.
В этом разделе — именительный падеж единственного числа и две модели
прилагательных на **-ος** [-os]. Это не все типы греческих прилагательных.

## Как выбрать форму { #agreement }

1. Найди существительное, которое описываешь.
2. Вспомни его артикль: **ο / η / το** [o / i / to] — мужской / женский / средний род.
3. Выбери соответствующую форму прилагательного. Пол говорящего не важен.

| Род | Перед существительным | После «быть» |
|---|---|---|
| мужской | ο μεγάλος κήπος [o meˈɣalos ˈkipos] — большой сад | Ο κήπος είναι μεγάλος. [o ˈkipos ˈine meˈɣalos] — Сад большой. |
| женский | η μεγάλη τσάντα [i meˈɣali ˈtsanda] — большая сумка | Η τσάντα είναι μεγάλη. [i ˈtsanda ˈine meˈɣali] — Сумка большая. |
| средний | το μεγάλο σπίτι [to meˈɣalo ˈspiti] — большой дом | Το σπίτι είναι μεγάλο. [to ˈspiti ˈine meˈɣalo] — Дом большой. |

Окончания существительного и прилагательного **не обязаны совпадать**:
**το μεγάλο παιδί** [to meˈɣalo peˈði] — большой ребёнок.
Слово «ребёнок» среднего рода независимо от пола ребёнка.
**ένα όμορφο κορίτσι** [ˈena ˈomorfo koˈritsi] — красивая девочка:
по-русски женский род, в греческом — средний.

Артикль перед целой группой согласуется с существительным:
**ένας καλός φίλος / μια καλή φίλη / ένα καλό βιβλίο**
[ˈenas kaˈlos ˈfilos / mya kaˈli ˈfili / ˈena kaˈlo viˈvlio] —
хороший друг / хорошая подруга / хорошая книга.
После «быть» перед одним признаком артикль не нужен:
**Είναι καλή.** [ˈine kaˈli] — Она хорошая.
Полное правило [артиклей](nominative-articles.md).

## Две модели: как получить женскую форму { #models }

У мужской формы убери **-ος** [-os] и посмотри на конец оставшейся основы,
а не на последнюю букву всего слова. Само мужское окончание у обеих моделей одинаково.

| Модель | Основа | Мужской | Женский | Средний |
|---|---|---|---|---|
| Ε1 | заканчивается согласным | καλ**ός** [kaˈlos] | καλ**ή** [kaˈli] | καλ**ό** [kaˈlo] |
| Ε2 | заканчивается гласным | ωραί**ος** [oˈreos] | ωραί**α** [oˈrea] | ωραί**ο** [oˈreo] |

В первом случае основа **καλ-** [kal-], во втором **ωραί-** [oˈre-].
Сохраняй ударение на том же слоге; если ударно окончание — перенеси знак на
новое окончание. Например, **ακριβός → ακριβή → ακριβό**
[akriˈvos → akriˈvi → akriˈvo], но **όμορφος → όμορφη → όμορφο**
[ˈomorfos → ˈomorfi → ˈomorfo].

Не определяй модель по русскому переводу или по роду существительного:
модель принадлежит прилагательному, а род выбирает нужную форму внутри модели.

## Исключения и особые женские формы { #exceptions }

| Мужской | Женский | Средний | Что запомнить |
|---|---|---|---|
| μοντέρνος [moˈndernos] | μοντέρνα [moˈnderna] | μοντέρνο [moˈnderno] | современный: после согласного женское окончание -α [-a] |
| σκούρος [ˈskuros] | σκούρα [ˈskura] | σκούρο [ˈskuro] | тёмный по цвету: тоже -α [-a] |
| γκρίζος [ˈgrizos] | γκρίζα [ˈgriza] | γκρίζο [ˈgrizo] | серый: тоже -α [-a] |
| φρέσκος [ˈfreskos] | φρέσκια [ˈfreskya] | φρέσκο [ˈfresko] | свежий: запомнить женскую форму целиком |
| γλυκός [ɣliˈkos] | γλυκιά [ɣliˈkya] | γλυκό [ɣliˈko] | сладкий: женское -ιά [-ˈya] |

В листе преподавателя для «свежий» отмечен также вариант женского окончания
**-η** [-i]; в разобранной таблице используем **φρέσκια** [ˈfreskya].
Это не повод менять все прилагательные после согласного на такую модель.

## Прилагательное или наречие? { #adverb }

**Είναι καλός.** [ˈine kaˈlos] — Он хороший: признак человека.
**Μιλάει καλά.** [miˈlai kaˈla] — Он / она говорит хорошо: характеристика действия.
Не заменяй «хорошо» мужским прилагательным.

**Η μέρα είναι ωραία.** [i ˈmera ˈine oˈrea] — День прекрасный:
женская форма согласуется со словом «день».
**Ωραία!** [oˈrea] — Отлично!: самостоятельная оценочная реплика.
Одинаковое написание не означает одинаковую роль в предложении.

## Типичные ошибки

- Выбирать женскую форму потому, что говоришь о себе и ты женщина. Смотри на описываемое слово.
- Согласовывать с русским родом: греческая книга среднего рода.
- Запоминать только мужскую форму и автоматически ставить женское окончание первой модели.
- Менять форму «быть» по роду: **είναι** [ˈine] одинаково для всех трёх родов.
- Забывать ударение или превращать прилагательное в наречие.
