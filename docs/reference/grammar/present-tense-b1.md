# Настоящее время: глаголы типа Β1

**Статус:** проверено по материалам урока 08, основному учебнику и рабочей
тетради

**Связанный урок:** [урок 08 — глаголы типа Β1 и анкета](../../lessons/lesson-08-verbs-b1-and-application.md)

Практика: [тренажёр глаголов типа Β1](../../training/present-tense-b1.md).

К типу Β1 относятся глаголы с ударным окончанием `-άω / -ώ`
`[-ˈao / -ˈo]`: `μιλάω / μιλώ` `[miˈlao / miˈlo]`,
`ρωτάω / ρωτώ` `[roˈtao / roˈto]`. В материалах урока используются в
основном полные разговорные формы на `-άω` `[-ˈao]`.

## Формы на примере `μιλάω` `[miˈlao]`

| Лицо | Форма | Транскрипция |
|---|---|---|
| `εγώ` `[eˈɣo]` | `μιλάω / μιλώ` | `[miˈlao / miˈlo]` |
| `εσύ` `[eˈsi]` | `μιλάς` | `[miˈlas]` |
| `αυτός / αυτή / αυτό` `[afˈtos / afˈti / afˈto]` | `μιλάει / μιλά` | `[miˈlai / miˈla]` |
| `εμείς` `[eˈmis]` | `μιλάμε` | `[miˈlame]` |
| `εσείς` `[eˈsis]` | `μιλάτε` | `[miˈlate]` |
| `αυτοί / αυτές / αυτά` `[afˈti / afˈtes / afˈta]` | `μιλάνε / μιλούν` | `[miˈlane / miˈlun]` |

Краткие и полные варианты в одной строке означают одно лицо, а не разные
значения. Например, `Μιλάει ελληνικά.` `[miˈlai eliniˈka]` и
`Μιλά ελληνικά.` `[miˈla eliniˈka]` — «он / она говорит по-гречески».

## Как отличить от типа Α

У глаголов типа Α словарное `-ω` `[o]` безударное:
`δουλεύω` `[ðuˈlevo]` → `δουλεύεις` `[ðuˈlevis]`.
У типа Β1 ударение падает на окончание:
`μιλάω` `[miˈlao]` → `μιλάς` `[miˈlas]`.

Нельзя выбирать спряжение только по русскому переводу. Словарную форму нужно
запоминать целиком: `βοηθάω` `[voiˈθao]`, но `μαθαίνω`
`[maˈθeno]`. Частая ошибка — смешивать окончания двух моделей и писать
неподтверждённую форму вроде `*μιλάεις`. Правильно:
`μιλάς` `[miˈlas]` для «ты» и `μιλάει` `[miˈlai]` для «он / она».

## Выбор лица

Сначала определяем подлежащее, затем ставим окончание:

- `Εγώ και ο Νίκος διψάμε.` `[eˈɣo ke o ˈnikos ðiˈpsame]` — двое,
  поэтому первое лицо множественного числа;
- `Η καθηγήτρια βοηθάει τον φοιτητή.`
  `[i kaθiˈyitria voiˈθai ton fitiˈti]` — один человек, третье лицо;
- `Εσείς τραγουδάτε.` `[eˈsis traɣuˈðate]` — несколько людей или
  вежливое «вы».
