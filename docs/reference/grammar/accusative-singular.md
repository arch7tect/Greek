# Винительный падеж — кого? что?

[Урок 19](../../lessons/lesson-19-current.md) · [Предлоги](prepositions-accusative.md) ·
[Артикли](nominative-articles.md).

## Зачем меняется форма { #choice }

Сначала определи роль слова. Кто выполняет действие — именительный. На кого или на что
направлено действие — винительный. После изученных предлогов также нужен винительный,
даже если по-русски получается другой падеж.

**Ο οδηγός βλέπει τον επιβάτη.** `[o oðiˈɣos ˈvlepi ton epiˈvati]`
— Водитель видит пассажира. Водитель — кто видит, пассажир — кого видит.
**Ο επιβάτης βλέπει τον οδηγό.** `[o epiˈvatis ˈvlepi ton oðiˈɣo]`
— Пассажир видит водителя. При смене ролей меняются формы, а не значение слов.

**Με τον πατέρα μου.** `[me ton paˈtera mu]` — С моим отцом.
В русском здесь творительный, в греческом винительный после предлога.
Не выбирай греческий падеж по окончанию русского перевода.

## Единственное число { #forms }

| Род | Именительный | Винительный | Что меняется |
|---|---|---|---|
| Мужской | ο `[o]` | τον `[ton]` | У изученных существительных на -ος / -ης / -ας `[os / is / as]` убираем конечную -ς `[s]`. |
| Женский | η `[i]` | τη / την `[ti / tin]` | Существительное сохраняет форму. |
| Средний | το `[to]` | το `[to]` | Артикль и существительное сохраняют форму. |

| Греческий | Произношение | Перевод |
|---|---|---|
| ο υπολογιστής → τον υπολογιστή | `[o ipoloɣiˈstis → ton ipoloɣiˈsti]` | компьютер → компьютер (что?) |
| ο αναπτήρας → τον αναπτήρα | `[o anapˈtiras → ton anapˈtira]` | зажигалка → зажигалку |
| ο χυμός → τον χυμό | `[o hiˈmos → ton hiˈmo]` | сок → сок (что?) |
| η μηχανή → τη μηχανή | `[i mihaˈni → ti mihaˈni]` | мотоцикл → мотоцикл (что?) |
| η καρέκλα → την καρέκλα | `[i kaˈrekla → tin kaˈrekla]` | стул → стул (что?) |
| το βιβλίο / το παιδί / το μάθημα | `[to viˈvlio / to peˈði / to ˈmaθima]` | книга / ребёнок / урок. В среднем роде форма сохраняется. |

Это правило для представленных типов единственного числа. Не переноси его автоматически
на все мужские слова и множественное число.

## Существительное вместе с прилагательным { #adjectives }

Прилагательное принимает род, число и падеж существительного.
В мужском единственного у изученных прилагательных тоже исчезает конечная -ς `[s]`.
Женские формы на -η / -α `[i / a]` и средние на -ο `[o]` внешне остаются прежними.

| Греческий | Произношение | Перевод |
|---|---|---|
| ο ακριβός υπολογιστής → τον ακριβό υπολογιστή | `[o akriˈvos ipoloɣiˈstis → ton akriˈvo ipoloɣiˈsti]` | дорогой компьютер → дорогой компьютер (что?) |
| η ακριβή τσάντα → την ακριβή τσάντα | `[i akriˈvi ˈtsanda → tin akriˈvi ˈtsanda]` | дорогая сумка → дорогую сумку |
| ο παλιός φίλος → τον παλιό φίλο | `[o paˈlyos ˈfilos → ton paˈlyo ˈfilo]` | старый друг → старого друга |
| η παλιά τσάντα → την παλιά τσάντα | `[i paˈlya ˈtsanda → tin paˈlya ˈtsanda]` | старая сумка → старую сумку |
| το ακριβό / το παλιό βιβλίο | `[to akriˈvo / to paˈlyo viˈvlio]` | дорогая / старая книга. Средний род сохраняет форму. |

**Θέλω τον ακριβό υπολογιστή.** `[ˈθelo ton akriˈvo ipoloɣiˈsti]`
— Хочу дорогой компьютер. Нельзя изменить только артикль, оставив мужские слова в именительном.
**Δεν θέλω τον ακριβό ανεμιστήρα.** `[ðen ˈθelo ton akriˈvo anemiˈstira]`
— Не хочу дорогой вентилятор. Отрицание не меняет выбор падежа.

## Где нужен винительный { #uses }

1. Прямое дополнение после глагола. **Περιμένω το λεωφορείο.**
   `[periˈmeno to leoforˈio]` — Жду автобус.
   **Ρωτάω τον οδηγό.** `[roˈtao ton oðiˈɣo]` — Спрашиваю водителя.
   **Βοηθάω τον φίλο μου.** `[voiˈθao ton ˈfilo mu]` — Помогаю другу.
   Последний перевод по-русски дательный, но греческий глагол требует прямого дополнения.
2. После предлогов **σε / από / με / για** `[se / aˈpo / me / ya]`.
   **Μένω με τον αδερφό μου.** `[ˈmeno me ton aðerˈfo mu]` — Живу с братом.
   **Πάω στον σταθμό.** `[ˈpao ston staθˈmo]` — Иду на станцию.
3. Имя в конструкции «меня / тебя / его зовут».
   **Ο Πέτρος είναι φίλος μου.** `[o ˈpetros ˈine ˈfilos mu]`
   — Петрос — мой друг.
   **Τον λένε Πέτρο.** `[ton ˈlene ˈpetro]` — Его зовут Петрос.
   **Είμαι ο Πέτρος.** `[ˈime o ˈpetros]` — Я Петрос.
   После «я есть» имя в именительном, после «его зовут» — в винительном.
   **Με λένε Θεόδωρο Ιωαννίδη.** `[me ˈlene θeˈoðoro ioaˈniði]`
   — Меня зовут Теодорос Иоаннидис. Меняется и изученная мужская фамилия.
   **Τη λένε Μαρία.** `[ti ˈlene maˈria]` — Её зовут Мария.
   У женского имени форма внешне не изменилась, но падеж тот же.

После **είμαι** `[ˈime]` — «я есть» слово, называющее человека, обычно стоит в именительном:
**Είναι ο οδηγός.** `[ˈine o oðiˈɣos]` — Это водитель.
Не превращай любое слово после любого глагола в винительный.
Другие глаголы проверяются отдельно, а не выводятся из русских вопросов.

## Конечное n { #final-n }

Мужской артикль **τον** `[ton]` сохраняет **ν** `[n]`.
У женского **την** `[tin]` конечное **ν** `[n]` сохраняется перед гласной,
а также перед **κ, π, τ, ξ, ψ, μπ, ντ, γκ, τσ, τζ**
`[k, p, t, ks, ps, b, d, g, ts, dz]`.
В остальных случаях пишем **τη** `[ti]`.

**τη μητέρα** `[ti miˈtera]` — маму, но
**την τσάντα** `[tin ˈtsanda]` — сумку.
В сочетании с местом действует та же проверка:
**στη στάση** `[sti ˈstasi]` — на остановке,
**στην αποβάθρα** `[stin apoˈvaθra]` — на платформе.

В конспекте таблица сокращена; полный список с двумя аффрикатами дан в текущем
учебнике на с. 98 (PDF 88) и в [правиле происхождения и места](origin-and-residence.md).

## Проверка себя

Кто делает → именительный. Кого / что вижу, жду, беру → винительный.
После изученного предлога → винительный.
Затем одновременно проверь артикль, мужское окончание существительного и прилагательного.
