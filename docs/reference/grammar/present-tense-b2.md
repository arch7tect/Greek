# Настоящее время, тип Β2

У глаголов этой группы ударение падает на окончание. Отличить Β2 от [Β1](present-tense-b1.md) удобнее по форме «ты». У Β2 **οδηγείς** [oðiˈɣis] «водишь», у Β1 **μιλάς** [miˈlas] «говоришь». В первом лице возможны **οδηγώ** [oðiˈɣo] и **μιλώ** [miˈlo], поэтому одной формы «я» недостаточно.

| Лицо | Окончание | «Водить» |
|---|---|---|
| Я | **-ώ** [o] | οδηγ**ώ** [oðiˈɣo] |
| Ты | **-είς** [is] | οδηγ**είς** [oðiˈɣis] |
| Он / она | **-εί** [i] | οδηγ**εί** [oðiˈɣi] |
| Мы | **-ούμε** [ume] | οδηγ**ούμε** [oðiˈɣume] |
| Вы | **-είτε** [ite] | οδηγ**είτε** [oðiˈɣite] |
| Они | **-ούν(ε)** [un(e)] | οδηγ**ούν(ε)** [oðiˈɣun(e)] |

**Μπορείς;** [boˈris] — Можешь? **Μπορείτε;** [boˈrite] — Можете? Формой множественного числа можно обратиться к одному человеку на «вы».

У **ζω** [zo] «живу» свой ряд. **ζω, ζεις, ζει, ζούμε, ζείτε, ζουν / ζούνε** [zo, zis, zi, ˈzume, ˈzite, zun / ˈzune]. [Разбор и примеры урока 21](../../lessons/lesson-21-current.md#b2) · [Карточка](../../assets/mobile/lesson-21/lesson-21-card-01.png)
