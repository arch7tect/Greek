# Настоящее время: короткие глаголы АВ

Модель из [урока 14](../../lessons/lesson-14-current.md#verbs-ab).
В отличие от обычного типа А, у «ты» нет окончания **-εις** `[is]`:
**πας** `[pas]` — идёшь, **λες** `[les]` — говоришь.
Ниже формы в порядке **я → ты → он/она → мы → вы → они**.

| Глагол | Шесть форм | Произношение |
|---|---|---|
| идти | πά**ω**, πα**ς**, πά**ει**, πά**με**, πά**τε**, πά**νε** | `[ˈpao / pas / ˈpai / ˈpame / ˈpate / ˈpane]` |
| слышать, слушать | ακού**ω**, ακού**ς**, ακού**ει**, ακού**με**, ακού**τε**, ακού**νε** | `[aˈkuo / aˈkus / aˈkui / aˈkume / aˈkute / aˈkune]` |
| говорить, сказать | λέ**ω**, λε**ς**, λέ**ει**, λέ**με**, λέ**τε**, λέ**νε** | `[ˈleo / les / ˈlei / ˈleme / ˈlete / ˈlene]` |
| есть | τρώ**ω**, τρω**ς**, τρώ**ει**, τρώ**με**, τρώ**τε**, τρώ**νε** | `[ˈtroo / tros / ˈtroi / ˈtrome / ˈtrote / ˈtrone]` |
| плакать | κλαί**ω**, κλαι**ς**, κλαί**ει**, κλαί**με**, κλαί**τε**, κλαί**νε** | `[ˈkleo / kles / ˈklei / ˈkleme / ˈklete / ˈklene]` |
| быть виноватым | φταί**ω**, φται**ς**, φταί**ει**, φταί**με**, φταί**τε**, φταί**νε** | `[ˈfteo / ftes / ˈftei / ˈfteme / ˈftete / ˈftene]` |
| жечь | καί**ω**, και**ς**, καί**ει**, καί**με**, καί**τε**, καί**νε** | `[ˈkeo / kes / ˈkei / ˈkeme / ˈkete / ˈkene]` |

**Εγώ φταίω. Συγγνώμη!** `[eˈɣo ˈfteo siˈɣnomi]` — Я виноват. Извини!
Это глагол, поэтому форму выбирают по лицу, а не по полу говорящего.
**Ο ήλιος καίει.** `[o ˈilios ˈkei]` — Солнце печёт.
В этих формах **αι** `[e]` читается как «э», не «ай».

**πάω / πηγαίνω** `[ˈpao / piˈyeno]` — два равнозначных ряда, но окончания
смешивать нельзя: **πας / πηγαίνεις** `[pas / piˈyenis]` — ты идёшь.
**Πάμε;** `[ˈpame]` может быть приглашением «Пойдём?».

Обращение к одному человеку на «Вы» требует множественного числа:
**Τι λέτε;** `[ti ˈlete]` — Что Вы скажете?
Наличие двух имён не всегда означает «они»: «я и…» — «мы», «ты и…» — «вы».
