# Сон и утренние действия

Правило по [уроку 18](../../lessons/lesson-18-current.md#sleep), учебник с. 87.

**κοιμάμαι** `[kiˈmame]` — сплю; в распорядке «ложусь спать».
Это отдельная модель, не продолжение обычных окончаний группы А.

| Лицо | Форма | Перевод |
|---|---|---|
| я | κοιμ**άμαι** `[kiˈmame]` | сплю |
| ты | κοιμ**άσαι** `[kiˈmase]` | спишь |
| он / она | κοιμ**άται** `[kiˈmate]` | спит |
| мы | κοιμ**όμαστε** `[kiˈmomaste]` | спим |
| вы | κοιμ**όσαστε** / κοιμ**άστε** `[kiˈmosaste / kiˈmaste]` | спите |
| они | κοιμ**ούνται** `[kiˈmunde]` | спят |

**Κοιμάμαι αργά.** `[kiˈmame arˈɣa]` — Поздно ложусь спать.
**Πάω για ύπνο.** `[ˈpao ya ˈipno]` — Иду спать.
**ξαπλώνω** `[ksapˈlono]` — ложусь, принимаю лежачее положение; сон не обязателен.

Для утра различай **ξυπνάω** `[ksipˈnao]` — просыпаюсь и
**σηκώνομαι** `[siˈkonome]` — встаю. **ντύνομαι** `[ˈdinome]` — одеваюсь,
**ετοιμάζομαι** `[etiˈmazome]` — собираюсь / готовлюсь:
подготовка шире, чем надевание одежды.
**πλένομαι** `[ˈplenome]` — моюсь; **πλένω το πρόσωπό μου** `[ˈpleno to ˈprosopo mu]` — мою своё лицо.
Окончания других глаголов на **-μαι** `[me]` нельзя полностью угадывать по одной таблице:
в этом уроке для них нужны прежде всего формы «я».
