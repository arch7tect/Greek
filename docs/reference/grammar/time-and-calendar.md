## Какой вопрос задаём

| Вопрос | Ответ | Смысл |
|---|---|---|
| **Τι ώρα είναι;** `[ti ˈora ˈine]` | **Είναι τρεις.** `[ˈine tris]` | Который час? — Три часа. |
| **Τι ώρα;** `[ti ˈora]` | **Στις τρεις.** `[stis tris]` | Во сколько? — В три. |
| **Πότε;** `[ˈpote]` | **Τη Δευτέρα.** `[ti ðefˈtera]` | Когда? — В понедельник. |

Для времени сейчас предлог не нужен. Для времени события:
**στη μία** `[sti ˈmia]` — в час; **στις δύο** `[stis ˈðio]` — в два.
Час — женского рода: **μία / τρεις / τέσσερις** `[ˈmia / tris / ˈteseris]`.
Сокращения образуются из предлога и артикля:
**σε + τη → στη** `[se + ti → sti]`, **σε + τις → στις** `[se + tis → stis]`.
Для полуночи: **στα μεσάνυχτα** `[sta meˈsanihta]`.

## Часы и минуты

**και** `[ke]` прибавляет прошедшие минуты к текущему часу;
**παρά** `[paˈra]` вычитает оставшиеся минуты из следующего часа.

- **δύο και τέταρτο** `[ˈðio ke ˈtetarto]` — 2:15.
- **δύο και μισή** `[ˈðio ke miˈsi]` — 2:30, не 1:30.
- **τρεις παρά τέταρτο** `[tris paˈra ˈtetarto]` — 2:45, не 3:45.
- **τρεις ακριβώς** `[tris akriˈvos]` — ровно 3:00.

**κατά τις τρεις** `[kaˈta tis tris]` — около трёх, не обязательно ровно.
**σε μισή ώρα** `[se miˈsi ˈora]` — через полчаса, отсчёт от сейчас.
Для 12-часовой записи уточняем часть дня; [таблица и примеры](../../lessons/lesson-13-current.md#day-parts).

## День, месяц и сезон: винительный без предлога

Для ответа «когда?» здесь достаточно артикля и существительного в винительном:

| Название | Когда? |
|---|---|
| **η Δευτέρα** `[i ðefˈtera]` — понедельник | **τη Δευτέρα** `[ti ðefˈtera]` — в понедельник |
| **ο Μάρτιος** `[o ˈmartios]` — март | **τον Μάρτιο** `[ton ˈmartio]` — в марте |
| **ο χειμώνας** `[o hiˈmonas]` — зима | **τον χειμώνα** `[ton hiˈmona]` — зимой |
| **το Σάββατο** `[to ˈsavato]` — суббота | **το Σάββατο** `[to ˈsavato]` — в субботу |

Не только артикль: у мужского существительного исчезает конечная сигма.
Не вставляй предлог «в» автоматически по русскому переводу.
[Все дни](../../lessons/lesson-13-current.md#week) · [все месяцы и сезоны](../../lessons/lesson-13-current.md#calendar).

**σήμερα / αύριο / απόψε** `[ˈsimera / ˈavrio / aˈpopse]` — сегодня / завтра / сегодня вечером —
наречия; артикль к ним не добавляется.
