# Кто, какой, этот и тот

Связанный [урок 16](../../lessons/lesson-16-current.md),
[карточки](../../memory/lesson-16-current.md).
Здесь — именительный падеж: кто / что является предметом разговора.

## Три разных задачи { #choice }

| Задача | Формы | Значение |
|---|---|---|
| Спросить о человеке или выбрать предмет | **ποιος / ποια / ποιο** `[pyos / pya / pyo]` | кто? какой / какая / какое? |
| Указать на близкое или уже названное | **αυτός / αυτή / αυτό** `[afˈtos / afˈti / afˈto]` | этот / эта / это; также он / она / оно |
| Выделить более далёкое | **εκείνος / εκείνη / εκείνο** `[eˈkinos / eˈkini / eˈkino]` | тот / та / то |

Род выбираем по **греческому** слову, число — по количеству.
**το βιβλίο** `[to viˈvlio]` — книга, но средний род:
**Ποιο βιβλίο; Αυτό το βιβλίο.** `[pyo viˈvlio? afˈto to viˈvlio]` —
Какая книга? Эта книга. Русское «какая» не требует греческой женской формы.

## Единственное и множественное число { #forms }

| Род и число | Кто / какой? | Этот | Тот |
|---|---|---|---|
| м., ед. | ποιος `[pyos]` | αυτός `[afˈtos]` | εκείνος `[eˈkinos]` |
| ж., ед. | ποια `[pya]` | αυτή `[afˈti]` | εκείνη `[eˈkini]` |
| ср., ед. | ποιο `[pyo]` | αυτό `[afˈto]` | εκείνο `[eˈkino]` |
| м., мн. | ποιοι `[pyi]` | αυτοί `[afˈti]` | εκείνοι `[eˈkini]` |
| ж., мн. | ποιες `[pyes]` | αυτές `[afˈtes]` | εκείνες `[eˈkines]` |
| ср., мн. | ποια `[pya]` | αυτά `[afˈta]` | εκείνα `[eˈkina]` |

Женское единственное и среднее множественное **ποια** `[pya]` пишутся одинаково.
Рядом с **είναι** `[ˈine]` число тоже не слышно: это и «есть», и «являются».
Поэтому смотри на существительное или на людей на картинке.
Смешанная группа людей использует мужское множественное.

**Ποιες είναι αυτές;** `[pyes ˈine afˈtes]` — Кто эти женщины?
**Ποια είναι αυτά;** `[pya ˈine afˈta]` — Что это за предметы среднего рода?
**Ποια παιδιά;** `[pya peˈðya]` — Какие дети?

## Нужен ли артикль? { #article }

Перед существительным после «этот / тот» **сохраняется определённый артикль**:
**αυτή η τσάντα** `[afˈti i ˈtsanda]` — эта сумка;
**εκείνο το νερό** `[eˈkino to neˈro]` — та вода.
Без существительного местоимение самостоятельно:
**Αυτή είναι ακριβή, αλλά εκείνη είναι φτηνή.**
`[afˈti ˈine akriˈvi aˈla eˈkini ˈine ftiˈni]` — Эта дорогая, а та дешёвая.
Второй раз «сумка» можно не повторять: род всё равно остаётся женским.

После вопросительного «какой?» перед существительным артикль не ставим:
**Ποιο λεωφορείο πηγαίνει στο κέντρο;**
`[pyo leofoˈrio piˈyeni sto ˈkendro]` — Какой автобус едет в центр?
Не добавляй артикль по модели указательного сочетания.

## Не путать близкие слова { #contrasts }

**τι** `[ti]` — «что?», вопрос без выбора рода: **Τι κάνεις;** `[ti ˈkanis]` — Что делаешь?
**ποιος** `[pyos]` и остальные формы — «кто? / какой именно?».
**εδώ** `[eˈðo]` — здесь; **εκεί** `[eˈki]` — там. Это место, а не название предмета.
**εκείνη η κυρία εκεί** `[eˈkini i kiˈria eˈki]` — та госпожа вон там:
первая форма — «та», последнее слово — «там».

**Αυτός είναι ψηλός.** `[afˈtos ˈine psiˈlos]` — Он высокий.
**Αυτός ο άντρας είναι ψηλός.** `[afˈtos o ˈandras ˈine psiˈlos]` — Этот мужчина высокий.
Одна форма может быть личным «он» или указательным «этот»: решает контекст.
