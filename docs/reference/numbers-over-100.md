# Числа больше ста

Источник: текущая редакция учебника, печатная с. 89 (PDF 80),
[урок 18](../lessons/lesson-18-current.md#numbers).
[Числа до 100](numbers-11-100.md) остаются основой.

## Сотни { #hundreds }

| Число | Греческий | Произношение |
|---|---|---|
| 100 | εκατό | `[ekaˈto]` |
| 101 | εκατόν ένα | `[ekaˈton ˈena]` |
| 200 | διακόσια | `[ðiaˈkosia]` |
| 300 | τριακόσια | `[triaˈkosia]` |
| 400 | τετρακόσια | `[tetraˈkosia]` |
| 500 | πεντακόσια | `[pendaˈkosia]` |
| 600 | εξακόσια | `[eksaˈkosia]` |
| 700 | εφτακόσια / επτακόσια | `[eftaˈkosia / eptaˈkosia]` |
| 800 | οχτακόσια / οκτακόσια | `[ohtaˈkosia / oktaˈkosia]` |
| 900 | εννιακόσια | `[enyaˈkosia]` |

Для счёта самостоятельных чисел используем средние формы.
Если за ста следует продолжение, в модели учебника стоит конечное «н»:
**εκατόν είκοσι τρία** `[ekaˈton ˈikosi ˈtria]` — 123.
После других сотен отдельное **ν** `[n]` не добавляем:
**διακόσια είκοσι τρία** `[ðiaˈkosia ˈikosi ˈtria]` — 223.
Не вставляем «и» между сотней, десятками и единицами.

## Тысячи и миллионы { #thousands }

**χίλια** `[ˈhilya]` — 1000. Для нескольких тысяч — **χιλιάδες** `[hiˈlyaðes]`,
женский род: **δύο / τρεις / τέσσερις χιλιάδες**
`[ˈðio / tris / ˈteseris hiˈlyaðes]` — 2000 / 3000 / 4000.
Само **δύο** `[ˈðio]` не меняется по роду.

Сотни согласуются с «тысячами»:
**εξακόσιες πενήντα χιλιάδες** `[eksaˈkosies peˈninda hiˈlyaðes]` — 650 000.
Типовое женское окончание сотен **-ες** `[es]` вместо среднего **-α** `[a]`.
Часть **εκατό χιλιάδες** `[ekaˈto hiˈlyaðes]` — 100 000 — не становится женским прилагательным.

**ένα εκατομμύριο** `[ˈena ekatoˈmirio]` — 1 000 000;
**τρία / τέσσερα εκατομμύρια** `[ˈtria / ˈtesera ekatoˈmiria]` — 3 / 4 миллиона,
средний род. «Три тысячи» и «три миллиона» требуют разных форм тройки.

**2.013 — δύο χιλιάδες δεκατρία** `[ˈðio hiˈlyaðes ðekaˈtria]`.
Точка в этих примерах — разделитель тысяч, не десятичная дробь.
Разбиваем число на группы справа по три цифры, читаем крупные группы первыми.

## Действия { #operations }

**συν / και** `[sin / ke]` — плюс; **πλην / μείον** `[plin / ˈmion]` — минус;
**επί** `[eˈpi]` — умножить на; **διά** `[ðiˈa]` — разделить на;
**ίσον** `[ˈison]` — равно.
