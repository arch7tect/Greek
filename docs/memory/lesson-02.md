# Урок 02 — чтение и ударение

**Статус:** проверено по назначенным страницам; памятка для повторения.

- Начальные `π / μπ / β` `[p / b / v]` — «п / б / в».
- Начальное `ντ` `[d]` не равно `δ` `[ð]`: у второго язык между зубами.
- Начальное `γκ` `[g]` не равно щелевой `γ` `[ɣ/y]`.
- `τσ / τζ` `[ts / dz]` — глухое «ц» и звонкое «дз».
- `αι` `[e]`, `ει / οι / υι` `[i]`, `ου` `[u]`: две буквы, один гласный.
- Ударение над второй буквой сочетания: `είμαι` `[ˈime]`.
- В `φως` `[fos]` и `ΝΙΚΟΣ` `[ˈnikos]` письменного знака нет.
  Только первая буква прописная и ударная — знак слева: `Άνι` `[ˈani]`.
