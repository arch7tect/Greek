# Вопросы и ответы — сквозной сборник

[A4 для печати — 6 страниц](../assets/print/questions-answers-a4.pdf){ .md-button }
[PDF для телефона — 16 страниц](../assets/mobile/questions-answers-phone.pdf){ .md-button }

Все 30 пунктов нашего списка: вопросы на «ты» и «вы», полные ответы, перевод и произношение. В обоих PDF одинаковое содержание; варианты оценки языка относятся к пункту 19. Это полный разговорный сборник, отдельно от [9 коротких карточек «Главное»](core.md).

Ответы — учебные примеры, а не биография одного человека. Адрес и контакты взяты из учебника. При вежливом обращении на «вы» один человек отвечает «я». Вопросы и ответы видны сразу; для проверки прикрой ответ.

Разборы: [знакомство](../lessons/lesson-03-introductions-and-eimai.md), [общение и жильё](../lessons/lesson-04-current.md), [запись на занятия](../lessons/lesson-05-current.md#registration), [языки и учёба](../lessons/lesson-06-current.md).

## 01. Как тебя / вас зовут? { #q01 }

**Ты: Πώς σε λένε;**  
`[pos se ˈlene]`  
Как тебя зовут?

**Вы: Πώς σας λένε;**  
`[pos sas ˈlene]`  
Как вас зовут?

**Вы: Πώς λέγεστε, παρακαλώ;**  
`[pos ˈleyeste parakaˈlo]`  
Как вас зовут, пожалуйста?

**Ответ: Με λένε Ολέγκ.**  
`[me ˈlene oˈleg]`  
Меня зовут Олег.


## 02. Как его / её зовут? { #q02 }

**Вопрос: Πώς τον λένε;**  
`[pos ton ˈlene]`  
Как его зовут?

**Ответ: Τον λένε Κάρλο.**  
`[ton ˈlene ˈkarlo]`  
Его зовут Карло.

**Вопрос: Πώς τη λένε;**  
`[pos ti ˈlene]`  
Как её зовут?

**Ответ: Τη λένε Μαρία.**  
`[ti ˈlene maˈria]`  
Её зовут Мария.


## 03. Как дела? { #q03 }

**Ты: Τι κάνεις; / Πώς είσαι;**  
`[ti ˈkanis / pos ˈise]`  
Как у тебя дела?

**Вы: Τι κάνετε; / Πώς είστε;**  
`[ti ˈkanete / pos ˈiste]`  
Как у вас дела?

**Ответ: Είμαι πολύ καλά, ευχαριστώ. Εσείς;**  
`[ˈime poˈli kaˈla efhariˈsto eˈsis]`  
У меня всё очень хорошо, спасибо. А у вас?

**Иначе: Είμαι έτσι κι έτσι.**  
`[ˈime ˈetsi ki ˈetsi]`  
У меня дела так себе.


## 04. Откуда ты / вы? { #q04 }

**Ты: Από πού είσαι;**  
`[aˈpo pu ˈise]`  
Откуда ты?

**Вы: Από πού είστε;**  
`[aˈpo pu ˈiste]`  
Откуда вы?

**Ответ: Είμαι από τη Ρωσία.**  
`[ˈime aˈpo ti roˈsia]`  
Я из России.

О происхождении, не обязательно о месте рождения. На вежливое «вы» один человек отвечает «я».

## 05. Из какого именно места? { #q05 }

**Вопрос: Από τη Γαλλία, από ποιο μέρος;**  
`[aˈpo ti ɣaˈlia aˈpo pyo ˈmeros]`  
Из Франции - из какого места?

**Ответ: Είμαι από το Παρίσι.**  
`[ˈime aˈpo to paˈrisi]`  
Я из Парижа.


## 06. Национальность { #q06 }

**Ты: Είσαι Ιταλίδα;**  
`[ˈise itaˈliða]`  
Ты итальянка?

**Ответ: Ναι, είμαι Ιταλίδα.**  
`[ne ˈime itaˈliða]`  
Да, я итальянка.

**Вы: Είστε Ισπανίδα;**  
`[ˈiste ispaˈniða]`  
Вы испанка?

**Ответ: Ναι, είμαι Ισπανίδα. Είμαι από τη Μαδρίτη.**  
`[ne ˈime ispaˈniða. ˈime aˈpo ti maˈðriti]`  
Да, я испанка. Я из Мадрида.


## 07. Откуда он / она? { #q07 }

`[aˈpo pu ˈine o ˈkarlo]`

`[o ˈkarlo ˈine aˈpo tin itaˈlia]`

Откуда Аише?

**Ответ: Η Αϊσέ είναι από την Τουρκία.**  
`[i aiˈse ˈine aˈpo tin turˈkia]`  
Аише из Турции.


## 08. Где ты / вы живёте? { #q08 }

**Ты: Πού μένεις;**  
`[pu ˈmenis]`  
Где ты живёшь?

**Вы: Πού μένετε;**  
`[pu ˈmenete]`  
Где вы живёте?

**Ответ: Μένω στη Λεμεσό, στην Κύπρο.**  
`[ˈmeno sti lemeˈso stin ˈkipro]`  
Я живу в Лимассоле, на Кипре.


## 09. Где вы сейчас живёте? { #q09 }

**Вы: Τώρα πού μένετε;**  
`[ˈtora pu ˈmenete]`  
Где вы сейчас живёте?

**Ответ: Τώρα μένω στη Λεμεσό.**  
`[ˈtora ˈmeno sti lemeˈso]`  
Сейчас я живу в Лимассоле.


## 10. Где именно? Адрес { #q10 }

**Ты: Εσύ πού ακριβώς μένεις;**  
`[eˈsi pu akriˈvos ˈmenis]`  
Ты где именно живёшь?

**Вы: Πού ακριβώς μένετε;**  
`[pu akriˈvos ˈmenete]`  
Где именно вы живёте?

**Кратко: Μία διεύθυνση;**  
`[ˈmia ðiˈefθinsi]`  
Адрес?

**Ответ: Μένω Σποράδων 3, στην Κυψέλη.**  
`[ˈmeno spoˈraðon ˈtria stin kiˈpseli]`  
Я живу на улице Спорадон, 3, в Кипсели.

Учебный адрес из диалога, не личные контакты.

## 11. Где она живёт? { #q11 }

**Вопрос: Πού μένει η Αϊσέ;**  
`[pu ˈmeni i aiˈse]`  
Где живёт Аише?

**Ответ: Η Αϊσέ μένει Σκύρου 16, στην Κυψέλη.**  
`[i aiˈse ˈmeni ˈskiru ðekaˈeksi stin kiˈpseli]`  
Аише живёт на улице Скиру, 16, в Кипсели.


## 12. Вы живёте в Салониках? { #q12 }

**Вы: Εσείς μένετε στη Θεσσαλονίκη;**  
`[eˈsis ˈmenete sti θesaloˈniki]`  
Вы живёте в Салониках?

**Ответ: Όχι, δεν μένω στη Θεσσαλονίκη. Μένω στη Λεμεσό.**  
`[ˈohi ðen ˈmeno sti θesaloˈniki. ˈmeno sti lemeˈso]`  
Нет, я не живу в Салониках. Я живу в Лимассоле.


## 13. Вы студентка? { #q13 }

**Вы: Είστε φοιτήτρια;**  
`[ˈiste fiˈtitria]`  
Вы студентка?

**Ответ: Ναι, είμαι φοιτήτρια.**  
`[ne ˈime fiˈtitria]`  
Да, я студентка.

**Вы: Είστε φοιτήτρια Erasmus;**  
`[ˈiste fiˈtitria ˈerazmus]`  
Вы студентка по программе Erasmus?

**Ответ: Μάλιστα, είμαι φοιτήτρια Erasmus.**  
`[ˈmalista ˈime fiˈtitria ˈerazmus]`  
Да, я студентка по программе Erasmus.


## 14. Что ты / вы изучаете? { #q14 }

**Ты: Τι σπουδάζεις;**  
`[ti spuˈðazis]`  
Что ты изучаешь в вузе?

**Вы: Τι σπουδάζετε;**  
`[ti spuˈðazete]`  
Что вы изучаете в вузе?

**Ответ: Σπουδάζω Ιστορία και Αρχαιολογία στο Πανεπιστήμιο Αθηνών.**  
`[spuˈðazo istoˈria ke arheoloˈyia sto panepiˈstimio aθiˈnon]`  
Я изучаю историю и археологию в Афинском университете.

**Иначе: Σπουδάζω Νομικά. Κάνω μεταπτυχιακό.**  
`[spuˈðazo nomiˈka. ˈkano metaptihiaˈko]`  
Я изучаю право. Учусь в магистратуре.


## 15. Где ты / вы учитесь? { #q15 }

`[pu spuˈðazis]`  
Где ты учишься в вузе?

**Вы: Πού σπουδάζετε;**  
`[pu spuˈðazete]`  
Где вы учитесь в вузе?

**Ответ: Σπουδάζω στο Πανεπιστήμιο Αθηνών.**

Я учусь в Афинском университете.

Вопрос построен по пройденной модели; ответ - из диалога.

## 16. Где ты / вы работаете? { #q16 }

`[pu ðuˈlevis]`

**Вы: Πού δουλεύετε;**  
`[pu ðuˈlevete]`

**Ответ: Δουλεύω στην καφετέρια.**

## 17. На каких языках говорите? { #q17 }

**Ты: Τι γλώσσες μιλάς;**  
`[ti ˈɣloses miˈlas]`  
На каких языках ты говоришь?

**Вы: Τι γλώσσες μιλάτε;**  
`[ti ˈɣloses miˈlate]`  
На каких языках вы говорите?

**Ответ: Μιλάω ρωσικά, πολύ λίγο ελληνικά και λίγο αγγλικά.**  
`[miˈlao rosiˈka poˈli ˈliɣo eliniˈka ke ˈliɣo aŋgliˈka]`  
Я говорю по-русски, совсем немного по-гречески и немного по-английски.


## 18. Какие иностранные языки знаете? { #q18 }

**Вы: Τι ξένες γλώσσες ξέρετε;**  
`[ti ˈksenes ˈɣloses ˈkserete]`  
Какие иностранные языки вы знаете?

**Ответ: Ξέρω λίγο αγγλικά και πολύ λίγο ελληνικά.**  
`[ˈksero ˈliɣo aŋgliˈka ke poˈli ˈliɣo eliniˈka]`  
Я немного знаю английский и совсем немного греческий.


## 19. Говорите по-гречески? { #q19 }

**Ты: Μιλάς ελληνικά;**  
`[miˈlas eliniˈka]`  
Ты говоришь по-гречески?

**Вы: Μιλάτε ελληνικά;**  
`[miˈlate eliniˈka]`  
Вы говорите по-гречески?

**Ответ: Ναι, μιλάω πολύ λίγο ελληνικά.**  
`[ne miˈlao poˈli ˈliɣo eliniˈka]`  
Да, я совсем немного говорю по-гречески.


## 19a. По-гречески: хорошо { #q19a }

**Ответ: Μιλάω πολύ καλά ελληνικά.**  
`[miˈlao poˈli kaˈla eliniˈka]`  
Я очень хорошо говорю по-гречески.

**Ответ: Μιλάω αρκετά καλά ελληνικά.**  
`[miˈlao arkeˈta kaˈla eliniˈka]`  
Я довольно хорошо говорю по-гречески.

**Ответ: Μιλάω καλά ελληνικά.**  
`[miˈlao kaˈla eliniˈka]`  
Я хорошо говорю по-гречески.


## 19b. По-гречески: немного / плохо { #q19b }

**Ответ: Μιλάω έτσι κι έτσι ελληνικά.**  
`[miˈlao ˈetsi ki ˈetsi eliniˈka]`  
Я говорю по-гречески так себе.

**Ответ: Μιλάω λίγο ελληνικά.**  
`[miˈlao ˈliɣo eliniˈka]`  
Я немного говорю по-гречески.

**Ответ: Δεν μιλάω καλά ελληνικά.**  
`[ðen miˈlao kaˈla eliniˈka]`  
Я плохо говорю по-гречески.

**Ответ: Δεν μιλάω καθόλου ελληνικά.**  
`[ðen miˈlao kaˈθolu eliniˈka]`  
Я совсем не говорю по-гречески.

Немного - объём знаний; хорошо / плохо - качество речи.

## 22. Номер телефона, пожалуйста? { #q22 }

**Вопрос: Ένα τηλέφωνο, παρακαλώ;**  
`[ˈena tiˈlefono parakaˈlo]`  
Номер телефона, пожалуйста?

**Ответ: Το κινητό μου είναι 69 74 63 81 45.**  
`[to kiniˈto mu ˈine eˈksinda eˈnya evðoˈminda ˈtesera eˈksinda ˈtria oɣˈðonda ˈena saˈranda ˈpende]`  
Мой мобильный телефон: 69 74 63 81 45.

Номер персонажа учебника. Произношение - парами чисел.

## 23. Электронная почта? { #q23 }

**Вопрос: Ένα μέιλ;**  
`[ˈena meil]`  
Электронная почта?

**Ответ: Το μέιλ μου είναι anebe@gmail.es.**  
`[to meil mu ˈine]`  
Моя электронная почта - anebe@gmail.es.

**Символ: παπάκι**  
`[paˈpaki]`  
Знак @.

**Символ: τελεία**  
`[teˈlia]`  
Точка.

Учебный адрес. Транскрипция ответа относится к греческим словам; латинский адрес при необходимости диктуют по буквам.

## 24. У вас есть фотография? { #q24 }

**Ответ: Ναι, έχω μία φωτογραφία. Ορίστε.**  
`[ne ˈeho ˈmia fotoɣraˈfia. oˈriste]`

`[ˈohi ðen ˈeho fotoɣraˈfia]`  
Нет, у меня нет фотографии.

## 30. А ты? А вы? { #q30 }

**Ты: Εσύ;**  
`[eˈsi]`  
А ты? После ответа о себе.

**Вы: Εσείς;**  
`[eˈsis]`  
А вы? Вежливо или группе.

**Тебя: Εσένα;**  
`[eˈsena]`  
А тебя? После «Меня зовут…».

**Вас: Εσάς;**  
`[eˈsas]`  
А вас? После «Меня зовут…».

**Вопрос: Με λένε Ολέγκ. Εσάς;**  
`[me ˈlene oˈleg eˈsas]`  
Меня зовут Олег. А вас?

**Ответ: Με λένε Μαρία.**  
`[me ˈlene maˈria]`  
Меня зовут Мария.
