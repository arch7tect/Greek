# Урок 08 — быстрое повторение

Четыре опоры: чей; дополнительное ударение; дальние родственники; отношения и дети.
Подробные объяснения остаются [в уроке](../lessons/lesson-08-current.md).

- Артикль выбираем по предмету, «его / её» — по владельцу:
  `η αδερφή του` `[i aðerˈfi tu]` — его сестра;
  `ο αδερφός της` `[o aðerˈfos tis]` — её брат.
- Если ударение на третьем слоге от конца, перед коротким притяжательным словом
  добавляется ещё одно: `το τηλέφωνό μου` `[to tiˈlefoˈno mu]` — мой телефон.
- В семейной схеме сначала выбираем человека, **о чьей семье** говорим.
- `ο άντρας μου` `[o ˈandras mu]` — мой муж;
  `η γυναίκα μου` `[i yiˈneka mu]` — моя жена
  ([карточка «Отношения и дети»](../assets/mobile/lesson-08/lesson-08-card-04.png)).
- `Έχετε παιδιά;` `[ˈehete peˈðya]` — У вас есть дети?
  `Όχι, δεν έχω.` `[ˈohi ðen ˈeho]` — Нет, у меня нет.

Спряжение Β1 повторяй по [сквозному набору](core.md): отдельную копию полной
таблицы в эти карточки не добавляем.
