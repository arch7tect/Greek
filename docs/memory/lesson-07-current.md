- **Говорить:** `μιλάω, μιλάς, μιλάει, μιλάμε, μιλάτε, μιλάνε`
  `[miˈlao, miˈlas, miˈlai, miˈlame, miˈlate, miˈlane]`.
- **Семья:** отец и мать — `οι γονείς` `[i ɣoˈnis]`; сын и дочь —
  `τα παιδιά` `[ta peˈðya]`; братья и сёстры — `τα αδέλφια` `[ta aˈðelfya]`.
- **Чей:** `μου / σου / του / της / μας / σας / τους`
  `[mu / su / tu / tis / mas / sas / tus]` — мой / твой / его / её / наш / ваш / их.
- **Не путать:** `η αδελφή του` `[i aðelˈfi tu]` — его сестра;
  `ο αδελφός της` `[o aðelˈfos tis]` — её брат.
- **Профессия:** `Τι δουλειά κάνει;` `[ti ðuˈlya ˈkani]` — кем работает?
  `Είναι γιατρός.` `[ˈine yaˈtros]` — он / она врач.

В сквозном наборе уже есть спряжение, принадлежность и оценка «хорошо / немного».
Не нужно учить дубликаты: [«Главное»](core.md).
