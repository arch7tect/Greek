базовые формы, вопросы с ответами и повседневные фразы. Всё видно сразу,
без скрытых ответов.

## Что повторять

| Карточка | Главное | Если нужно разобраться |
|---|---|---|
| 1. Местоимения и «быть» | Я, ты, он / она / оно, мы, вы, они — с формой глагола; мой / твой / его / её / наш / ваш / их | [«Быть»](../reference/grammar/eimai.md), [местоимения](../reference/grammar/personal-pronouns.md) |
| 2. Глаголы А: проживать | Шесть форм; окончания выделены внутри слова | [Глаголы А](../reference/grammar/present-tense-a.md) |

| 4. Знакомство | Имя, происхождение, национальность, «как дела?» | [Знакомство](../reference/greetings-and-introductions.md) |

| 6. Фразы на каждый день | Приветствия, прощания, спасибо и пожалуйста | [Фразы общения](../reference/greetings-and-introductions.md) |
| 7. Род и артикли | Род по окончанию, конкретный / какой-то, «из» и «в» | [Артикли](../reference/grammar/nominative-articles.md), [предлоги](../reference/grammar/prepositions-accusative.md) |

| 9. Как хорошо и сколько | Прекрасно / хорошо / так себе; немного / совсем немного / совсем не | [Оттенки и отрицание](../lessons/lesson-06-current.md#language-level) |

**11, 12, 70, 80 и 100** выделены отдельно: начни повторение чисел с них.
«Откуда ты?» не означает «Где ты родился?» — второй вопрос
в этот набор пока не входит.

## Как пользоваться

Прочитай нужную карточку вслух. Затем прикрой греческий текст и попробуй
вспомнить формы или фразу по русскому переводу. Достаточно нескольких минут;
не нужно ежедневно перелистывать все карточки каждого урока.

[Карточки по урокам](mobile-cards.md) остаются для повторения конкретной темы.
Сквозной набор будем уточнять по мере учёбы, не добавляя дубликаты базовых правил.
