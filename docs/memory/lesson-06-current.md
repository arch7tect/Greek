- **Откуда:** `Είμαι από τη Ρωσία.` `[ˈime aˈpo ti roˈsia]` — я из России.
- **Кто:** `Είμαι Ρώσος / Ρωσίδα.` `[ˈime ˈrosos / roˈsiða]` — я русский / русская.
- **Язык:** `Μιλάω ρωσικά.` `[miˈlao rosiˈka]` — говорю по-русски.
- **Где живу:** `Μένω στην Κύπρο.` `[ˈmeno stin ˈkipro]` — живу на Кипре.
- **Шесть форм:** `μιλάω, μιλάς, μιλάει, μιλάμε, μιλάτε, μιλάνε`
  `[miˈlao, miˈlas, miˈlai, miˈlame, miˈlate, miˈlane]`.
- **Как хорошо:** `πολύ καλά / αρκετά καλά / λίγο`
  `[poˈli kaˈla / arkeˈta kaˈla / ˈliɣo]` — очень хорошо / достаточно хорошо / немного.
- **Совсем не:** `Δεν μιλάω καθόλου.` `[ðen miˈlao kaˈθolu]`.
- Страна и национальность — с большой буквы, язык — с маленькой.
  Женскую форму национальности учим вместе с мужской: одного общего окончания нет.
