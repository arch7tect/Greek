# Урок 11 — быстрое повторение

[A4 — 1 страница](../assets/print/lesson-11-study-card-a4.pdf) ·
[Телефон — 4 карточки](../assets/mobile/lesson-11-phone-cards.pdf) ·

Четыре опоры: род и окончания; исключения; основные противоположности;
вопросительные и указательные местоимения.
Это выборка для повторения, не замена [подробного урока](../lessons/lesson-11-current.md).

- **καλός / καλή / καλό** [kaˈlos / kaˈli / kaˈlo] — хороший / хорошая / хорошее.
- **ωραίος / ωραία / ωραίο** [oˈreos / oˈrea / oˈreo] — красивый / красивая / красивое.
- **ποιος / ποια / ποιο** [pyos / pya / pyo] — кто? / какой, какая, какое?

В [сквозной набор](core.md) добавлено только согласование и две модели
с исключениями: правило пригодится в следующих уроках.
Полный список признаков остаётся [в словаре урока](../vocabulary/lesson-11.md),
не превращаем каждый антоним в отдельную сквозную карточку.
