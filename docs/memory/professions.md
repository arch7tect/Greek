Один тематический набор из пройденных слов: профессии, женские формы,
места работы и слова о занятости. Без возраста, семьи и скороговорок.
На первых двух листах — люди, на третьем — места. Таблицы ниже повторяют
тот же состав. Редкие профессии тоже оставлены: это подготовка к диктанту
по теме, а не только первый разговорный минимум.

Сначала прочитай слово, затем закрой греческую колонку и напиши его по переводу.
Проверяй отдельно артикль, буквы и ударение. В тренажёре нужен именно
словарный артикль, хотя в предложении «я — врач» перед профессией его обычно нет.
Если в записи два варианта через косую черту, тренажёр принимает один из них;
отдельно записанные мужская и женская формы повторяются раздельно.

Различай **ο γυμναστής / η γυμνάστρια** [o yimnaˈstis / i yimˈnastria] —
тренер / тренер-женщина и **το γυμναστήριο** [to yimnaˈstirio] — спортзал.
**ο φούρναρης** [o ˈfurnaris] — пекарь, **ο φούρνος** [o ˈfurnos] — пекарня.
Студент, безработный и пенсионер — не названия профессий, но нужны для ответа
о занятии человека.
