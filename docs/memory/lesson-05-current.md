- **Род учим с артиклем**: `ο / η / το` `[o / i / to]` — мужской / женский / средний.
- Один, какой-то: `ένας / μία / ένα` `[ˈenas / ˈmia / ˈena]`.
- Неопределённый артикль — ещё не уточняем, какой предмет. Определённый —
  собеседнику понятно, какой именно. Род выбирает пару форм, смысл — одну из них.
- Окончания — подсказка, не гарантия: **-ος, -ης, -ας** `[os, is, as]` обычно мужские;
  **-α, -η** `[a, i]` женские; **-ο, -ι, -μα** `[o, i, ma]` средние.
- `το μάθημα` `[to ˈmaθima]` — урок; `το κορίτσι` `[to koˈritsi]` — девочка:
  оба среднего рода.
- Вежливый вопрос → ответ про себя: `Πού μένετε; — Μένω εδώ.`
  `[pu ˈmenete — ˈmeno eˈðo]` — «Где вы живёте? — Живу здесь».
- Диалог с. 48: имя → студентка → страна → специальность → адрес → телефон → почта → фото.
- Числа до 100: десяток + единицы без союза. `είκοσι τρία` `[ˈikosi ˈtria]` — 23.
