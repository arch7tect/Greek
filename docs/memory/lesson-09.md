# Урок 09 — коротко для памяти

## Ближайшая семья

- `οι γονείς` `[i ɣoˈnis]` — родители;
- `ο πατέρας / ο μπαμπάς` `[o paˈteras / o baˈbas]` — отец / папа;
- `η μητέρα / η μαμά` `[i miˈtera / i maˈma]` — мать / мама;
- `ο γιος / η κόρη` `[o yos / i ˈkori]` — сын / дочь;
- `ο αδερφός / η αδερφή` `[o aðerˈfos / i aðerˈfi]` — брат / сестра.

## Чей?

| Владелец | Форма после существительного |
|---|---|
| я | `μου` `[mu]` |
| ты | `σου` `[su]` |
| он / она | `του / της` `[tu / tis]` |
| мы | `μας` `[mas]` |
| вы | `σας` `[sas]` |
| они | `τους` `[tus]` |

- `ο πατέρας μου` `[o paˈteras mu]` — мой отец;
- `η μητέρα σου` `[i miˈtera su]` — твоя мать;
- `τα παιδιά τους` `[ta peˈðya tus]` — их дети.

Форма зависит от владельца, а не от рода предмета. Она ставится после
существительного.

Дополнительное ударение:
`η οικογένεια → η οικογένειά μου`
`[i ikoˈyenia → i ikoˈyeniˈa mu]`.
