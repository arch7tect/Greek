# Урок 08 — коротко для памяти

## Две модели настоящего времени

| Лицо | Тип Α: `δουλεύω` `[ðuˈlevo]` | Тип Β1: `μιλάω` `[miˈlao]` |
|---|---|---|
| я | `δουλεύω` `[ðuˈlevo]` | `μιλάω` `[miˈlao]` |
| ты | `δουλεύεις` `[ðuˈlevis]` | `μιλάς` `[miˈlas]` |
| он / она | `δουλεύει` `[ðuˈlevi]` | `μιλάει` `[miˈlai]` |
| мы | `δουλεύουμε` `[ðuˈlevume]` | `μιλάμε` `[miˈlame]` |
| вы | `δουλεύετε` `[ðuˈlevete]` | `μιλάτε` `[miˈlate]` |
| они | `δουλεύουν` `[ðuˈlevun]` | `μιλάνε` `[miˈlane]` |

Тип Α: словарное `-ω` `[o]` без ударения. Тип Β1: ударное
`-άω / -ώ` `[-ˈao / -ˈo]`.

## Как выбирать

1. Узнать словарную модель: `μαθαίνω` `[maˈθeno]` — Α,
   `ρωτάω` `[roˈtao]` — Β1.
2. Найти подлежащее.
3. Поставить окончание нужного лица.

`Η καθηγήτρια ρωτάει.` `[i kaθiˈyitria roˈtai]` — преподавательница
спрашивает.<br>
`Οι φοιτητές ρωτάνε.` `[i fitiˈtes roˈtane]` — студенты спрашивают.
