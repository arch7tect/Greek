# Урок 10 — быстрое повторение

[A4 — 1 страница](../assets/print/lesson-10-study-card-a4.pdf) ·

Три опоры: возраст; кто, где и что делает; рассказ о себе.
К диктанту отдельно: [профессии и места работы — шпаргалка и тренажёр](professions.md).
Полные пары профессий, таблицы, текст и перевод — [в уроке](../lessons/lesson-10-current.md).

- **Πόσων χρονών είσαι;** [ˈposon hroˈnon ˈise?] — Сколько тебе лет?
- **ενός χρόνου / τριών χρονών / τεσσάρων χρονών**
  [eˈnos ˈhronu / triˈon hroˈnon / teˈsaron hroˈnon] — одного / трёх / четырёх лет.
- **ο φούρνος / ο φούρναρης** [o ˈfurnos / o ˈfurnaris] — пекарня / пекарь.
- **Με λένε … Μένω … Δουλεύω …** [me ˈlene … ˈmeno … ðuˈlevo …] —
  Меня зовут … Живу … Работаю …

[Словарь](../vocabulary/lesson-10.md) · [Домашка](../homework/lesson-10-current.md).

Для регулярного повторения используй [сквозной набор](core.md) и
[вопросы с полными ответами](questions-answers.md): формы «работать» относятся
к уже имеющейся модели Α1, вопросы о профессии и возрасте уже собраны там.
Новые редкие профессии не превращаем в ещё одну сквозную карточку.
