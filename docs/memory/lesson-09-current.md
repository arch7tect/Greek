Четыре опоры: кем / где работаешь; мужские и женские профессии; место работы; возраст.
Полные таблицы, диалог и рассказ об Эве — [в уроке](../lessons/lesson-09-current.md).

- `Τι δουλειά κάνεις;` `[ti ðuˈlya ˈkanis]` — Кем работаешь?
  `Είμαι μηχανικός.` `[ˈime mihaniˈkos]` — Я инженер.
- `Πού δουλεύεις;` `[pu ðuˈlevis]` — Где работаешь?
  `Δουλεύω στο γραφείο.` `[ðuˈlevo sto ɣraˈfio]` — Работаю в офисе.
- `ο / η γιατρός` `[o / i yaˈtros]` — мужчина-врач / женщина-врач:
  окончание не меняется, выбираем артикль.
- `Πόσων χρονών είσαι;` `[ˈposon hroˈnon ˈise]` — Сколько тебе лет?
  `Είμαι είκοσι τριών χρονών.` `[ˈime ˈikosi triˈon hroˈnon]` — Мне 23 года.

Спряжение «работать» — знакомая модель Α1: повторяй
[сквозную карточку](core.md), не добавляя ещё одну полную таблицу.
