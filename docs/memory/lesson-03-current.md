## Краткое повторение

| Кто | «Быть» |
|---|---|
| `εγώ` `[eˈɣo]` — я | `είμαι` `[ˈime]` |
| `εσύ` `[eˈsi]` — ты | `είσαι` `[ˈise]` |
| `αυτός` `[afˈtos]` — он, мужской род | `είναι` `[ˈine]` |
| `αυτή` `[afˈti]` — она, женский род | `είναι` `[ˈine]` |
| `αυτό` `[afˈto]` — оно, средний род | `είναι` `[ˈine]` |
| `εμείς` `[eˈmis]` — мы | `είμαστε` `[ˈimaste]` |
| `εσείς` `[eˈsis]` — вы | `είστε / είσαστε` `[ˈiste / ˈisaste]` |
| `αυτοί` `[afˈti]` — они: мужской род; также смешанная группа людей | `είναι` `[ˈine]` |
| `αυτές` `[afˈtes]` — они: женский род | `είναι` `[ˈine]` |
| `αυτά` `[afˈta]` — они: средний род | `είναι` `[ˈine]` |

Например: два мужчины или мужчина и женщина — `αυτοί` `[afˈti]`;
две женщины — `αυτές` `[afˈtes]`; несколько книг — `αυτά` `[afˈta]`,
потому что `το βιβλίο` `[to viˈvlio]` — среднего рода.
Для предметов разного рода есть [отдельное правило](../reference/grammar/personal-pronouns.md#mixed-objects).

На слух `αυτή` `[afˈti]` — «она» и `αυτοί` `[afˈti]` — «они» совпадают;
различать их помогают написание и контекст.

- `Είμαι η Μαρία.` `[ˈime i maˈria]` — я Мария.
  `Με λένε Μαρία.` `[me ˈlene maˈria]` — меня зовут Мария; здесь без артикля.
- `Από πού είσαι;` `[aˈpo pu ˈise]` — откуда ты?
  `Από πού είστε;` `[aˈpo pu ˈiste]` — откуда вы?
  Один человек отвечает «я», даже если спросили вежливо на «вы».
- `Δεν είμαι…` `[ðen ˈime]` — я не…; отрицание перед глаголом.
- Форма третьего лица одинакова в обоих числах: не определять «он» или «они»
  только по глаголу.
- Род предмета выбирать по греческому артиклю, не по переводу.
