## Фото: упражнение 3 { #photo }

Перед упражнением: [глаголы АВ](../assets/mobile/core/card-17.png).

**Μαζί με τον διπλανό / τη διπλανή σου συμπληρώνετε τα κενά.**
`[maˈzi me ton ðiplaˈno / ti ðiplaˈni su simpliˈronete ta keˈna]` —
Вместе с соседом / соседкой заполняете пропуски. Дома можно выполнить самостоятельно.

Пункты **0–5**. В №0 одна форма уже дана; остаются **14 пропусков** во всём упражнении.
В скобках **ακούω / πάω / λέω** `[aˈkuo / ˈpao / ˈleo]` —
слушаю / иду / говорю. Нужно изменить форму, а не переписать словарную.

1. Найди подлежащее. Сестра и я — мы; мама и папа — они.
2. В ответе форма зависит от отвечающего: вопрос на «вы» сам по себе не означает ответ «мы».
3. **κύριε Νίκο** `[ˈkirie ˈniko]` — вежливое обращение к одному человеку, форма «вы».
4. **σε αγώνες μπάσκετ** `[se aˈɣones ˈbasket]` — на баскетбольные матчи;
   **στο θέατρο** `[sto ˈθeatro]` — в театр;
   **λέω όχι / ναι** `[ˈleo ˈohi / ne]` — говорю нет / да.

В №3 краткий ответ **Όχι, δεν …** `[ˈohi ðen]` не содержит местоимения:
подумай, отвечает вся группа «мы» или один человек «я». В групповом диалоге
естественно «мы»; отдельно стоящий ответ одного человека тоже грамматически возможен.
Ключа преподавателя для этого места нет; не принимай отсутствие местоимения за ошибку.

## Рабочий файл: с. 93, упражнение 3.0 { #words }

**Διαλέγω τη σωστή λέξη.** `[ðiaˈleɣo ti soˈsti ˈleksi]` — Выбираю правильное слово.
Преподаватель написал «упр. 30»; на странице напечатано **3.0**.
**Печатная с. 93 = PDF 9** нового рабочего файла.

Десять предложений, №1 — готовый пример: остаются **девять пропусков**.
Слова берём из рамки; проверяем не только перевод, но и число глагола,
время суток, сезон и смысл всей фразы.
**Πόσον καιρό…;** `[ˈposon keˈro]` — «Как долго / как давно…?»;
**κλασική μουσική** `[klasiˈki musiˈki]` — классическая музыка.
В №7 есть подсказка «раз в месяц»: выбери подходящую частотность.

На распечатке также видны 3.1–3.3 и подписи преподавателя: это соседи назначенного

## Видео 1: письменные ответы до 6:25 { #video-one }

Перед просмотром: [вопросы и ответы](../memory/questions-answers.md),
[семья и местоимения принадлежности](../assets/mobile/core/card-1.png).

[Открыть видео о знакомстве](https://www.youtube.com/watch?v=8VKdTtEm_EI).
Смотри **до 6:25**. Преподаватель просит записать полными предложениями сведения
об участниках; можно отмечать время появления человека.

| Что нужно узнать | Транскрипция | Перевод |
|---|---|---|
| Πώς τον / τη λένε; | `[pos ton / ti ˈlene]` | Как его / её зовут? |
| Από πού είναι; | `[aˈpo pu ˈine]` | Откуда он / она? |
| Πού μένουν τώρα; | `[pu ˈmenun ˈtora]` | Где они живут сейчас? |
| Τι δουλειά κάνουν; | `[ti ðuˈlya ˈkanun]` | Кем они работают? |

Последние два вопроса в сообщении преподавателя стоят во множественном числе.
Если описываешь одного участника, используй **μένει / κάνει** `[ˈmeni / ˈkani]` —
«живёт / делает», а не «они».

Шаблон для одного человека:
**Τον / Τη λένε … Είναι από … Τώρα μένει … Είναι … / Δουλεύει …**
`[ton / ti ˈlene … ˈine aˈpo … ˈtora ˈmeni … ˈine … / ðuˈlevi …]` —
Его / её зовут… Он / она из… Сейчас живёт… Он / она… / Работает…

Не достраивай сведения, которых человек не сказал. Удобная запись:

| Отметка времени | Имя | Откуда | Где живёт сейчас | Работа |
|---|---|---|---|---|
| … | … | … | … | … |

После заполнения таблицы преврати строки в полные предложения.
