## С. 35, №6 — прилагательное и существительное { #accusative }

**Συμπληρώνω με τα ουσιαστικά και τα επίθετα στον σωστό τύπο.** [simpliˈrono me ta usiastiˈka ke ta eˈpiθeta ston soˈsto ˈtipo] — Вставляю существительные и прилагательные в правильной форме.

После примера девять пунктов. Сначала установи роль группы, затем согласуй прилагательное с существительным. В №3 группа сама является подлежащим. В №5 перед пропуском уже стоит предлог, а в №6 между **σε** [se] и артиклем стоит указательное слово. Во втором пропуске №6 форму подсказывает глагол «пью». ## С. 36, №8 — одна фотография { #photo }

Выбери одну из четырёх картинок. Кратко опиши, кого видишь, где он или она находится и что делает. Можно начать с **Στην εικόνα βλέπω έναν άντρα / μία γυναίκα.** [stin iˈkona ˈvlepo ˈenan ˈandra / ˈmia yiˈneka] — На картинке я вижу мужчину / женщину. Для первых фраз хватит слов из выбранной рамки.
