## С. 58: рассказ по карточке { #profile }

Образец — Никос. Самостоятельно написать про Александера, Айше, Карло,
Светлану и затем про себя. Для каждого:

1. Откуда человек: имя + «он / она из…».
2. Национальность: выбрать мужскую или женскую форму.
3. На каких языках и насколько хорошо говорит.
4. Что изучает в вузе.
5. Где живёт: переписать адрес и район из карточки.
6. Телефон — только если указан. У Айше в карточке номера нет, не выдумываем.

Опоры для глаголов:

| О другом человеке | О себе |
|---|---|
| `είναι` `[ˈine]` — он / она есть | `είμαι` `[ˈime]` — я есть |
| `μιλάει` `[miˈlai]` — говорит | `μιλάω` `[miˈlao]` — говорю |
| `σπουδάζει` `[spuˈðazi]` — изучает в вузе | `σπουδάζω` `[spuˈðazo]` — изучаю в вузе |
| `μένει` `[ˈmeni]` — живёт | `μένω` `[ˈmeno]` — живу |

Если человек совсем не говорит на языке, нужно отрицание:
`δεν μιλάει καθόλου` `[ðen miˈlai kaˈθolu]` — совсем не говорит.
Не заменяй «не говорит совсем» на «говорит немного».

Можно сначала пользоваться карточкой. Затем закрой её и проверь окончания
самостоятельно. [Разобранный образец и слова](../lessons/lesson-06-current.md#profile).

## Подготовка к диктанту

- Числа **0–100**: [0–10](../reference/numbers-0-10.md),
  [11–100](../reference/numbers-11-100.md).
- Глаголы группы А с печатной с. **40 / PDF-с. 34**:
  `μένω` `[ˈmeno]` — живу; `μαθαίνω` `[maˈθeno]` — учу;
  `σπουδάζω` `[spuˈðazo]` — изучаю в вузе;
  `διαβάζω` `[ðiaˈvazo]` — читаю; `γράφω` `[ˈɣrafo]` — пишу;
  `ξέρω` `[ˈksero]` — знаю; `έχω` `[ˈeho]` — имею;
  `θέλω` `[ˈθelo]` — хочу; `κάνω` `[ˈkano]` — делаю;
  `δουλεύω` `[ðuˈlevo]` — работаю.

Повтори [шесть окончаний группы А](../reference/grammar/present-tense-a.md).
Новая группа Β1 нужна в упражнениях, но в формулировке диктанта отдельно
названы именно числа и группа А. На странице курса также просят прислать
написанные диктанты; отправка в этой домашке не отмечена как выполненная.
