## Что освоить

- Сначала выбирать прилагательное по смыслу, затем согласовывать его по роду.
- Описывать предмет словосочетанием и полным предложением.
- Различать «новый», «молодой», «старый»; «маленький», «младший», «старший».
- Соединять знакомые вопросы в беседу о себе, учёбе, работе и семье.

## Разбор

### Два решения: значение и форма { #agreement }

В задании нельзя ограничиться знакомым переводом. Сначала выясни, какой признак
подтверждается второй фразой; затем найди существительное и выбери его род.

**Αυτή η τσάντα είναι φτηνή. Κάνει μόνο δέκα ευρώ.**
`[afˈti i ˈtsanda ˈine ftiˈni ˈkani ˈmono ˈðeka evˈro]` —
Эта сумка дешёвая. Она стоит всего десять евро.

Цена подсказывает «дешёвая», а не «модная». Сумка — женского рода,
поэтому нужна форма **φτηνή** `[ftiˈni]`, не мужская **φτηνός** `[ftiˈnos]`.
Здесь **κάνει** `[ˈkani]` означает «стоит», хотя базовое значение глагола — «делает».

| Проверка | Что делать | Пример |
|---|---|---|
| Смысл | Прочитай обе фразы, не только пропуск | **μόνο δέκα ευρώ** `[ˈmono ˈðeka evˈro]` — всего 10 евро |
| Род | Найди главное существительное и его артикль | **η τσάντα** `[i ˈtsanda]` — сумка, женский род |
| Форма | Замени окончание прилагательного | **φτηνός → φτηνή** `[ftiˈnos → ftiˈni]` — дешёвый → дешёвая |

Род принадлежит предмету, не говорящему. После «быть» он сохраняется:
**Το ποδήλατο είναι ωραίο.** `[to poˈðilato ˈine oˈreo]` — Велосипед отличный.
Велосипед по-гречески среднего рода, даже если о нём говорит мужчина.

Две модели и исключения — в [правиле прилагательных](../reference/grammar/adjectives-e1-e2.md).
Коротко: женское **-η** `[-i]` у основы на согласную, **-α** `[-a]` у основы на гласную;
среднее **-ο** `[-o]`. Это модели изученных прилагательных, не правило для всех слов языка.
Особые формы вроде **φρέσκια** `[ˈfreskya]` — свежая — вспоминаем целиком.

### Словосочетания из упражнения 11 { #phrases }

В конспекте разобрана вся таблица, не только подписанные переводы.
Прилагательное перед существительным согласуется так же, как после «быть».

| Словосочетание | Произношение | Значение |
|---|---|---|
| κρύος καφές | `[ˈkrios kaˈfes]` | холодный кофе |
| νέος άντρας | `[ˈneos ˈandras]` | молодой мужчина |
| καλή μέρα | `[kaˈli ˈmera]` | хороший день |
| φτηνή εφημερίδα | `[ftiˈni efimeˈriða]` | дешёвая газета |
| ωραίο ποδήλατο | `[oˈreo poˈðilato]` | отличный / красивый велосипед |
| όμορφη κοπέλα | `[ˈomorfi koˈpela]` | красивая девушка |
| ψηλό αγόρι | `[psiˈlo aˈɣori]` | высокий мальчик |
| κακός καθηγητής | `[kaˈkos kaθiyiˈtis]` | плохой преподаватель |
| ζεστή σοκολάτα | `[zeˈsti sokoˈlata]` | горячий шоколад |
| καθαρή τάξη | `[kaθaˈri ˈtaksi]` | чистый класс |
| μικρός αδελφός | `[miˈkros aðelˈfos]` | маленький / младший брат |
| καινούργιο μάθημα | `[keˈnuryo ˈmaθima]` | новый урок |
| βρώμικο αυτοκίνητο | `[ˈvromiko aftoˈkinito]` | грязная машина |
| κοντή γυναίκα | `[koˈndi yiˈneka]` | невысокая женщина |

Не переносим русский род: шоколад здесь женского рода, мальчик — среднего,
машина — среднего. Упражнение тренирует именно греческое согласование.

### Полные предложения из упражнения 12 { #sentences }

| Предложение с произношением | Перевод |
|---|---|
| Η τυρόπιτά μου είναι φρέσκια. `[i tiˈropiˈta mu ˈine ˈfreskya]` | Мой пирог с сыром свежий. |
| Το σπίτι σας είναι πολύ ακριβό. `[to ˈspiti sas ˈine poˈli akriˈvo]` | Ваш дом очень дорогой. |
| Η μηχανή μου δεν είναι καινούργια. `[i mihaˈni mu ðen ˈine keˈnurya]` | Мой мотоцикл не новый. |
| Ο αναπτήρας είναι φτηνός. `[o anapˈtiras ˈine ftiˈnos]` | Зажигалка дешёвая. |
| Το αυτοκίνητό μας είναι βρώμικο. `[to aftoˈkiniˈto mas ˈine ˈvromiko]` | Наша машина грязная. |
| Η τσάντα της είναι μικρή. `[i ˈtsanda tis ˈine miˈkri]` | Её сумка маленькая. |
| Η άσκηση τρία δεν είναι δύσκολη. `[i ˈaskisi ˈtria ðen ˈine ˈðiskoli]` | Упражнение три не трудное. |
| Το μάθημα εννιά είναι εύκολο. `[to ˈmaθima eˈnya ˈine ˈefkolo]` | Урок девять лёгкий. |
| Η συμμαθήτριά μου είναι πολύ έξυπνη. `[i simaˈθitriˈa mu ˈine poˈli ˈeksipni]` | Моя одноклассница очень умная. |

В последнем примере преподаватель также написал **ψηλή** `[psiˈli]` — высокая:
это другой подходящий по роду признак, а не перевод слова «умная».

**μου / σας / της / μας** `[mu / sas / tis / mas]` — мой / ваш / её / наш.
Они показывают владельца; окончание прилагательного всё равно определяется предметом.
В длинных словах перед безударным «мой / наш» может появляться дополнительный тонос,
как в примерах с пирогом, машиной и одноклассницей. Это не меняет род или значение.

### Значение зависит от того, что описываем { #meaning }

- **νέος / νέα / νέο** `[ˈneos / ˈnea / ˈneo]` — молодой о человеке,
  новый в другом подходящем контексте. Возраст учительницы — подсказка к «молодая»,
  а не к «новая»: её недавно приняли на работу или она молода — разные факты.
- **καινούργιος / καινούργια / καινούργιο** `[keˈnuryos / keˈnurya / keˈnuryo]` —
  новый; **παλιός / παλιά / παλιό** `[paˈlyos / paˈlya / paˈlyo]` — старый, прежний.
  В домашке машина используется 15 лет: это подсказка о возрасте вещи, не о скорости.
- **μικρός αδελφός** `[miˈkros aðelˈfos]` — маленький или младший брат;
  **μεγάλος αδελφός** `[meˈɣalos aðelˈfos]` — большой или старший брат.
  Контекст семьи позволяет говорить о старшинстве, не только о размере.
- **ψηλός / κοντός** `[psiˈlos / koˈndos]` — высокий / низкий по росту;
  **μαύρος / μαύρη / μαύρο** `[ˈmavros / ˈmavri / ˈmavro]` — чёрный по цвету.
  «Тёмный» и «чёрный» не полностью взаимозаменяемы.

В упражнении 13 повторяются пары: дорогой — дешёвый, хороший — плохой,
большой — маленький, красивый — некрасивый, трудный — лёгкий, высокий — низкий,
толстый — тонкий, горячий — холодный, новый — старый, молодой — пожилой,
чистый — грязный, красивый — некрасивый, бедный — богатый.
[Тройки и произношение](../lessons/lesson-11-current.md#opposites).
В упражнении 10 отдельно закреплены женские окончания первых пяти слов на **-η** `[-i]`
и следующих пяти на **-α** `[-a]`; не выбирай окончание по русскому переводу.

### «Этот предмет» и его признак { #this-object }

В дополнительных заданиях указательное слово тоже имеет род существительного.
Это не просто «он / она»: сочетание с артиклем означает «этот / эта / это».

| Пример с произношением | Перевод |
|---|---|
| Αυτό το σπίτι είναι άσχημο. `[afˈto to ˈspiti ˈine ˈashimo]` | Этот дом некрасивый. |
| Αυτός ο αναπτήρας είναι μικρός. `[afˈtos o anapˈtiras ˈine miˈkros]` | Эта зажигалка маленькая. |
| Αυτή η καρέκλα είναι καινούργια. `[afˈti i kaˈrekla ˈine keˈnurya]` | Этот стул новый. |
| Αυτός ο υπολογιστής είναι παλιός. `[afˈtos o ipoloyiˈstis ˈine paˈlyos]` | Этот компьютер старый. |
| Αυτή η ομπρέλα είναι μαύρη. `[afˈti i oˈbrela ˈine ˈmavri]` | Этот зонт чёрный. |
| Αυτή η μηχανή είναι όμορφη. `[afˈti i mihaˈni ˈine ˈomorfi]` | Этот мотоцикл красивый. |
| Αυτό το πιάτο είναι καθαρό. `[afˈto to ˈpyato ˈine kaθaˈro]` | Эта тарелка чистая. |
| Αυτό το ρολόι είναι ακριβό. `[afˈto to roˈloi ˈine akriˈvo]` | Эти часы дорогие. |
| Αυτός ο άντρας είναι κοντός. `[afˈtos o ˈandras ˈine koˈndos]` | Этот мужчина невысокий. |
| Αυτό το θρανίο είναι βρώμικο. `[afˈto to θraˈnio ˈine ˈvromiko]` | Эта парта грязная. |

Русское «часы» — множественное, греческое слово в этом предложении — единственное.
Согласовывай с греческим словом. Не убирай артикль между указательным словом и существительным.

### Ролевая беседа: о себе и семье { #conversation }

Учебник предлагает сыграть Анну и Клаудию, а не пересказать чужую биографию от третьего лица.
**Η Άννα και η Κλαούντια κάνουν μεταπτυχιακό στη Φιλοσοφική Σχολή και μιλάνε στο facebook.**
`[i ˈana ke i klaˈundia ˈkanun metaptihiaˈko sti filosofiˈki shoˈli ke miˈlane sto ˈfeisbuk]` —
Анна и Клаудия учатся в магистратуре на философском факультете и разговаривают в Facebook.
Название факультета — название подразделения университета, не утверждение, что обе изучают философию.

Ниже связные варианты по данным ролей; это учебная сборка, не записанный в источнике диалог.

**Είμαι η Άννα. Είμαι Ελληνίδα, από τη Θεσσαλονίκη. Μένω στο Παγκράτι.**
`[ˈime i ˈana ˈime eliˈniða aˈpo ti θesaloˈniki ˈmeno sto paŋˈgrati]` —
Я Анна. Я гречанка, из Салоник. Живу в Панграти.

**Είμαι φιλόλογος. Είμαι είκοσι τριών χρονών. Έχω δύο αδέρφια. Έχω σχέση.**
`[ˈime fiˈloloɣos ˈime ˈikosi triˈon hroˈnon ˈeho ˈðio aˈðerfya ˈeho ˈshesi]` —
Я филолог. Мне 23 года. У меня двое братьев и/или сестёр. Я в отношениях.

**Είμαι η Κλαούντια. Είμαι Ιταλίδα, από τη Ρώμη. Μένω στου Ζωγράφου.**
`[ˈime i klaˈundia ˈime itaˈliða aˈpo ti ˈromi ˈmeno stu zoˈɣrafu]` —
Я Клаудия. Я итальянка, из Рима. Живу в районе Зографу.

**Είμαι ψυχολόγος. Είμαι είκοσι έξι χρονών. Είμαι μοναχοπαίδι και είμαι αρραβωνιασμένη.**
`[ˈime psihoˈloɣos ˈime ˈikosi ˈeksi hroˈnon ˈime monahoˈpeði ke ˈime aravonyaˈsmeni]` —
Я психолог. Мне 26 лет. Я единственный ребёнок в семье и помолвлена.

Форма **στου Ζωγράφου** `[stu zoˈɣrafu]` дана в учебнике для этого названия района.
Не строй по ней правило для всех городов: **στη Λεμεσό** `[sti lemeˈso]` — в Лимасоле.

| Вопрос / модель из пометок с произношением | Значение и выбор |
|---|---|
| Πού μένεις; `[pu ˈmenis]` | Где ты живёшь? Не спрашивает происхождение. |
| Τι δουλειά κάνεις; `[ti ðuˈlya ˈkanis]` | Кем ты работаешь? Профессия, не адрес работы. |
| Δουλεύω ως φιλόλογος. `[ðuˈlevo os fiˈloloɣos]` | Работаю филологом: **ως** `[os]` — в качестве. |
| Είσαι παντρεμένη; `[ˈise pandreˈmeni]` | Ты замужем? Обращение к женщине. |
| Έχεις αδέρφια; `[ˈehis aˈðerfya]` | У тебя есть братья или сёстры? Не только братья. |
| Έχω τρεις αδερφούς. `[ˈeho tris aðerˈfus]` | У меня три брата. Именно мужчины. |
| Έχω τρία αδέρφια. `[ˈeho ˈtria aˈðerfya]` | У меня трое братьев и/или сестёр. Общее слово среднего рода. |
| Έχω ένα αγόρι και ένα κορίτσι. `[ˈeho ˈena aˈɣori ke ˈena koˈritsi]` | У меня мальчик и девочка; в разговоре о детях — сын и дочь. |

**Είμαι φιλόλογος.** `[ˈime fiˈloloɣos]` — Я филолог — короче и тоже правильно.
Перед профессией после «быть» артикль не нужен, но в словаре учим
**ο / η φιλόλογος** `[o / i fiˈloloɣos]`: слово одинаковое, род показывает артикль.
Полный набор знакомых вопросов — [в сквозном сборнике](../memory/questions-answers.md).

### Слова-подсказки в письменной домашке { #homework-words }

| Фрагмент с произношением | По словам / смысл |
|---|---|
| Οδηγώ το αυτοκίνητο αυτό δεκαπέντε χρόνια. `[oðiˈɣo to aftoˈkinito afˈto ðekaˈpende ˈhronya]` | Вожу эту машину 15 лет. **οδηγώ** `[oðiˈɣo]` — я вожу. |
| Σε πέντε λεπτά μόνο πηγαίνω στο κέντρο. `[se ˈpende leˈpta ˈmono piˈyeno sto ˈkendro]` | Всего за пять минут добираюсь до центра. **σε** `[se]` здесь относится ко времени. |
| Πάμε βόλτα στο πάρκο; `[ˈpame ˈvolta sto ˈparko]` | Пойдём гулять в парк? Не обычное сообщение «мы идём», а предложение. |
| Είμαστε είκοσι φοιτητές μέσα και κάνουμε μάθημα. `[ˈimaste ˈikosi fitiˈtes ˈmesa ke ˈkanume ˈmaθima]` | Внутри нас двадцать студентов, и у нас занятие. **μέσα** `[ˈmesa]` — внутри. |
| Το παντελόνι τώρα είναι… `[to pandeˈloni ˈtora ˈine]` | Брюки сейчас… Греческое существительное единственного числа, среднего рода. |

Не путай **το λεπτό** `[to leˈpto]` — минуту — с **λεπτό** `[leˈpto]` —
тонкое: одинаковое звучание и ударение, но разная роль. Различаем по контексту.
Новый глагол «водить» здесь нужен для понимания задания; его отдельное спряжение не задано.

## Практика перед домашкой

1. Повтори [короткую памятку](../memory/lesson-12-current.md), затем назови род пяти предметов
   и придумай к каждому признак. Проверь и значение, и окончание.
2. Открой [слова урока 12](../training/vocabulary.md?lesson=12). «Новые слова» не включают
   старые прилагательные; для них включи «С повторением». Сначала основные, потом весь набор.
3. Проговори рассказ о себе по схеме: имя → происхождение → жильё → работа / учёба → семья.
   Используй собственные факты, не возраст и профессию персонажа учебника.
4. Для аудирования сначала слушай без текста и отмечай, что услышал о каждом человеке.
   [Плеер и порядок проверки](../homework/lesson-12-current.md#listening).
