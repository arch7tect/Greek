# Урок 07 — языки, профессии и семья

[Карточка A4](../assets/print/lesson-07-study-card-a4.pdf){ .md-button }
[Карточки для телефона](../assets/mobile/lesson-07-phone-cards.pdf){ .md-button }

## Что освоить

- Рассказать, на каких языках человек говорит и кем работает.
- Выбрать форму «говорить», даже если вместо местоимения стоят два имени.
- Назвать близких и объяснить, кто кому приходится родственником.
- Различать «он / она» и «его / её»: кто действует и чья это семья.

## Разбор

### 1. О человеке: кто, на каком языке, кем работает { #people }

Три вопроса требуют разных ответов. Национальность — не язык, а профессия —
не действие «работать». В упражнении с персонажами Вера — болгарка,
говорит на трёх языках и работает парикмахером.

| Вопрос | Полный ответ | Значение |
|---|---|---|
| `Ποια είναι αυτή;` `[pia ˈine afˈti]` | `Είναι η Βέρα.` `[ˈine i ˈvera]` | Кто она? — Это Вера. |
| `Είναι Ελληνίδα;` `[ˈine eliˈniða]` | `Όχι, είναι Βουλγάρα.` `[ˈohi ˈine vulˈɣara]` | Она гречанка? — Нет, болгарка. |
| `Τι γλώσσα μιλάει;` `[ti ˈɣlosa miˈlai]` | `Μιλάει βουλγαρικά, αγγλικά και ελληνικά.` `[miˈlai vulɣariˈka aŋgliˈka ke eliniˈka]` | На каком языке говорит? — На болгарском, английском и греческом. |
| `Δουλεύει;` `[ðuˈlevi]` | `Ναι, είναι κομμώτρια.` `[ne ˈine koˈmotria]` | Работает? — Да, она парикмахер. |
| `Τι δουλειά κάνει;` `[ti ðuˈlya ˈkani]` | `Είναι κομμώτρια.` `[ˈine koˈmotria]` | Кем работает? — Парикмахером. |

В последнем вопросе `τι` `[ti]` — «какую», `δουλειά` `[ðuˈlya]` — «работу»,
`κάνει` `[ˈkani]` — «делает». Целиком — «Кем он / она работает?».
В ответе с профессией после «быть» обычно **нет артикля**:
`Είναι γιατρός.` `[ˈine yaˈtros]` — Он / она врач.
Но при назывании конкретного человека артикль нужен:
`Είναι η Βέρα.` `[ˈine i ˈvera]` — Это Вера.

Об одном мужчине спрашиваем `Ποιος είναι αυτός;` `[pios ˈine afˈtos]` —
«Кто он?», о женщине — `Ποια είναι αυτή;` `[pia ˈine afˈti]` — «Кто она?».
Форма глагола «есть» при этом одна: `είναι` `[ˈine]`.

### 2. Как выбрать форму «говорить» { #speak }

| Кто | Форма | Перевод |
|---|---|---|
| `εγώ` `[eˈɣo]` | μιλ**άω** `[miˈlao]` | я говорю |
| `εσύ` `[eˈsi]` | μιλ**άς** `[miˈlas]` | ты говоришь |
| `αυτός / αυτή / αυτό` `[afˈtos / afˈti / afˈto]` | μιλ**άει** `[miˈlai]` | он / она / оно говорит |
| `εμείς` `[eˈmis]` | μιλ**άμε** `[miˈlame]` | мы говорим |
| `εσείς` `[eˈsis]` | μιλ**άτε** `[miˈlate]` | вы говорите |
| `αυτοί / αυτές / αυτά` `[afˈti / afˈtes / afˈta]` | μιλ**άνε** `[miˈlane]` | они говорят |

Это один удобный ряд для запоминания. Варианты `μιλώ` `[miˈlo]`,
`μιλά` `[miˈla]`, `μιλούν` `[miˈlun]` тоже правильные;
[полная модель Β1](../reference/grammar/present-tense-b1.md).

В домашнем упражнении сначала ищи **действующее лицо**, не название языка:

- Два имени → «они». Даже если обе женщины, окончание глагола не меняется.
- «Я и ещё кто-то» → «мы», потому что говорящий входит в группу.
- Обращение «господин…» → вежливое «вы», хотя человек один.
- Отрицание не меняет спряжение: сначала «не», затем та же личная форма.

`Εγώ και η Μαρία μιλάμε ελληνικά.`
`[eˈɣo ke i maˈria miˈlame eliniˈka]` — Мы с Марией говорим по-гречески.
Здесь нельзя брать «они»: **я** тоже говорю.

`Κύριε Γεωργίου, μιλάτε τουρκικά;`
`[ˈkirie yeorˈyiu miˈlate turkiˈka]` — Господин Георгиу, Вы говорите по-турецки?
Это обращение к собеседнику, а не рассказ «он говорит».

### 3. Страна, национальность и степень владения языком { #languages }

| О чём говорим | Пример |
|---|---|
| Происхождение: из какой страны | `Είναι από τη Γερμανία.` `[ˈine aˈpo ti yermaˈnia]` — Он / она из Германии. |
| Национальность: кто | `Είναι Γερμανός.` `[ˈine yermaˈnos]` — Он немец. |
| Язык: на каком говорит | `Μιλάει γερμανικά.` `[miˈlai yermaniˈka]` — Он / она говорит по-немецки. |

Национальность согласуется с человеком, название языка не меняется в
зависимости от пола говорящего. Страны и национальности пишем с большой буквы,
языки — с маленькой. [Таблица стран, мужских и женских форм](lesson-06-current.md#nationalities).

В упражнении №9 конспекта дополнительно встречаются
`Πολωνή / Πολωνέζα` `[poloˈni / poloˈneza]` — полька,
`πολωνικά` `[poloniˈka]` — по-польски и `ιαπωνικά` `[iaponiˈka]` — по-японски.
Вариант `γιαπωνέζικα` `[yapoˈnezika]`, знакомый по другой таблице, тоже означает
японский язык. Не нужно из-за этого менять ответ «говорит».

| Выражение | Значение |
|---|---|
| `τέλεια` `[ˈtelia]` | отлично, прекрасно |
| `πολύ καλά` `[poˈli kaˈla]` | очень хорошо |
| `αρκετά καλά` `[arkeˈta kaˈla]` | достаточно хорошо |
| `καλά` `[kaˈla]` | хорошо |
| `έτσι κι έτσι` `[ˈetsi ki ˈetsi]` | так себе |
| `όχι πολύ καλά` `[ˈohi poˈli kaˈla]` | не очень хорошо |
| `λίγο / πολύ λίγο` `[ˈliɣo / poˈli ˈliɣo]` | немного / совсем немного |
| `καθόλου` `[kaˈθolu]` | совсем, нисколько — в отрицательном ответе |

Проценты на учебной шкале — условные подсказки, не результат теста и не уровни
владения языком. «Так себе» оценивает **качество**, «немного» — **объём** умения.

`Μιλάω λίγο ισπανικά.` `[miˈlao ˈliɣo ispaniˈka]` и
`Μιλάω ισπανικά λίγο.` `[miˈlao ispaniˈka ˈliɣo]` — оба варианта понятны:
говорю немного по-испански. Для нейтрального ответа удобно ставить оценку
перед названием языка.

`Όχι, δεν μιλάω καθόλου γαλλικά.`
`[ˈohi ðen miˈlao kaˈθolu ɣaliˈka]` — Нет, я совсем не говорю по-французски.
Первое «нет» отвечает на вопрос, а **«не» перед глаголом** отрицает действие.
Не заменяй эту фразу утвердительным «говорю совсем».

### 4. Профессии и пять групп слов { #jobs }

В упражнении №6 нужно разложить слова по смыслу, а не по окончанию:
язык, страна, адрес, профессия, семья. Например, «мать» и «учительница» обе
женского рода, но первая — родственница, вторая — профессия.

| Категория | Пример | Перевод |
|---|---|---|
| `η γλώσσα` `[i ˈɣlosa]` — язык | `ισπανικά` `[ispaniˈka]` | по-испански |
| `η χώρα` `[i ˈhora]` — страна | `η Σουηδία` `[i suiˈðia]` | Швеция |
| `ο δρόμος` `[o ˈðromos]` — дорога, улица | `η οδός` `[i oˈðos]`, `η πλατεία` `[i plaˈtia]` | улица, площадь |
| `το επάγγελμα` `[to eˈpaŋgelma]` — профессия | `ο γιατρός` `[o yaˈtros]` | врач |
| `η οικογένεια` `[i ikoˈyenia]` — семья | `η μητέρα` `[i miˈtera]` | мать |

Заголовок «дорога» в задании объединяет **адреса**, в том числе площадь и
название улицы с номером дома. Не нужно считать их профессиями или странами.

| Профессия из материалов | Перевод |
|---|---|
| `ο / η γιατρός` `[o / i yaˈtros]` | врач — мужчина / женщина |
| `ο / η γραμματέας` `[o / i ɣramaˈteas]` | секретарь — мужчина / женщина |
| `ο διπλωμάτης` `[o ðiploˈmatis]` | дипломат |
| `η δασκάλα` `[i ðaˈskala]` | учительница |
| `ο μάγειρας` `[o ˈmaɣiras]` | повар |
| `ο αρχιτέκτονας` `[o arhiˈtektonas]` | архитектор |
| `η κομμώτρια` `[i koˈmotria]` | парикмахер |
| `η πωλήτρια` `[i poˈlitria]` | продавщица |
| `ο ξυλουργός` `[o ksilurˈɣos]` | столяр |
| `η κτηνίατρος` `[i ktiniˈatros]` | ветеринар — женщина |
| `η γυμνάστρια` `[i yimˈnastria]` | тренер, преподаватель физкультуры |

Артикль важнее последней буквы. «Врач» и «секретарь» могут обозначать мужчину
или женщину без изменения самого существительного. Учим слово вместе с
артиклем; [общие правила рода](../reference/grammar/nominative-articles.md).

### 5. Семья: кто кому приходится { #family }

На схеме семейное дерево. Горизонтальная линия соединяет пару, вертикальная
ведёт к детям. Рассказ ведёт Панос: его родители — Василис и Христина,
сестра — Эфи, девушка — Элени. Георгиос и Мария — родители Христины,
а для Паноса и Эфи они дедушка и бабушка. Эфи замужем за Александросом.

| Слово | Перевод | Несколько человек |
|---|---|---|
| `ο πατέρας` `[o paˈteras]` | отец | `οι πατέρες` `[i paˈteres]` |
| `η μητέρα` `[i miˈtera]` | мать | `οι μητέρες` `[i miˈteres]` |
| `ο γιος` `[o yos]` | сын | `οι γιοι` `[i yi]` |
| `η κόρη` `[i ˈkori]` | дочь | `οι κόρες` `[i ˈkores]` |
| `ο αδελφός` `[o aðelˈfos]` | брат | `οι αδελφοί` `[i aðelˈfi]` |
| `η αδελφή` `[i aðelˈfi]` | сестра | `οι αδελφές` `[i aðelˈfes]` |
| `ο παππούς` `[o paˈpus]` | дедушка | `οι παππούδες` `[i paˈpuðes]` |
| `η γιαγιά` `[i yaˈya]` | бабушка | `οι γιαγιάδες` `[i yaˈyaðes]` |
| `ο εγγονός` `[o eɣoˈnos]` | внук | `οι εγγονοί` `[i eɣoˈni]` |
| `η εγγονή` `[i eɣoˈni]` | внучка | `οι εγγονές` `[i eɣoˈnes]` |

Собирательные названия: `οι γονείς` `[i ɣoˈnis]` — родители,
`τα παιδιά` `[ta peˈðya]` — дети, `τα αδέλφια` `[ta aˈðelfya]` — братья и сёстры,
`τα εγγόνια` `[ta eˈɣonya]` — внуки обоих полов.
Разговорные `ο μπαμπάς` `[o baˈbas]` и `η μαμά` `[i maˈma]` — папа и мама.

Сравни родство и отношения:

- `ο άντρας μου` `[o ˈandras mu]` — мой муж; без контекста слово может значить «мужчина».
- `η γυναίκα μου` `[i yiˈneka mu]` — моя жена; само слово также значит «женщина».
- `η κοπέλα μου` `[i koˈpela mu]` — моя девушка, не обязательно жена.
- `ο φίλος μου` `[o ˈfilos mu]` — мой друг или мой парень: решает контекст.
- `ο σύντροφός μου / η σύντροφός μου` `[o ˈsindroˈfos mu / i ˈsindroˈfos mu]` — мой партнёр / моя партнёрша.

`Είναι παντρεμένος.` `[ˈine pandreˈmenos]` — Он женат.
`Είναι παντρεμένη.` `[ˈine pandreˈmeni]` — Она замужем.
Здесь меняется **прилагательное**, а не глагол «есть».

### 6. «Мой», «его» и «её»: о ком сейчас речь { #possessives }

Схема: **артикль + родственник + чей**. Короткое слово ставится после
существительного: `η αδελφή μου` `[i aðelˈfi mu]` — моя сестра.

| Чей / чья / чьи | Форма | Пример |
|---|---|---|
| мой | `μου` `[mu]` | `ο πατέρας μου` `[o paˈteras mu]` — мой отец |
| твой | `σου` `[su]` | `η μητέρα σου` `[i miˈtera su]` — твоя мать |
| его | `του` `[tu]` | `η αδελφή του` `[i aðelˈfi tu]` — его сестра |
| её | `της` `[tis]` | `ο αδελφός της` `[o aðelˈfos tis]` — её брат |
| наш | `μας` `[mas]` | `τα παιδιά μας` `[ta peˈðya mas]` — наши дети |
| ваш | `σας` `[sas]` | `η κόρη σας` `[i ˈkori sas]` — ваша дочь |
| их | `τους` `[tus]` | `τα εγγόνια τους` `[ta eˈɣonya tus]` — их внуки |

Выбираем форму по **человеку, о чьей семье говорим**, а не по родственнику.
У Паноса сестра — женщина, но «его сестра» всё равно с `του` `[tu]`.
У Эфи брат — мужчина, но «её брат» с `της` `[tis].

`Η Έφη είναι η αδελφή του.` `[i ˈefi ˈine i aðelˈfi tu]` — Эфи — его сестра.
`Ο Πάνος είναι ο αδελφός της.` `[o ˈpanos ˈine o aðelˈfos tis]` — Панос — её брат.
Так меняется точка отсчёта в упражнении №21: сначала говорим о Паносе,
затем об Эфи, Христине, Василисе, Георгиосе и Элени.

«Она» — `αυτή` `[afˈti]`, «её» после существительного — `της` `[tis]`.
Не подставляй местоимение «она» вместо «её».
Подробности и дополнительное ударение —
[в правиле принадлежности](../reference/grammar/personal-pronouns.md#possession).

### 7. Понимаем рассказ о семье { #reading }

Сначала найди в рассказе действующее лицо, потом глагол и связь с другими
людьми. Не все глаголы имеют одну модель спряжения.

| Фраза | Перевод и разбор |
|---|---|
| `Οι γονείς μου έχουν δύο παιδιά.` `[i ɣoˈnis mu ˈehun ˈðio peˈðya]` | У моих родителей двое детей. «Родители» → «они имеют». |
| `Μένουν στη Θεσσαλονίκη.` `[ˈmenun sti θesaloˈniki]` | Они живут в Салониках. В рассказе это Эфи и Александрос. |
| `Δεν είμαι παντρεμένος.` `[ðen ˈime pandreˈmenos]` | Я не женат. Панос говорит о себе. |
| `Περνάμε ωραία.` `[perˈname oˈrea]` | Хорошо проводим время. Не буквальное «проходим красиво». |
| `Γελάμε πολύ.` `[yeˈlame poˈli]` | Много смеёмся. |
| `Αγαπάνε πολύ τα εγγόνια τους.` `[aɣaˈpane poˈli ta eˈɣonya tus]` | Они очень любят своих внуков. «Их» относится к бабушке и дедушке. |
| `Η γιαγιά μου μαγειρεύει πολύ ωραία.` `[i yaˈya mu mayiˈrevi poˈli oˈrea]` | Моя бабушка очень вкусно готовит. |
| `Συζητάμε πολύ.` `[siziˈtame poˈli]` | Мы много беседуем, обсуждаем. |

В упражнении №22 требуется вернуться к тексту и выбрать слово по смыслу:
семейное положение, отношения, готовка, разговор. Например,
`έχει σχέση` `[ˈehi ˈshesi]` — состоит в отношениях; это не «имеет родственника».

### 8. Песня для узнавания знакомых слов

В конспекте есть песня о признании в любви на разных языках.
Знакомые опоры: `αγαπάω` `[aɣaˈpao]` — люблю,
`η αγάπη` `[i aˈɣapi]` — любовь, `η γλώσσα` `[i ˈɣlosa]` — язык.
Полезно узнавать названия языков на слух. Формы других времён из песни
не нужно автоматически добавлять к изучаемому спряжению настоящего времени.

## Практика перед домашкой

1. Назови формы «говорить» для «я», «мы», «две женщины», вежливого «Вы».
2. Скажи о Вере: кто она по национальности, какие языки знает, кем работает.
3. Посмотри на семейное дерево и объясни, кто Эфи для Паноса и Панос для Эфи.
4. Расскажи о двух родственниках: имя, родство, профессия, языки.
