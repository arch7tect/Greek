## Что освоить

Рассказывать, откуда человек, какой он национальности, где живёт, что изучает
и на каких языках говорит. Различать страну, национальность и язык; выбирать
мужскую или женскую форму национальности. Новая грамматика — глаголы типа Β1
на **-άω** `[ˈao]`, прежде всего `μιλάω` `[miˈlao]` — «говорю».

Для повторения достаточно **четырёх карточек**. Таблицы стран и подробный
диалог ниже нужны для понимания и работы с упражнениями — не нужно за один
подход заучивать каждую строку.

## Разбор

### 1. Четыре разных сведения о человеке { #country-person-language }

Не выбирай слово по русскому «из / на / по» отдельно от смысла вопроса.
Сначала реши, **что именно сообщаешь**.

| О чём говорим | Пример | Перевод |
|---|---|---|
| Страна происхождения | `Είμαι από τη Ρωσία.` `[ˈime aˈpo ti roˈsia]` | Я из России. |
| Национальность | `Είμαι Ρώσος.` `[ˈime ˈrosos]` / `Είμαι Ρωσίδα.` `[ˈime roˈsiða]` | Я русский / русская. |
| Язык | `Μιλάω ρωσικά.` `[miˈlao rosiˈka]` | Я говорю по-русски. |
| Нынешнее место жительства | `Μένω στην Κύπρο.` `[ˈmeno stin ˈkipro]` | Я живу на Кипре. |

Страна происхождения и нынешнее жильё могут не совпадать. Национальность
в учебном рассказе тоже не заменяет название страны. **Россия, русский и
по-русски — три разные формы**, а не одно слово с разными артиклями.

#### Какие вопросы задавать

- `Από πού είσαι;` `[aˈpo pu ˈise]` — откуда ты?
- `Πού μένεις;` `[pu ˈmenis]` — где ты живёшь?
- `Τι γλώσσες μιλάς;` `[ti ˈɣloses miˈlas]` — на каких языках ты говоришь?
- `Τι σπουδάζεις;` `[ti spuˈðazis]` — что ты изучаешь в вузе?

`Τι` `[ti]` означает «что / какой», а `γλώσσες` `[ˈɣloses]` — «языки».
Слово целиком: `η γλώσσα` `[i ˈɣlosa]`, множественное
`οι γλώσσες` `[i ˈɣloses]`.

#### Где нужен артикль

В модели происхождения: `από + артикль + страна`.
Например, `από τη Γαλλία` `[aˈpo ti ɣaˈlia]` — из Франции;
`από την Ιταλία` `[aˈpo tin itaˈlia]` — из Италии;
`από τον Καναδά` `[aˈpo ton kanaˈða]` — из Канады.

В простом сообщении национальности после «быть» артикля нет:
`Είναι Γάλλος.` `[ˈine ˈɣalos]` — он француз.
В словаре артикль сохраняем: `ο Γάλλος` `[o ˈɣalos]`,
`η Γαλλίδα` `[i ɣaˈliða]` — француз, француженка.
Артикль в словарной записи не означает, что его нужно вставлять в любую фразу.

После «говорю» название языка обычно без артикля:
`Μιλάει γαλλικά.` `[miˈlai ɣaliˈka]` — говорит по-французски.
Словарное название — `τα γαλλικά` `[ta ɣaliˈka]`, форма множественного числа.

**Написание:** страна и национальность — с большой буквы, язык — с маленькой:
`Γαλλία — Γάλλος — γαλλικά` `[ɣaˈlia — ˈɣalos — ɣaliˈka]`.
Большая буква в начале предложения — обычное исключение из этого сравнения.

Подробнее: [происхождение, жильё и выбор артикля](../reference/grammar/origin-and-residence.md).

### 2. Как выбрать национальность { #nationalities }

Для одного мужчины нужна мужская форма, для одной женщины — женская.
Само название страны при этом не меняется. Вопрос не в роде страны:
Франция — женского рода, но француз может быть мужчиной.

| Страна | Мужчина | Женщина | Язык |
|---|---|---|---|
| Греция — `η Ελλάδα` `[i eˈlaða]` | `Έλληνας` `[ˈelinas]` | `Ελληνίδα` `[eliˈniða]` | `ελληνικά` `[eliniˈka]` |
| Россия — `η Ρωσία` `[i roˈsia]` | `Ρώσος` `[ˈrosos]` | `Ρωσίδα` `[roˈsiða]` | `ρωσικά` `[rosiˈka]` |
| Франция — `η Γαλλία` `[i ɣaˈlia]` | `Γάλλος` `[ˈɣalos]` | `Γαλλίδα` `[ɣaˈliða]` | `γαλλικά` `[ɣaliˈka]` |
| Германия — `η Γερμανία` `[i yermaˈnia]` | `Γερμανός` `[yermaˈnos]` | `Γερμανίδα` `[yermaˈniða]` | `γερμανικά` `[yermaniˈka]` |
| Италия — `η Ιταλία` `[i itaˈlia]` | `Ιταλός` `[itaˈlos]` | `Ιταλίδα` `[itaˈliða]` | `ιταλικά` `[italiˈka]` |
| Испания — `η Ισπανία` `[i ispaˈnia]` | `Ισπανός` `[ispaˈnos]` | `Ισπανίδα` `[ispaˈniða]` | `ισπανικά` `[ispaniˈka]` |
| Турция — `η Τουρκία` `[i turˈkia]` | `Τούρκος` `[ˈturkos]` | `Τουρκάλα` `[turˈkala]` | `τουρκικά` `[turkiˈka]` |

Для упражнений сначала нужны эти пары. **Женскую форму нельзя всегда получить
заменой последней буквы:** встречаются разные модели. Обрати внимание и на
перемещение ударения: `Ρώσος → Ρωσίδα` `[ˈrosos → roˈsiða]`.

#### Модели женских форм из конспекта

| Модель | Примеры |
|---|---|
| **-ίδα** `[ˈiða]` | `Γάλλος → Γαλλίδα` `[ˈɣalos → ɣaˈliða]`; `Ιταλός → Ιταλίδα` `[itaˈlos → itaˈliða]` |
| **-έζα** `[ˈeza]` | `Καναδός → Καναδέζα` `[kanaˈðos → kanaˈðeza]`; `Κινέζος → Κινέζα` `[kiˈnezos → kiˈneza]` |
| **-α** `[a]` | `Βούλγαρος → Βουλγάρα` `[ˈvulɣaros → vulˈɣara]`; `Σέρβος → Σέρβα` `[ˈservos → ˈserva]` |
| **-ή** `[ˈi]` | `Ισραηλινός → Ισραηλινή` `[israiliˈnos → israiliˈni]` |

Это группы для запоминания, а не универсальная формула. Отдельно запоминаем
`Τούρκος → Τουρκάλα` `[ˈturkos → turˈkala]` и
`Κορεάτης → Κορεάτισσα` `[koreˈatis → koreˈatisa]`.

#### Остальные страны из таблицы и упражнения с персонажами

Это справочная часть: заглядывай, когда встречается нужный человек.
Формы мужчины и женщины даны для конструкции «он / она — кто».
Перечисленные языки — учебные примеры, а не полный список языков каждой страны.

| Страна | Мужчина / женщина | Язык в материале |
|---|---|---|
| Албания — `η Αλβανία` `[i alvaˈnia]` | `Αλβανός / Αλβανίδα` `[alvaˈnos / alvaˈniða]` | `αλβανικά` `[alvaniˈka]` |
| Америка — `η Αμερική` `[i ameriˈki]` | `Αμερικανός / Αμερικανίδα` `[amerikaˈnos / amerikaˈniða]` | `αγγλικά` `[aŋgliˈka]` |
| Австралия — `η Αυστραλία` `[i afstraˈlia]` | `Αυστραλός / Αυστραλέζα` `[afstraˈlos / afstraˈleza]` | `αγγλικά` `[aŋgliˈka]` |
| Дания — `η Δανία` `[i ðaˈnia]` | `Δανός / Δανέζα` `[ðaˈnos / ðaˈneza]` | `δανέζικα` `[ðaˈnezika]` |
| Канада — `ο Καναδάς` `[o kanaˈðas]` | `Καναδός / Καναδέζα` `[kanaˈðos / kanaˈðeza]` | `αγγλικά και γαλλικά` `[aŋgliˈka ke ɣaliˈka]` |
| Швеция — `η Σουηδία` `[i suiˈðia]` | `Σουηδός / Σουηδέζα` `[suiˈðos / suiˈðeza]` | `σουηδικά` `[suiðiˈka]` |
| Китай — `η Κίνα` `[i ˈkina]` | `Κινέζος / Κινέζα` `[kiˈnezos / kiˈneza]` | `κινέζικα` `[kiˈnezika]` |
| Нидерланды — `η Ολλανδία` `[i olanˈðia]` | `Ολλανδός / Ολλανδέζα` `[olanˈðos / olanˈðeza]` | `ολλανδικά` `[olanðiˈka]` |
| Египет — `η Αίγυπτος` `[i ˈeɣiptos]` | `Αιγύπτιος / Αιγύπτια` `[eˈyiptios / eˈyiptia]` | `αραβικά` `[araviˈka]` |
| Болгария — `η Βουλγαρία` `[i vulɣaˈria]` | `Βούλγαρος / Βουλγάρα` `[ˈvulɣaros / vulˈɣara]` | `βουλγαρικά` `[vulɣariˈka]` |
| Сербия — `η Σερβία` `[i serˈvia]` | `Σέρβος / Σέρβα` `[ˈservos / ˈserva]` | `σερβικά` `[serviˈka]` |
| Израиль — `το Ισραήλ` `[to israˈil]` | `Ισραηλινός / Ισραηλινή` `[israiliˈnos / israiliˈni]` | `εβραϊκά` `[evraiˈka]` |
| Норвегия — `η Νορβηγία` `[i norviˈyia]` | `Νορβηγός / Νορβηγίδα` `[norviˈɣos / norviˈyiða]` | `νορβηγικά` `[norviyiˈka]` |
| Япония — `η Ιαπωνία` `[i iapoˈnia]` | `Γιαπωνέζος / Γιαπωνέζα` `[yapoˈnezos / yapoˈneza]` | `γιαπωνέζικα` `[yapoˈnezika]` |
| Корея — `η Κορέα` `[i koˈrea]` | `Κορεάτης / Κορεάτισσα` `[koreˈatis / koreˈatisa]` | `κορεάτικα` `[koreˈatika]` |

В таблице США обозначены также как `οι Ηνωμένες Πολιτείες`
`[i inoˈmenes poliˈties]` — Соединённые Штаты. Это множественное число;
не переносим на него артикль единственного числа от слова «Америка».

В отдельной вставке различаются `το Ηνωμένο Βασίλειο`
`[to inoˈmeno vaˈsilio]` — Соединённое Королевство — и
`η Αγγλία` `[i aŋˈglia]` — Англия. Соответственно:
`Βρετανός / Βρετανίδα` `[vretaˈnos / vretaˈniða]` — британец / британка;
`Άγγλος / Αγγλίδα` `[ˈaŋglos / aŋˈgliða]` — англичанин / англичанка.
Это не взаимозаменяемые географические названия.

### 3. «Говорю»: новая модель спряжения { #speak }

До этого была группа А с безударным **-ω** `[o]`, например
`μένω` `[ˈmeno]` — живу. Здесь **ударное -άω** `[ˈao]`:
`μιλάω` `[miˈlao]` — говорю. В таблице учебника группа называется **Β1**:
это обозначение спряжения, не уровень владения языком B1.

| Кто | Форма | Значение |
|---|---|---|
| `εγώ` `[eˈɣo]` | μιλ**άω** / μιλ**ώ** `[miˈlao / miˈlo]` | я говорю |
| `εσύ` `[eˈsi]` | μιλ**άς** `[miˈlas]` | ты говоришь |
| `αυτός / αυτή / αυτό` `[afˈtos / afˈti / afˈto]` | μιλ**άει** / μιλ**ά** `[miˈlai / miˈla]` | он / она / оно говорит |
| `εμείς` `[eˈmis]` | μιλ**άμε** `[miˈlame]` | мы говорим |
| `εσείς` `[eˈsis]` | μιλ**άτε** `[miˈlate]` | вы говорите |
| `αυτοί / αυτές / αυτά` `[afˈti / afˈtes / afˈta]` | μιλ**άνε** / μιλ**ούν** `[miˈlane / miˈlun]` | они говорят: мужской / женский / средний род |

Варианты через косую черту означают **то же лицо и то же действие**.
Для первого запоминания возьми один ряд: `μιλάω, μιλάς, μιλάει, μιλάμε,
μιλάτε, μιλάνε` `[miˈlao, miˈlas, miˈlai, miˈlame, miˈlate, miˈlane]`.
Остальные формы пока узнавай при чтении.

#### Как выбирать окончание

1. Определи, кто действует: я, ты, один человек, мы, вы или они.
2. Узнай модель глагола по его исходной форме.
3. Подставь окончание **этой** модели, а не окончание соседнего глагола.

| Лицо | Группа А: учусь в вузе | Тип Β1: говорю |
|---|---|---|
| Ты | σπουδάζ**εις** `[spuˈðazis]` | μιλ**άς** `[miˈlas]` |
| Он / она | σπουδάζ**ει** `[spuˈðazi]` | μιλ**άει** `[miˈlai]` |
| Мы | σπουδάζ**ουμε** `[spuˈðazume]` | μιλ**άμε** `[miˈlame]` |
| Вы | σπουδάζ**ετε** `[spuˈðazete]` | μιλ**άτε** `[miˈlate]` |

Ловушка: не добавляй обычное «-ис» к «говорю». Для «ты» здесь
`μιλάς` `[miˈlas]`, а не форма группы А. Зато узнаваемые опоры остаются:
«мы» содержит **м**, «вы» — **т**; всё окончание учим вместе.

`Η Λάουρα μιλάει ιταλικά.` `[i ˈlaura miˈlai italiˈka]` — Лаура говорит
по-итальянски: один человек. `Ο Φλαβιάν και η Λάουρα μιλάνε ελληνικά.`
`[o flaviˈan ke i ˈlaura miˈlane eliniˈka]` — Флавиан и Лаура говорят
по-гречески: двое, поэтому «они». Пол влияет на местоимение, но **не меняет
окончание глагола**.

[Полное правило и примеры типа Β1](../reference/grammar/present-tense-b1.md).

### 4. Насколько хорошо я знаю язык { #language-level }

На вопрос `Μιλάς ελληνικά;` `[miˈlas eliniˈka]` — «Говоришь по-гречески?» —
можно ответить не только «да» или «нет». После глагола добавляем степень умения.

| Выражение | Значение |
|---|---|
| `τέλεια` `[ˈtelia]` | прекрасно, идеально |
| `πολύ καλά` `[poˈli kaˈla]` | очень хорошо |
| `αρκετά καλά` `[arkeˈta kaˈla]` | достаточно хорошо |
| `καλά` `[kaˈla]` | хорошо |
| `έτσι κι έτσι` `[ˈetsi ki ˈetsi]` | так себе |
| `όχι πολύ καλά` `[ˈohi poˈli kaˈla]` | не очень хорошо |
| `λίγο` `[ˈliɣo]` | немного |
| `πολύ λίγο` `[poˈli ˈliɣo]` | совсем немного |
| `καθόλου` `[kaˈθolu]` | совсем не, нисколько — в отрицательном ответе |

Проценты в учебной шкале — иллюстрация значений, **не тест и не уровни CEFR**.
Не нужно вычислять, «на сколько процентов» ты говоришь.

`Η μητρική γλώσσα` `[i mitriˈki ˈɣlosa]` — родной язык;
`η ξένη γλώσσα` `[i ˈkseni ˈɣlosa]` — иностранный язык.
Во множественном числе: `οι μητρικές γλώσσες` `[i mitriˈkes ˈɣloses]`,
`οι ξένες γλώσσες` `[i ˈksenes ˈɣloses]`.
Вопрос преподавателя `Τι ξένες γλώσσες ξέρετε;`
`[ti ˈksenes ˈɣloses ˈkserete]` — «Какие иностранные языки вы знаете?»;
вариант с `μιλάτε` `[miˈlate]` спрашивает, на каких вы говорите.

#### Отрицание: куда поставить «не»

`Δεν` `[ðen]` ставится **перед глаголом**:

- `Δεν μιλάω καλά ελληνικά.` `[ðen miˈlao kaˈla eliniˈka]` — я плохо
  говорю по-гречески; это не обязательно полное отсутствие знания.
- `Δεν μιλάω καθόλου γαλλικά.` `[ðen miˈlao kaˈθolu ɣaliˈka]` — я совсем
  не говорю по-французски.

Короткий ответ `Καθόλου.` `[kaˈθolu]` понятен из вопроса. Но в полном
предложении нельзя просто убрать отрицание: учи связку
`δεν … καθόλου` `[ðen … kaˈθolu]` — «совсем не».
В учебнике встречается сокращённое `δε` `[ðe]` перед некоторыми согласными;
смысл отрицания остаётся тем же.

#### «Понимаю» не значит «свободно говорю»

| Действие | Пример |
|---|---|
| Понимать | `Καταλαβαίνω ελληνικά.` `[katalaˈveno eliniˈka]` — понимаю греческий |
| Говорить | `Μιλάω ελληνικά.` `[miˈlao eliniˈka]` — говорю по-гречески |
| Читать | `Διαβάζω ελληνικά.` `[ðiaˈvazo eliniˈka]` — читаю по-гречески |
| Писать | `Γράφω ελληνικά.` `[ˈɣrafo eliniˈka]` — пишу по-гречески |

Эти умения могут быть развиты по-разному. Естественный ответ начинающего:
`Καταλαβαίνω αρκετά καλά, αλλά μιλάω λίγο.`
`[katalaˈveno arkeˈta kaˈla aˈla miˈlao ˈliɣo]` — понимаю достаточно
хорошо, но говорю немного. `Αλλά` `[aˈla]` — «но».

### 5. Диалог: что ты изучаешь? { #studies-dialogue }

В диалоге на печатной с. 52 Лаура и Флавиан знакомятся, уточняют происхождение,
обсуждают учёбу и знание греческого. Ниже весь разговор с переводом:
читай сначала по смысловым частям, затем по ролям.

| Кто | Реплика | Перевод |
|---|---|---|

| Флавиан | `Γεια χαρά!` `[ya haˈra]` | Привет! |
| Лаура | `Πώς σε λένε;` `[pos se ˈlene]` | Как тебя зовут? |
| Флавиан | `Με λένε Φλαβιάν. Εσένα;` `[me ˈlene flaviˈan eˈsena]` | Меня зовут Флавиан. А тебя? |
| Лаура | `Είμαι η Λάουρα. Από πού είσαι;` `[ˈime i ˈlaura aˈpo pu ˈise]` | Я Лаура. Откуда ты? |
| Флавиан | `Είμαι από τη Γαλλία.` `[ˈime aˈpo ti ɣaˈlia]` | Я из Франции. |
| Лаура | `Α, είσαι Γάλλος, λοιπόν! Από τη Γαλλία, από ποιο μέρος;` `[a ˈise ˈɣalos liˈpon aˈpo ti ɣaˈlia aˈpo pyo ˈmeros]` | А, значит, ты француз! Из Франции — из какого места? |

| Лаура | `Σπουδάζω Νομικά. Κάνω μεταπτυχιακό. Εσύ;` `[spuˈðazo nomiˈka ˈkano metaptihiaˈko eˈsi]` | Изучаю право. Учусь в магистратуре. А ты? |
| Флавиан | `Σπουδάζω Ψυχολογία στο Πανεπιστήμιο Αθηνών. Μιλάς ελληνικά μια χαρά!` `[spuˈðazo psiholoˈyia sto panepiˈstimio aθiˈnon miˈlas eliniˈka mya haˈra]` | Изучаю психологию в Афинском университете. Ты прекрасно говоришь по-гречески! |
| Лаура | `Ε, έτσι κι έτσι! Καταλαβαίνω, όμως, πολύ καλά!` `[e ˈetsi ki ˈetsi katalaˈveno ˈomos poˈli kaˈla]` | Ну, так себе! Но понимаю очень хорошо! |
| Лаура | `Έχω μία φίλη Ελληνίδα και με βοηθάει πολύ! Αυτή κάνει διδακτορικό.` `[ˈeho ˈmia ˈfili eliˈniða ke me voiˈθai poˈli afˈti ˈkani ðiðaktoriˈko]` | У меня есть подруга-гречанка, и она мне очень помогает! Она учится в докторантуре. |
| Флавиан | `Α, πολύ ωραία!` `[a poˈli oˈrea]` | А, очень здорово! |

#### Что важно понять по словам

**«Из какого места?»** — `από ποιο μέρος;` `[aˈpo pyo ˈmeros]`:
`από` `[aˈpo]` — из, `ποιο` `[pyo]` — какого, `μέρος` `[ˈmeros]` — места.
Здесь уже знают страну и уточняют город или область. Не повторяй только страну.

**«А тебя?» и «А ты?»** В `Με λένε… Εσένα;` `[me ˈlene eˈsena]`
подразумевается «А тебя как зовут?». В `Σπουδάζω… Εσύ;`
`[spuˈðazo eˈsi]` — «А ты что изучаешь?». Формы «тебя» и «ты» не одинаковы.

**«Она мне помогает»** — `με βοηθάει` `[me voiˈθai]`:
`με` `[me]` относится к тому, кому помогают, а окончание глагола — к тому,
кто помогает. Поэтому это не «я помогаю». Не выбирай лицо глагола по ближайшему
маленькому слову.

**«Но понимаю»** — `καταλαβαίνω, όμως` `[katalaˈveno ˈomos]`.
`Όμως` `[ˈomos]` — «однако / но»; в этом разговоре противопоставляет
слабую разговорную речь хорошему пониманию.

#### Учёба: три разные вещи

| Выражение | Значение |
|---|---|
| `σπουδάζω Νομικά` `[spuˈðazo nomiˈka]` | изучаю право в вузе — специальность |
| `κάνω μεταπτυχιακό` `[ˈkano metaptihiaˈko]` | учусь в магистратуре — ступень обучения |
| `κάνω διδακτορικό` `[ˈkano ðiðaktoriˈko]` | учусь в докторантуре / работаю над докторской диссертацией |

`Μαθαίνω` `[maˈθeno]` — учу, узнаю, осваиваю; не обязательно в вузе.
`Σπουδάζω` `[spuˈðazo]` — изучаю как вузовскую специальность.
`Μελετάω` `[meleˈtao]` — занимаюсь, изучаю материал внимательно.
Русское «учить» не даёт одной универсальной греческой формы.

### 6. Другие глаголы той же модели { #verbs }

В конспекте рядом с таблицей выделены следующие глаголы. Для спряжения
замени основу, сохрани модель «говорю». Не нужно заучивать отдельную таблицу
для каждого слова.

| Глагол | Значение | Пример формы |
|---|---|---|
| `αγαπάω` `[aɣaˈpao]` | люблю | αγαπ**άς** `[aɣaˈpas]` — ты любишь |
| `ρωτάω` `[roˈtao]` | спрашиваю | ρωτ**άμε** `[roˈtame]` — мы спрашиваем |
| `απαντάω` `[apaˈndao]` | отвечаю | απαντ**άει** `[apaˈndai]` — он / она отвечает |
| `γελάω` `[yeˈlao]` | смеюсь | γελ**άτε** `[yeˈlate]` — вы смеётесь |
| `μελετάω` `[meleˈtao]` | изучаю, занимаюсь | μελετ**άμε** `[meleˈtame]` — мы занимаемся |
| `περπατάω` `[perpaˈtao]` | хожу пешком | περπατ**άνε** `[perpaˈtane]` — они идут пешком |
| `περνάω` `[perˈnao]` | прохожу; провожу время | περν**άμε** `[perˈname]` — мы проводим время |
| `συναντάω` `[sinaˈndao]` | встречаю | συναντ**άς** `[sinaˈndas]` — ты встречаешь |
| `τραγουδάω` `[traɣuˈðao]` | пою | τραγουδ**άει** `[traɣuˈðai]` — он / она поёт |
| `χαιρετάω` `[hereˈtao]` | приветствую | χαιρετ**άτε** `[hereˈtate]` — вы приветствуете |

Пример преподавателя: `Περνάμε καλά στην Κύπρο!`
`[perˈname kaˈla stin ˈkipro]` — мы хорошо проводим время на Кипре.
Здесь глагол означает не «проходим мимо», а «проводим время»:
выражение запоминается вместе со словом «хорошо».

### 7. Собираем рассказ о человеке { #profile }

Порядок опор: **имя → страна → национальность → языки и уровень → учёба →
адрес → телефон**. Берём сведения из карточки задания, не придумываем
недостающий телефон.

Пример из учебника, разбитый на части:

| Фраза | Значение |
|---|---|
| `Ο Νίκος είναι από την Ελλάδα.` `[o ˈnikos ˈine aˈpo tin eˈlaða]` | Никос из Греции. |
| `Είναι Έλληνας.` `[ˈine ˈelinas]` | Он грек. |
| `Μιλάει αρκετά καλά αγγλικά.` `[miˈlai arkeˈta kaˈla aŋgliˈka]` | Достаточно хорошо говорит по-английски. |
| `Σπουδάζει Μαθηματικά.` `[spuˈðazi maθimatiˈka]` | Изучает математику. |
| `Μένει Ερατούς 99, στο Μαρούσι.` `[ˈmeni eraˈtus eneˈninda eˈnya sto maˈrusi]` | Живёт на улице Эратус, 99, в Маруси. |
| `Το τηλέφωνό του είναι…` `[to tiˈlefoˈno tu ˈine]` | Его телефон… |

Почему у слова «телефон» два ударения? В связке
`το τηλέφωνό του` `[to tiˈlefoˈno tu]` короткое безударное «его» вызывает
дополнительное ударение на последнем слоге предыдущего слова. В словаре
по-прежнему `το τηλέφωνο` `[to tiˈlefono]`. В рассказе о женщине:
`το τηλέφωνό της` `[to tiˈlefoˈno tis]` — её телефон.

Имена, улицы и районы в задании **переписываем**, а не переводим и не учим
как основной словарь. Новые специальности: `η Στατιστική` `[i statistiˈki]` —
статистика; `η Ιατρική` `[i iatriˈki]` — медицина;
`η Πληροφορική` `[i pliroforiˈki]` — информатика;
`η Βιολογία` `[i violoˈyia]` — биология.

Когда доходишь до строки «я», меняешь **все** глаголы, а не только первый:
`είναι → είμαι` `[ˈine → ˈime]`, `μιλάει → μιλάω` `[miˈlai → miˈlao]`,
`σπουδάζει → σπουδάζω` `[spuˈðazi → spuˈðazo]`,
`μένει → μένω` `[ˈmeni → ˈmeno]`.
