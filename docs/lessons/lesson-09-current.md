# Урок 09 — профессии, места работы и возраст

## Что освоить

- Различать вопросы «кем работаешь?» и «где работаешь?» и отвечать полным предложением.
- Назвать профессию мужчины и женщины: иногда меняется слово, иногда только артикль.
- Связать профессию с местом работы, правильно выбрать «в / на» с артиклем.
- Спросить возраст и понять формы числительных в ответе; рассказать о занятиях родственников.

## Разбор

### 1. Кем работаешь — не то же самое, что где работаешь { #work }

| Вопрос | Ответ | Что сообщаем |
|---|---|---|
| `Τι δουλειά κάνεις;` `[ti ðuˈlya ˈkanis]` — Кем ты работаешь? | `Είμαι μηχανικός.` `[ˈime mihaniˈkos]` — Я инженер. | профессию |
| `Τι δουλειά κάνετε;` `[ti ðuˈlya ˈkanete]` — Кем вы работаете? | `Είμαι καθηγήτρια.` `[ˈime kaθiˈyitria]` — Я преподавательница. | вежливое обращение или вопрос группе |
| `Πού δουλεύεις;` `[pu ðuˈlevis]` — Где ты работаешь? | `Δουλεύω στο γραφείο.` `[ðuˈlevo sto ɣraˈfio]` — Я работаю в офисе. | место |
| `Πού δουλεύετε;` `[pu ðuˈlevete]` — Где вы работаете? | `Δουλεύω στην καφετέρια.` `[ðuˈlevo stin kafeˈteria]` — Я работаю в кафе. | место, а не название профессии |

Разберём первый вопрос: `τι` `[ti]` — что / какой;
`η δουλειά` `[i ðuˈlya]` — работа; `κάνεις` `[ˈkanis]` — ты делаешь.
Буквально «какую работу ты делаешь?», естественно по-русски «кем работаешь?».
В ответе на вежливое «вы» один человек говорит **я**, а не «мы».

Другой способ спросить о занятии:
`Με τι ασχολείσαι;` `[me ti ashoˈlise]` — Чем ты занимаешься?
`Με τι ασχολείστε;` `[me ti ashoˈliste]` — Чем вы занимаетесь?
Здесь `με` `[me]` входит в конструкцию «заниматься чем-либо».
В контексте урока это вопрос о работе; вне этого контекста он может быть шире.
Не заменяй эти формы окончаниями обычного глагола «работать».

Когда называем свою профессию после «быть», артикль обычно **не нужен**:
`Είμαι γιατρός.` `[ˈime yaˈtros]` — Я врач.
Но при назывании конкретного человека:
`Η Εύα είναι νοσοκόμα.` `[i ˈeva ˈine nosoˈkoma]` — Эва — медсестра.
Перед именем артикль есть; перед профессией в этом ответе — нет.
Словарный артикль всё равно учим: он показывает род слова.

`Δεν δουλεύω. Είμαι φοιτητής.` `[ðen ðuˈlevo ˈime fitiˈtis]` —
Я не работаю. Я студент.
`Είμαι άνεργη.` `[ˈime ˈaneryi]` — Я безработная.
`Είμαι συνταξιούχος.` `[ˈime sindaksiˈuhos]` — Я пенсионер / пенсионерка.
**Не работаю сейчас** не обязательно значит **безработный**: причиной могут быть
учёба, пенсия или временный перерыв.

### 2. «Работаю»: знакомая модель Α1 { #verbs }

| Кто | Форма | Перевод |
|---|---|---|
| я | δουλεύ**ω** `[ðuˈlevo]` | работаю |
| ты | δουλεύ**εις** `[ðuˈlevis]` | работаешь |
| он / она / оно | δουλεύ**ει** `[ðuˈlevi]` | работает |
| мы | δουλεύ**ουμε** `[ðuˈlevume]` | работаем |
| вы | δουλεύ**ετε** `[ðuˈlevete]` | работаете |
| они | δουλεύ**ουν** `[ðuˈlevun]` | работают |

Сочетание `ευ` `[ev]` здесь произносится с «в», потому что дальше звонкий звук.
Пол человека не меняет глагол: `Αυτός δουλεύει. Αυτή δουλεύει.`
`[afˈtos ðuˈlevi afˈti ðuˈlevi]` — Он работает. Она работает.
Зато название профессии может измениться.
[Модель Α1](../reference/grammar/present-tense-a.md) ·
[формы «быть»](../reference/grammar/eimai.md).

### 3. Профессии: где меняется слово { #professions }

Сначала выбери, говоришь о мужчине или о женщине, затем возьми нужную пару.
Не пытайся сделать женскую форму простым удалением последней буквы.

| Мужчина | Женщина | Значение |
|---|---|---|
| `ο καθηγητής` `[o kaθiyiˈtis]` | `η καθηγήτρια` `[i kaθiˈyitria]` | преподаватель / преподавательница |
| `ο πωλητής` `[o poliˈtis]` | `η πωλήτρια` `[i poˈlitria]` | продавец / продавщица |
| `ο κομμωτής` `[o komoˈtis]` | `η κομμώτρια` `[i koˈmotria]` | парикмахер |
| `ο γυμναστής` `[o yimnaˈstis]` | `η γυμνάστρια` `[i yimˈnastria]` | тренер, преподаватель физкультуры |
| `ο τραγουδιστής` `[o traɣuðiˈstis]` | `η τραγουδίστρια` `[i traɣuˈðistria]` | певец / певица |
| `ο δάσκαλος` `[o ˈðaskalos]` | `η δασκάλα` `[i ðaˈskala]` | учитель / учительница |
| `ο νοσοκόμος` `[o nosoˈkomos]` | `η νοσοκόμα` `[i nosoˈkoma]` | медбрат / медсестра |
| `ο νοσηλευτής` `[o nosilefˈtis]` | `η νοσηλεύτρια` `[i nosiˈleftria]` | медбрат / медсестра: другая пара из таблицы |
| `ο σερβιτόρος` `[o serviˈtoros]` | `η σερβιτόρα` `[i serviˈtora]` | официант / официантка |
| `ο μάγειρας` `[o ˈmaɣiras]` | `η μαγείρισσα` `[i maˈyirisa]` | повар |
| `ο μανάβης` `[o maˈnavis]` | `η μανάβισσα` `[i maˈnavisa]` | продавец овощей и фруктов |
| `ο μαθητής` `[o maθiˈtis]` | `η μαθήτρια` `[i maˈθitria]` | ученик / ученица |
| `ο φοιτητής` `[o fitiˈtis]` | `η φοιτήτρια` `[i fiˈtitria]` | студент / студентка |
| `ο ταξιτζής` `[o taksiˈdzis]` | `η ταξιτζού` `[i taksiˈdzu]` | таксист / таксистка |
| `ο άνεργος` `[o ˈanerɣos]` | `η άνεργη` `[i ˈaneryi]` | безработный / безработная |

В нескольких парах ударение переходит: преподаватель и преподавательница,
учитель и учительница. Запоминай **оба слова целиком**, с ударением.
«Ученик» и «студент» различаются: первый учится в школе, второй — в вузе.
«Учитель» и «преподаватель» также не заменяем автоматически друг другом:
в заданиях школьный учитель соотнесён со школой, преподаватель — с университетом.

### 4. Профессии: слово одно, артикль разный { #common-gender }

`ο γιατρός` `[o yaˈtros]` — мужчина-врач,
`η γιατρός` `[i yaˈtros]` — женщина-врач. Окончание одинаковое.
Именно поэтому правило «на -с — значит мужчина» **не универсально**.

| Слово с двумя артиклями | Значение |
|---|---|
| `ο / η δικηγόρος` `[o / i ðikiˈɣoros]` | адвокат |
| `ο / η γιατρός` `[o / i yaˈtros]` | врач |
| `ο / η μηχανικός` `[o / i mihaniˈkos]` | инженер; механик — по контексту |
| `ο / η δημοσιογράφος` `[o / i ðimosioˈɣrafos]` | журналист |
| `ο / η φαρμακοποιός` `[o / i farmakopiˈos]` | фармацевт |
| `ο / η ηθοποιός` `[o / i iθopiˈos]` | актёр / актриса |
| `ο / η αρχαιολόγος` `[o / i arheoˈloɣos]` | археолог |
| `ο / η υπάλληλος` `[o / i iˈpalilos]` | сотрудник / сотрудница |
| `ο / η φωτογράφος` `[o / i fotoˈɣrafos]` | фотограф |
| `ο / η αρχιτέκτονας` `[o / i arhiˈtektonas]` | архитектор |
| `ο / η αστυνομικός` `[o / i astinomiˈkos]` | полицейский |
| `ο / η γραμματέας` `[o / i ɣramaˈteas]` | секретарь |
| `ο / η ταμίας` `[o / i taˈmias]` | кассир |
| `ο / η τεχνικός` `[o / i tehniˈkos]` | техник |
| `ο / η διπλωμάτης` `[o / i ðiploˈmatis]` | дипломат |
| `ο / η συνταξιούχος` `[o / i sindaksiˈuhos]` | пенсионер / пенсионерка |

После «быть» без артикля пол может быть понятен только из имени:
`Η Μαριάννα είναι δικηγόρος.` `[i mariˈana ˈine ðikiˈɣoros]` — Марианна — адвокат.
Не добавляй к слову искусственное «женское окончание».

### 5. Где работают: профессия + место { #places }

| Место | Значение | Пример |
|---|---|---|
| `το σχολείο` `[to shoˈlio]` | школа | `Είμαι δάσκαλος. Δουλεύω στο σχολείο.` `[ˈime ˈðaskalos ðuˈlevo sto shoˈlio]` — Я учитель. Работаю в школе. |
| `το νοσοκομείο` `[to nosokoˈmio]` | больница | `Είμαι γιατρός. Δουλεύω στο νοσοκομείο.` `[ˈime yaˈtros ðuˈlevo sto nosokoˈmio]` — Я врач. Работаю в больнице. |
| `το σουπερμάρκετ` `[to superˈmarket]` | супермаркет | `Είμαι ταμίας. Δουλεύω στο σουπερμάρκετ.` `[ˈime taˈmias ðuˈlevo sto superˈmarket]` — Я кассир. Работаю в супермаркете. |
| `το συνεργείο` `[to sinerˈyio]` | автомастерская | `Είμαι μηχανικός. Δουλεύω στο συνεργείο.` `[ˈime mihaniˈkos ðuˈlevo sto sinerˈyio]` — Я механик. Работаю в автомастерской. |
| `το βενζινάδικο` `[to venziˈnaðiko]` | заправка | `Είμαι υπάλληλος. Δουλεύω στο βενζινάδικο.` `[ˈime iˈpalilos ðuˈlevo sto venziˈnaðiko]` — Я сотрудник. Работаю на заправке. |
| `το πανεπιστήμιο` `[to panepiˈstimio]` | университет | место работы преподавателя и учёбы студента |
| `η αστυνομία` `[i astinoˈmia]` | полиция | организация |
| `το αστυνομικό τμήμα` `[to astinomiˈko ˈtmima]` | полицейское отделение | конкретное место работы |
| `η γραμματεία` `[i ɣramaˈtia]` | секретариат | место работы секретаря |
| `το δικηγορικό γραφείο` `[to ðikiɣoriˈko ɣraˈfio]` | адвокатская контора | место работы адвоката |
| `το γραφείο` `[to ɣraˈfio]` | офис; письменный стол | в вопросе о работе — офис |
| `η τράπεζα` `[i ˈtrapeza]` | банк | место работы кассира или другого сотрудника |
| `το θέατρο` `[to ˈθeatro]` | театр | актёр |
| `το κομμωτήριο` `[to komoˈtirio]` | парикмахерская | парикмахер |
| `το σπίτι` `[to ˈspiti]` | дом | можно работать дома |
| `το εστιατόριο` `[to estiaˈtorio]` | ресторан | повар или официант |
| `η καφετέρια` `[i kafeˈteria]` | кафе | официант |
| `το φαρμακείο` `[to farmaˈkio]` | аптека | фармацевт |
| `η κλινική` `[i kliniˈki]` | клиника | медсестра в упражнении |
| `η πρεσβεία` `[i presˈvia]` | посольство | дипломат |
| `το κατάστημα` `[to kaˈtastima]` | магазин | продавец |
| `το μανάβικο` `[to maˈnaviko]` | овощная лавка | продавец овощей и фруктов |
| `το εμπορικό κέντρο` `[to emporiˈko ˈkendro]` | торговый центр | место из домашнего задания |

Это **учебные сочетания, а не единственно возможные места работы**.
Кассир может работать и в банке, и в супермаркете. Ответ определяет контекст.
Инженер — не обязательно автомеханик: в упражнении картинка автомастерской
задаёт значение «механик».

Для «в / на» соединяем предлог с артиклем:
`σε + το → στο` `[se + to → sto]`;
`σε + τη(ν) → στη(ν)` `[se + ti(n) → sti(n)]`.
`στην τράπεζα` `[stin ˈtrapeza]` — в банке,
`στη γραμματεία` `[sti ɣramaˈtia]` — в секретариате,
`στο γραφείο` `[sto ɣraˈfio]` — в офисе.
`τη` `[ti]` само по себе **не значит «в»**: это артикль. Значение «в» даёт предлог.
[Предлоги и винительный падеж](../reference/grammar/prepositions-accusative.md).

В учебном примере студентка не работает, а учится:
`Είμαι φοιτήτρια. Σπουδάζω στο πανεπιστήμιο.`
`[ˈime fiˈtitria spuˈðazo sto panepiˈstimio]` — Я студентка. Учусь в университете.
`Τι σπουδάζεις;` `[ti spuˈðazis]` — Что изучаешь в вузе?
Предметы из рамки:
`Φιλολογία / Φυσική / Οικονομικά / Βιολογία / Μαθηματικά`
`[filoloˈyia / fisiˈki / ikonomiˈka / violoˈyia / maθimatiˈka]` —
филология / физика / экономика / биология / математика.

### 6. Рассказ об Эве: весь текст { #eva }

| Греческий текст и чтение | Перевод |
|---|---|
| `Η Εύα είναι από την Πολωνία.` `[i ˈeva ˈine aˈpo tin poloˈnia]` | Эва из Польши. |
| `Τώρα μένει στην Ελλάδα, στη Θεσσαλονίκη.` `[ˈtora ˈmeni stin eˈlaða sti θesaloˈniki]` | Сейчас живёт в Греции, в Салониках. |
| `Είναι νοσοκόμα, αλλά τώρα δεν δουλεύει.` `[ˈine nosoˈkoma aˈla ˈtora ðen ðuˈlevi]` | Она медсестра, но сейчас не работает. |
| `Μαθαίνει ελληνικά στο Σχολείο Ελληνικής Γλώσσας.` `[maˈθeni eliniˈka sto shoˈlio eliniˈkis ˈɣlosas]` | Изучает греческий в Школе греческого языка. |
| `Ο άντρας της είναι από την Τσεχία, μένει στην Πράγα και είναι φαρμακοποιός.` `[o ˈandras tis ˈine aˈpo tin tseˈhia ˈmeni stin ˈpraɣa ke ˈine farmakopiˈos]` | Её муж из Чехии, живёт в Праге и работает фармацевтом. |

`αλλά` `[aˈla]` — **но**: противопоставляет профессию и отсутствие работы сейчас.
`τώρα` `[ˈtora]` — **сейчас**; `της` `[tis]` после «муж» — **её**.
У Эвы и её мужа разные города проживания: нельзя переносить Салоники на мужа.
Ответы на четыре вопроса опираются на напечатанный текст, не на догадки по фото.

| Вопрос | Ответ по тексту |
|---|---|
| `Από πού είναι η Εύα;` `[aˈpo pu ˈine i ˈeva]` — Откуда Эва? | `Είναι από την Πολωνία.` `[ˈine aˈpo tin poloˈnia]` — Из Польши. |
| `Πού μένει τώρα;` `[pu ˈmeni ˈtora]` — Где сейчас живёт? | `Μένει στη Θεσσαλονίκη.` `[ˈmeni sti θesaloˈniki]` — В Салониках. |
| `Τι δουλειά κάνει;` `[ti ðuˈlya ˈkani]` — Кем работает? | `Είναι νοσοκόμα, αλλά τώρα δεν δουλεύει.` `[ˈine nosoˈkoma aˈla ˈtora ðen ðuˈlevi]` — Медсестра, но сейчас не работает. |
| `Τι δουλειά κάνει ο άντρας της;` `[ti ðuˈlya ˈkani o ˈandras tis]` — Кем работает её муж? | `Είναι φαρμακοποιός.` `[ˈine farmakopiˈos]` — Фармацевт. |

### 7. Возраст: «скольких лет ты?» { #age }

`Πόσων χρονών είσαι;` `[ˈposon hroˈnon ˈise]` — Сколько тебе лет?
`Πόσων χρονών είστε;` `[ˈposon hroˈnon ˈiste]` — Сколько вам лет?
`Πόσων χρονών είναι;` `[ˈposon hroˈnon ˈine]` — Сколько ему / ей лет?

По словам: `πόσων` `[ˈposon]` — скольких;
`χρονών` `[hroˈnon]` — лет; `είσαι` `[ˈise]` — ты есть.
Это родительные формы в выражении возраста. По-русски переводим целиком:
«тебе сколько лет?», но греческий ответ строим с **быть**.

| Форма счёта | Форма в выражении возраста | Пример |
|---|---|---|
| `ένα` `[ˈena]` | `ενός` `[eˈnos]` | `Είναι τριάντα ενός χρονών.` `[ˈine triˈanda eˈnos hroˈnon]` — Ему 31 год. |
| `τρία` `[ˈtria]` | `τριών` `[triˈon]` | `Είναι είκοσι τριών χρονών.` `[ˈine ˈikosi triˈon hroˈnon]` — Ему 23 года. |
| `τέσσερα` `[ˈtesera]` | `τεσσάρων` `[teˈsaron]` | `Είναι τεσσάρων μηνών έγκυος.` `[ˈine teˈsaron miˈnon ˈeŋgios]` — Она на четвёртом месяце беременности. |

В составном числе меняется нужная **последняя часть**, а не все слова.
Число 27 остаётся знакомым:
`Είναι είκοσι εφτά χρονών.` `[ˈine ˈikosi eˈfta hroˈnon]` — Ей 27 лет.
Не говорим «имею 27» по аналогии с другими языками.
«Год» — `ο χρόνος` `[o ˈhronos]`, годы — `τα χρόνια` `[ta ˈhronya]`;
«месяц» — `ο μήνας` `[o ˈminas]`, месяцы — `οι μήνες` `[i ˈmines]`.
В диалоге нужны формы **лет / месяцев**, не «годы / месяцы».
[Краткое правило в справочнике чисел](../reference/numbers-11-100.md#age).

### 8. Диалог за столом: семья, профессия и возраст { #dialogue }

| Кто | Реплика и чтение | Перевод |
|---|---|---|
| Яннис | `Εσύ, Φλαβιάν, έχεις αδέρφια;` `[eˈsi flavˈian ˈehis aˈðerfya]` | Флавиан, у тебя есть братья или сёстры? |
| Флавиан | `Ναι, έχω δύο. Ο μεγάλος μου αδερφός είναι ο Κριστιάν και ο μικρός είναι ο Τιερί.` `[ne ˈeho ˈðio o meˈɣalos mu aðerˈfos ˈine o kristˈian ke o miˈkros ˈine o tyeˈri]` | Да, двое. Моего старшего брата зовут Кристиан, а младшего — Тьери. |
| София | `Σπουδάζουν;` `[spuˈðazun]` | Они учатся в вузе? |
| Флавиан | `Ο Τιερί είναι φοιτητής στην Ιατρική και ο Κριστιάν δουλεύει.` `[o tyeˈri ˈine fitiˈtis stin iatriˈki ke o kristˈian ðuˈlevi]` | Тьери — студент медицинского факультета, а Кристиан работает. |
| София | `Τι δουλειά κάνει;` `[ti ðuˈlya ˈkani]` | Кем он работает? |
| Флавиан | `Είναι δικηγόρος.` `[ˈine ðikiˈɣoros]` | Он адвокат. |
| София | `Πόσων χρονών είναι;` `[ˈposon hroˈnon ˈine]` | Сколько ему лет? |
| Флавиан | `Είναι τριάντα ενός χρονών.` `[ˈine triˈanda eˈnos hroˈnon]` | Ему 31 год. |
| София | `Και ο Τιερί;` `[ke o tyeˈri]` | А Тьери? |
| Флавиан | `Είκοσι τριών.` `[ˈikosi triˈon]` | Двадцать три. |
| София | `Εσύ, Λάουρα, έχεις αδέρφια;` `[eˈsi ˈlaura ˈehis aˈðerfya]` | Лаура, у тебя есть братья или сёстры? |
| Лаура | `Ναι, μια αδερφή είκοσι εφτά χρονών. Είναι δασκάλα.` `[ne mya aðerˈfi ˈikosi eˈfta hroˈnon ˈine ðaˈskala]` | Да, сестра, ей 27 лет. Она учительница. |
| София | `Παντρεμένη;` `[pandreˈmeni]` | Замужем? |
| Лаура | `Ναι.` `[ne]` | Да. |
| София | `Έχει παιδιά;` `[ˈehi peˈðya]` | У неё есть дети? |
| Лаура | `Είναι τεσσάρων μηνών έγκυος.` `[ˈine teˈsaron miˈnon ˈeŋgios]` | Она на четвёртом месяце беременности. |
| София | `Με το καλό!` `[me to kaˈlo]` | Пусть всё пройдёт хорошо! |
| Лаура | `Ευχαριστούμε!` `[efhariˈstume]` | Спасибо! (от нас) |
| Никос | `Α! Παιδιά, σε λίγο αρχίζει η ταινία. Πάμε στο σαλόνι;` `[a peˈðya se ˈliɣo arˈhizi i teˈnia ˈpame sto saˈloni]` | А! Ребята, скоро начинается фильм. Пойдём в гостиную? |
| Лаура, Флавиан, Вангелис | `Ναι.` `[ne]` | Да. |

**Не теряем, о ком говорят.** В начале профессия и возраст относятся к
Кристиану, не к Флавиану. Затем София переключается на Тьери, потом — на сестру Лауры.
`ο μεγάλος / ο μικρός` `[o meˈɣalos / o miˈkros]` здесь **старший / младший**,
а не описание роста. Во второй части слово «брат» не повторяется.
`τα αδέρφια` `[ta aˈðerfya]` — братья и сёстры вместе; это не только братья.
`μια` `[mya]` — одна (краткое произношение), относится к сестре, не к возрасту.

`έγκυος` `[ˈeŋgios]` — беременная; выражение с четырьмя месяцами описывает срок.
`Με το καλό!` `[me to kaˈlo]` — доброжелательное пожелание благополучного события,
здесь — рождения ребёнка; не буквальное «с хорошим».
`σε λίγο` `[se ˈliɣo]` — скоро; `αρχίζει` `[arˈhizi]` — начинается;
`η ταινία` `[i teˈnia]` — фильм; `το σαλόνι` `[to saˈloni]` — гостиная.
`Πάμε;` `[ˈpame]` — Пойдём? — предложение сделать что-то вместе.

В утверждениях после диалога есть нестыковка: печатное первое утверждение
говорит, что Флавиан **не** единственный ребёнок в семье, но в конспекте
отмечено «ложь». По самому диалогу у него два брата, поэтому утверждение
**верно**. Для остальных пунктов проверяй человека, профессию и число;
не копируй отметку без чтения реплики.

### 9. Семейная схема и задания о работе { #practice-models }

В схеме семьи Янниса все связи названы относительно **Янниса**:

| Предложение и чтение | Перевод |
|---|---|
| `Ο Χαράλαμπος είναι ο αδερφός του.` `[o haˈralambos ˈine o aðerˈfos tu]` | Хараламбос — его брат. |
| `Η Νάντια είναι η μητέρα του.` `[i ˈnandya ˈine i miˈtera tu]` | Надя — его мать. |
| `Ο Αντρέας είναι ο πατέρας του.` `[o anˈdreas ˈine o paˈteras tu]` | Андреас — его отец. |
| `Η Αγγελική είναι η γυναίκα του.` `[i aŋgeliˈki ˈine i yiˈneka tu]` | Ангелики — его жена. |
| `Ο Κώστας είναι ο γιος του.` `[o ˈkostas ˈine o yos tu]` | Костас — его сын. |
| `Η Ελένη είναι η κόρη του.` `[i eˈleni ˈine i ˈkori tu]` | Элени — его дочь. |
| `Η Μαρία είναι η γιαγιά του.` `[i maˈria ˈine i yaˈya tu]` | Мария — его бабушка. |
| `Ο Φίλιππος είναι ο παππούς του.` `[o ˈfilipos ˈine o paˈpus tu]` | Филиппос — его дедушка. |

`Έχω μια αδερφή.` `[ˈeho mya aðerˈfi]` — У меня одна сестра.
`Έχω έναν αδερφό.` `[ˈeho ˈenan aðerˈfo]` — У меня один брат.
`Δεν έχω αδέρφια.` `[ðen ˈeho aˈðerfya]` — У меня нет братьев и сестёр.
После «имею» мужские формы отличаются от словарных: «брат» без конечного «с».
[Семья и выбор «его / её»](lesson-08-current.md#family).

В упражнениях о работе нужны три разных действия:

- №14: сопоставить готовое **название профессии** с фотографией.
  `Η Δάφνη είναι μαθήτρια.` `[i ˈðafni ˈine maˈθitria]` — Дафни — ученица.
- №15–16: по профессии найти **место**, или по месту выбрать **профессию**.
  `Δουλεύω στην πρεσβεία. Είμαι διπλωμάτης.`
  `[ðuˈlevo stin presˈvia ˈime ðiploˈmatis]` — Работаю в посольстве. Я дипломат.
- №17: вставить **место**, а не профессию:
  `Η φοιτήτρια σπουδάζει στο πανεπιστήμιο.`
  `[i fiˈtitria spuˈðazi sto panepiˈstimio]` — Студентка учится в университете.

Это материал для разбора, не дополнительная обязательная домашка.

3. Расскажи о персонаже: кто он → кем работает → где работает.

   Ответы «23» и «31» не относятся к одному брату.
