## Что освоить

- Выбирать род прилагательного по существительному, а не по русскому переводу.
- Различать две изученные модели и запоминать исключения.
- Учить признаки противоположными парами и употреблять их в словосочетаниях.
- Повторить вопросы «кто / какой?» и указания «этот / тот».
- Описывать человека, предмет, комнату и семью короткими предложениями.

## Разбор

### Главное правило: чей это признак? { #agreement }

**Η κόρη της είναι μικρή.** [i ˈkori tis ˈine miˈkri] — Её дочь маленькая.
**Ο ξάδερφός σου είναι έξυπνος.** [o ˈksaðerfos su ˈine ˈeksipnos] —
Твой двоюродный брат умный.
**Το ποτό μου είναι κρύο.** [to poˈto mu ˈine ˈkrio] — Мой напиток холодный.

Сначала найди описываемое существительное. Его род определяет окончание
прилагательного; принадлежность «мой / твой / её» ничего здесь не меняет.
У «дочь» женский род, у «двоюродный брат» мужской, у «напиток» средний.
Форма **είναι** [ˈine] — «есть / является» — во всех трёх предложениях одна.

Можно поставить признак перед существительным:
**η καθαρή μπλούζα / το ζεστό τσάι / η όμορφη γυναίκα**
[i kaθaˈri ˈbluza / to zeˈsto ˈtsai / i ˈomorfi yiˈneka] —
чистая блузка / горячий чай / красивая женщина.
Или после «быть»:
**Η μπλούζα της είναι καθαρή.** [i ˈbluza tis ˈine kaθaˈri] — Её блузка чистая.
**Το τσάι σου είναι ζεστό.** [to ˈtsai su ˈine zeˈsto] — Твой чай горячий.
**Η γυναίκα του είναι όμορφη.** [i yiˈneka tu ˈine ˈomorfi] — Его жена красивая.

Выбор формы, ударение, артикли и типичные ошибки подробно:
[единое правило прилагательных](../reference/grammar/adjectives-e1-e2.md).
Ниже — **вся лексика таблиц и листа занятия**, а не только обведённые слова.

### Ε1: согласная в конце основы { #e1 }

Убери мужское окончание **-ος** [-os]. Если основа заканчивается согласным,
обычно женское окончание **-η** [-i], среднее **-ο** [-o].
Например, **καλός → καλή → καλό** [kaˈlos → kaˈli → kaˈlo].
Это модель изученных слов на такое мужское окончание, не универсальное
правило для любых прилагательных.

|---|---|---|---|
| καλ**ος** [kaˈlos] | καλή [kaˈli] | καλ**ο** [kaˈlo] | хороший |
| κακ**ος** [kaˈkos] | κακή [kaˈki] | κακ**ο** [kaˈko] | плохой |

В тренажёре используем написание с омегой.

### Ε2: гласная в конце основы { #e2 }

Женское окончание **-α** [-a], среднее **-ο** [-o].
**νέος → νέα → νέο** [ˈneos → ˈnea → ˈneo] —
молодой / молодая / молодое; новый / новая / новое.

| Мужской | Женский | Средний | Значение |
|---|---|---|---|
| καινούργι**ος** [keˈnuryos] | καινούργ**ια** [keˈnurya] | καινούργι**ο** [keˈnuryo] | новый |
| νέ**ος** [ˈneos] | νέ**α** [ˈnea] | νέ**ο** [ˈneo] | новый; молодой |
| παλι**ος** [paˈlyos] | παλιά [paˈlya] | παλι**ο** [paˈlyo] | старый; прежний |
| πλούσι**ος** [ˈplusios] | πλούσ**ια** [ˈplusia] | πλούσι**ο** [ˈplusio] | богатый |
| ωραί**ος** [oˈreos] | ωραί**α** [oˈrea] | ωραί**ο** [oˈreo] | красивый; приятный |
| κρύ**ος** [ˈkrios] | κρύ**α** [ˈkria] | κρύ**ο** [ˈkrio] | холодный |
| άδει**ος** [ˈaðyos] | άδε**ια** [ˈaðya] | άδει**ο** [ˈaðyo] | пустой |

**καινούργιος** [keˈnuryos] — новый, прежде всего о предмете.
**νέος** [ˈneos] — молодой о человеке, новый о предмете или роли.
**παλιός** [paˈlyos] — старый / прежний о вещи.
**ηλικιωμένος** [ilikioˈmenos] — пожилой о человеке.
Не называй пожилого человека автоматически словом «старый предмет».

**Η Στέλλα είναι μικρή. Η Άννα είναι μεγάλη.**
[i ˈstela ˈine miˈkri. i ˈana ˈine meˈɣali] —
Стелла маленькая / младше. Анна взрослая / старше: смысл зависит от контекста.
«Большой» не обязательно означает высокий рост: для роста есть отдельное слово.

### Исключения { #exceptions }

| Мужской | Женский | Средний | Значение |
|---|---|---|---|
| μοντέρν**ος** [moˈndernos] | μοντέρν**α** [moˈnderna] | μοντέρν**ο** [moˈnderno] | современный; модный |
| σκούρ**ος** [ˈskuros] | σκούρ**α** [ˈskura] | σκούρ**ο** [ˈskuro] | тёмный по цвету |
| γκρίζ**ος** [ˈgrizos] | γκρίζ**α** [ˈgriza] | γκρίζ**ο** [ˈgrizo] | серый |
| φρέσκ**ος** [ˈfreskos] | φρέσκ**ια** [ˈfreskya] | φρέσκ**ο** [ˈfresko] | свежий |
| γλυκ**ος** [ɣliˈkos] | γλυκιά [ɣliˈkya] | γλυκ**ο** [ɣliˈko] | сладкий |

Три первых слова имеют женское окончание **-α** [-a] даже после согласного.
Два последних лучше учить сразу тройкой, особенно женскую форму.
[Почему так выбираем форму](../reference/grammar/adjectives-e1-e2.md#exceptions).

### Противоположности: учи парами { #opposites }

| Пара | Значение |
|---|---|
| μεγάλος ↔ μικρός [meˈɣalos ↔ miˈkros] | большой ↔ маленький |
| καλός ↔ κακός [kaˈlos ↔ kaˈkos] | хороший ↔ плохой |
| όμορφος ↔ άσχημος [ˈomorfos ↔ ˈashimos] | красивый ↔ некрасивый |
| φτηνός ↔ ακριβός [ftiˈnos ↔ akriˈvos] | дешёвый ↔ дорогой |
| ψηλός ↔ κοντός [psiˈlos ↔ koˈndos] | высокий ↔ низкий |
| χοντρός ↔ λεπτός [hoˈndros ↔ leˈptos] | толстый ↔ тонкий |
| ζεστός ↔ κρύος [zeˈstos ↔ ˈkrios] | горячий ↔ холодный |
| καθαρός ↔ βρώμικος [kaθaˈros ↔ ˈvromikos] | чистый ↔ грязный |
| εύκολος ↔ δύσκολος [ˈefkolos ↔ ˈðiskolos] | лёгкий ↔ трудный |
| πλούσιος ↔ φτωχός [ˈplusios ↔ ftoˈhos] | богатый ↔ бедный |
| γεμάτος ↔ άδειος [yeˈmatos ↔ ˈaðyos] | полный ↔ пустой |
| ανοιχτός ↔ κλειστός [anihˈtos ↔ kliˈstos] | открытый ↔ закрытый |
| γρήγορος ↔ αργός [ˈɣriɣoros ↔ arˈɣos] | быстрый ↔ медленный |
| καινούργιος ↔ παλιός [keˈnuryos ↔ paˈlyos] | новый ↔ старый |

Не все слова образуют строгие противоположные пары: например, умный и
вежливый — разные признаки. Не придумывай антоним только ради пары.

### Все словосочетания из упражнения на согласование { #phrases }

[Открыть страницу с упражнением крупно](../assets/lessons/11/lesson-11-agreement.png).

В каждой строке можно проверить: артикль → род существительного → форма признака.

| Словосочетание | Перевод |
|---|---|
| ο νέος άντρας [o ˈneos ˈandras] | молодой мужчина |
| η όμορφη κοπέλα [i ˈomorfi koˈpela] | красивая девушка |
| το γρήγορο αυτοκίνητο [to ˈɣriɣoro aftoˈkinito] | быстрый автомобиль |
| ο μεγάλος κήπος [o meˈɣalos ˈkipos] | большой сад |
| το ζεστό φαγητό [to zeˈsto fayiˈto] | горячая еда |
| η καλή φίλη [i kaˈli ˈfili] | хорошая подруга |
| το παλιό ραδιόφωνο [to paˈlyo raðiˈofono] | старое радио |
| ο καλός μαθητής [o kaˈlos maθiˈtis] | хороший ученик |
| το άδειο ποτήρι [to ˈaðyo poˈtiri] | пустой стакан |
| ο ευγενικός κύριος [o evyeniˈkos ˈkirios] | вежливый господин |
| η καινούργια ζακέτα [i keˈnurya zaˈketa] | новая кофта / кардиган |
| το μικρό σπίτι [to miˈkro ˈspiti] | маленький дом |
| το βρώμικο πάτωμα [to ˈvromiko ˈpatoma] | грязный пол |
| η μοντέρνα μουσική [i moˈnderna musiˈki] | современная музыка |
| ο αυστηρός δάσκαλος [o afstiˈros ˈðaskalos] | строгий учитель |
| η εύκολη άσκηση [i ˈefkoli ˈaskisi] | лёгкое упражнение |

На первой иллюстрированной странице также:
**ένας ζεστός καφές / ένας κρύος καφές**
[ˈenas zeˈstos kaˈfes / ˈenas ˈkrios kaˈfes] — горячий / холодный кофе;
**ένας πλούσιος άντρας με ένα ακριβό αυτοκίνητο**
[ˈenas ˈplusios ˈandras me ˈena akriˈvo aftoˈkinito] —
богатый мужчина с дорогим автомобилем.
У одного человека и его машины разные роды: мужской у мужчины,
средний у автомобиля. Поэтому у двух признаков разные окончания.

### Описать целый предмет или семью { #sentences }

[Картинки и пары предложений крупно](../assets/lessons/11/lesson-11-opposites.png).

| Пример | Перевод |
|---|---|
| Αυτή είναι μια μεγάλη οικογένεια. [afˈti ˈine mya meˈɣali ikoˈyenia] | Это большая семья. |
| Αυτό είναι ένα φτηνό σπίτι. [afˈto ˈine ˈena ftiˈno ˈspiti] | Это дешёвый дом. |
| Αυτό είναι ένα γεμάτο δωμάτιο. [afˈto ˈine ˈena yeˈmato ðoˈmatio] | Это заполненная комната. |
| Αυτή είναι μια ανοιχτή πόρτα. [afˈti ˈine mya anihˈti ˈporta] | Это открытая дверь. |
| Αυτός είναι ένας δύσκολος δρόμος. [afˈtos ˈine ˈenas ˈðiskolos ˈðromos] | Это трудная дорога. |
| Αυτό είναι ένα καινούργιο αυτοκίνητο. [afˈto ˈine ˈena keˈnuryo aftoˈkinito] | Это новая машина. |

Чтобы получить вторую картинку каждой пары, замени признак антонимом
**в том же роде**. Не меняй «это» на средний род автоматически:
дверь женского рода, дорога мужского.
«Трудная дорога» описывает сложность пути, не материал покрытия.

### Слова в пометках преподавателя { #notes }

| Фраза | Смысл |
|---|---|
| Καθαρίζω το σπίτι μου. [kaθaˈrizo to ˈspiti mu] | Я убираю свой дом. |
| ευτυχώς / δυστυχώς [eftiˈhos / ðistiˈhos] | к счастью / к сожалению |
| η εβδομάδα [i evðoˈmaða] | неделя |
| Κάνει ζέστη. [ˈkani ˈzesti] | Жарко. |
| Κάνει κρύο. [ˈkani ˈkrio] | Холодно. |
| ανοίγω / κλείνω [aˈniɣo / ˈklino] | я открываю / закрываю |

Температура воздуха — готовые выражения, а не согласование прилагательного
с человеком. «Холодный чай» и «на улице холодно» строятся по-разному.

### Повторение: кто / какой, этот / тот { #pronouns }

**Ποιος / ποια / ποιο;** [pyos / pya / pyo?] — Кто? / Какой, какая, какое?
Род выбирается по человеку или предмету:
**Ποιο βιβλίο κάνετε;** [pyo viˈvlio ˈkanete?] —
По какому учебнику вы занимаетесь? Буквально «какую книгу вы делаете?».

**αυτός / αυτή / αυτό** [afˈtos / afˈti / afˈto] — этот / эта / это;
**εκείνος / εκείνη / εκείνο** [eˈkinos / eˈkini / eˈkino] — тот / та / то.
В домашнем задании «та госпожа там» даёт подсказку к дальнему указанию.

**Αυτή είναι η δασκάλα μου και αυτό είναι το παιδί της.**
[afˈti ˈine i ðaˈskala mu ke afˈto ˈine to peˈði tis] —
Это моя учительница, а это её ребёнок.
**Ξέρεις ποια είναι;** [ˈkseris pya ˈine?] — Знаешь, кто она?
Не подменяй вопросительное местоимение указательным.
[Местоимения и принадлежность](../reference/grammar/personal-pronouns.md).

### Повторение семейного положения { #family }

На странице аудирования повторяются:
**παντρεμένος / παντρεμένη** [pandreˈmenos / pandreˈmeni] — женат / замужем;
**ελεύθερος / ελεύθερη** [eˈlefθeros / eˈlefθeri] — свободен / свободна;
**αρραβωνιασμένος / αρραβωνιασμένη** [aravoniazˈmenos / aravoniazˈmeni] —
помолвлен / помолвлена;
**χωρισμένος / χωρισμένη** [horisˈmenos / horisˈmeni] — разведён / разведена.

**Ο γιος της είναι μικρός.** [o yos tis ˈine miˈkros] — Её сын маленький.
**Έχει μια αδερφή φοιτήτρια.** [ˈehi mya aðerˈfi fiˈtitria] —
У него / неё есть сестра-студентка.
По ложному утверждению нельзя самостоятельно восстановить правильный возраст
или профессию: для этого нужен сам диалог.
[Семья и отношения](lesson-08-current.md#family).

### Песня: прилагательное в живой фразе { #song }

[Γιώργος Νταλάρας — Σ’ Αγαπώ](https://www.youtube.com/watch?v=EY5VyixPSP4)
[ˈyorɣos daˈlaras — saɣaˈpo] — Йоргос Даларас, «Я тебя люблю».

**Σ’ αγαπώ γιατί είσαι ωραία.** [saɣaˈpo yaˈti ˈise oˈrea] —
Я люблю тебя, потому что ты прекрасна.
Форма признака здесь женская: обращение к женщине; глагол «ты есть» не меняется по роду.
Это дополнительный пример, не требование выучить весь текст песни.

3. Опиши комнату и предмет в ней двумя полными предложениями.
