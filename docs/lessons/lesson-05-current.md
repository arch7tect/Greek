## Что освоить

Определять род существительного и выбирать артикль; называть предметы в классе;
понимать вопросы при записи на занятия. Повторение — знакомство, формы глаголов
группы А и числа 0–100. **Род относится к существительному, а не к его владельцу.**

## Разбор

### 1. Как определить род { #gender }

Сначала посмотри на артикль. Окончание помогает узнать знакомую модель, но
не заменяет запоминание слова с артиклем.

| Род | Частые окончания | Примеры |
|---|---|---|
| Мужской | **-ος, -ης, -ας** `[os, is, as]` | `ο δάσκαλος` `[o ˈðaskalos]` — учитель; `ο φοιτητής` `[o fitiˈtis]` — студент; `ο πίνακας` `[o ˈpinakas]` — доска |
| Женский | **-α, -η** `[a, i]` | `η φοιτήτρια` `[i fiˈtitria]` — студентка; `η τάξη` `[i ˈtaksi]` — класс |
| Средний | **-ο, -ι, -μα** `[o, i, ma]` | `το βιβλίο` `[to viˈvlio]` — книга; `το μολύβι` `[to moˈlivi]` — карандаш; `το μάθημα` `[to ˈmaθima]` — урок |

Важные ловушки: `το πρόγραμμα` `[to ˈproɣrama]` — программа — среднего рода,
хотя заканчивается на «а». `Το κορίτσι` `[to koˈritsi]` — девочка — тоже
грамматически среднего рода. Русский род и пол человека не дают надёжного ответа.

[Полное правило: род и артикли](../reference/grammar/nominative-articles.md#gender).

### 2. «Этот предмет» или «какой-то один» { #articles }

| Род | Уже понятно, какой | Один / какой-то |
|---|---|---|
| Мужской | `ο` `[o]` | `ένας` `[ˈenas]` |
| Женский | `η` `[i]` | `μία / μια` `[ˈmia / mya]` |
| Средний | `το` `[to]` | `ένα` `[ˈena]` |

`Είναι μία καρέκλα.` `[ˈine ˈmia kaˈrekla]` — это стул, один из стульев.
`Η καρέκλα είναι εδώ.` `[i kaˈrekla ˈine eˈðo]` — стул здесь: понятно, какой.
Артикль обычно не переводится отдельным русским словом.

Здесь изучается **именительный падеж**. Не подставляй эти формы автоматически
после глагола «иметь» или предлога: `ένας` `[ˈenas]` может стать
`έναν` `[ˈenan]`. [Почему меняется форма](../reference/grammar/prepositions-accusative.md).

### 3. Предметы в классе { #classroom }

Учи не голое название, а маленькую пару «артикль + слово».

| Мужской род | Женский род | Средний род |
|---|---|---|
| `ο πίνακας` `[o ˈpinakas]` — доска | `η καρέκλα` `[i kaˈrekla]` — стул | `το τραπέζι` `[to traˈpezi]` — стол |
| `ο χάρτης` `[o ˈhartis]` — карта | `η βιβλιοθήκη` `[i vivlioˈθiki]` — библиотека | `το θρανίο` `[to θraˈnio]` — парта |
| `ο υπολογιστής` `[o ipoloyiˈstis]` — компьютер | `η τάξη` `[i ˈtaksi]` — класс | `το παράθυρο` `[to paˈraθiro]` — окно |

В конспекте также подписаны губка, стена, пол и полка. Остальные слова упражнений
собраны в [словаре урока](../vocabulary/lesson-05.md#current-pass).
Проверяй себя в обе стороны: предмет → название с артиклем; название → предмет.

### 4. Запись на занятия { #registration }

Диалог на **печатной с. 48 учебника** — разговор в секретариате, на вежливое «вы».
Его нужно выучить. Запоминай порядок: имя → учёба → страна → специальность →
адрес → телефон → почта → фотография → аудитория.

| Реплика | Что означает |
|---|---|
| `Πώς λέγεστε, παρακαλώ;` `[pos ˈleɣeste parakaˈlo]` | Как вас зовут, пожалуйста? |
| `Είστε φοιτήτρια;` `[ˈiste fiˈtitria]` | Вы студентка? |
| `Μάλιστα.` `[ˈmalista]` | Да; вежливое подтверждение |
| `Τι σπουδάζετε;` `[ti spuˈðazete]` | Что вы изучаете в вузе? |
| `Τώρα πού μένετε;` `[ˈtora pu ˈmenete]` | Где вы сейчас живёте? |
| `Μία διεύθυνση;` `[ˈmia ðiˈefθinsi]` | Адрес? |
| `Ένα τηλέφωνο, παρακαλώ;` `[ˈena tiˈlefono parakaˈlo]` | Номер телефона, пожалуйста? |
| `Έχετε μία φωτογραφία;` `[ˈehete ˈmia fotoɣraˈfia]` | У вас есть фотография? |
| `Ορίστε η κάρτα σας.` `[oˈriste i ˈkarta sas]` | Вот ваша карточка |
| `Καλή αρχή!` `[kaˈli arˈhi]` | Хорошего начала! |

Не путать вопросы о стране и национальности: `Είστε Ισπανίδα;`
`[ˈiste ispaˈniða]` — «Вы испанка?», а `Από πού είστε;`
`[aˈpo pu ˈiste]` — «Откуда вы?».

Для почты: `το μέιλ` `[to meil]` — электронная почта;
`παπάκι` `[paˈpaki]` — знак @; `τελεία` `[teˈlia]` — точка.
`Το κινητό μου` `[to kiniˈto mu]` — мой мобильный телефон.
Личные данные в учебном диалоге принадлежат персонажу: для тренировки не нужно
сообщать свои настоящие контакты.

### 5. Что повторить { #revision }

- Числа: [0–10](../reference/numbers-0-10.md) и
  [11–100, чтение телефонов](../reference/numbers-11-100.md).
  Составное число — десяток плюс единицы **без «и»**:
  `είκοσι τρία` `[ˈikosi ˈtria]` — 23.
- Глаголы: «ты» — **-εις** `[is]`, «он/она» — **-ει** `[i]`,
  «мы» — **-ουμε** `[ume]`, «вы» — **-ετε** `[ete]`, «они» — **-ουν** `[un]`.
  `Πού μένετε; — Μένω εδώ.` `[pu ˈmenete — ˈmeno eˈðo]` — «Где вы живёте? — Я живу здесь».
  **При ответе лицо меняется**: вежливое «вы» в вопросе не требует «мы» в ответе.
- Рассказ о другом человеке: `Τον λένε Μάριο.` `[ton ˈlene ˈmario]` — его зовут Марио;
  `Τη λένε Μαρία.` `[ti ˈlene maˈria]` — её зовут Мария.
  Затем страна, жильё и самочувствие.

## Практика перед домашкой

1. Найди в комнате пять предметов и назови их с артиклем.
2. Замени определённый артикль неопределённым, сохранив род.
3. Прочитай диалог с. 48, закрой ответы и отвечай за студентку.
4. Продиктуй пять случайных чисел до 100. Затем повтори
   [глагольные окончания](../training/present-tense-a.md).

Для дополнительного повторения приветствий —
[песня «Καλημέρα, τι κάνεις;»](https://www.youtube.com/watch?v=PBAg10F7CPw)
`[kaliˈmera ti ˈkanis]` — «Доброе утро, как дела?».
