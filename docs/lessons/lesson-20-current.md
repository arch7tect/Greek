## Что освоить

- Выбирать «какой?», «этот», «тот» по роду и роли слова в предложении.
- Купить билет, спросить про тариф, отправление, прибытие и длительность.
- Понять, почему после предлога меняется вся группа слов, а определённый артикль остаётся.
- Назвать своё настроение и коротко ответить на вопрос о поездке.

## Разбор

### Сначала роль, затем род { #pronouns }

Спроси себя, кто выполняет действие или о ком говорится с «есть». Это именительный. Если слово отвечает на «кого? что?» после глагола либо стоит после изученных предлогов, нужен винительный. Подробнее о выборе формы — в [правиле винительного](../reference/grammar/accusative-singular.md).

| Род | Вопрос: именительный → винительный | «Этот»: именительный → винительный | «Тот»: именительный → винительный |
|---|---|---|---|
| Мужской | ποιος → ποιον [pyos → pyon] | αυτός → αυτόν [afˈtos → afˈton] | εκείνος → εκείνον [eˈkinos → eˈkinon] |
| Женский | ποια → ποια [pya → pya] | αυτή → αυτή(ν) [afˈti → afˈti(n)] | εκείνη → εκείνη [eˈkini → eˈkini] |
| Средний | ποιο → ποιο [pyo → pyo] | αυτό → αυτό [afˈto → afˈto] | εκείνο → εκείνο [eˈkino → eˈkino] |

**Αυτός ο γιατρός είναι νέος.** [afˈtos o yaˈtros ˈine ˈneos] — Этот врач молодой. Врач здесь подлежащее.
**Ξέρεις αυτόν τον γιατρό;** [ˈkseris afˈton ton yaˈtro] — Ты знаешь этого врача? «Кого знаешь?» Меняются **все три слова**.

У «этот/тот» с существительным артикль сохраняется: **εκείνον τον δρόμο** [eˈkinon ton ˈðromo] — ту дорогу. У вопросительного «какой» между ним и существительным артикля нет: **ποιον δρόμο** [pyon ˈðromo] — какую дорогу. Русское «дорога» женского рода, греческое слово мужского.

**Πάμε για καφέ σε αυτή την καφετέρια;** [ˈpame ya kaˈfe se afˈti tin kafeˈteria] — Пойдём на кофе в это кафе? Между **σε** [se] и артиклем стоит указательное слово, поэтому предлог пишется отдельно. Без указательного слова **στην καφετέρια** [stin kafeˈteria] — в кафе.

**Αυτή την Παρασκευή** [afˈti tin paraskeˈvi] — в эту пятницу. Группа в винительном обозначает время и употребляется без **σε** [se].

В таблице конспекта для нескольких людей встречаются **Ποιους βλέπεις;** [pyus ˈvlepis] — Кого ты видишь? (мужчины или смешанная группа), **Ποιες βλέπεις;** [pyes ˈvlepis] — Кого ты видишь? (женщины), **Ποια βλέπεις;** [pya ˈvlepis] — Которых ты видишь? (средний род, например дети). На рисунке женской группы стоит **Ποιες είναι αυτές;** [pyes ˈine afˈtes] — Кто эти женщины? Здесь вопрос уже в именительном. Полная таблица — в [справочнике](../reference/grammar/question-and-demonstrative-pronouns.md#accusative).

### Какой я сегодня { #mood }

**Ποια γάτα είμαι σήμερα; / Ποιος γάτος είμαι σήμερα;** [pya ˈɣata ˈime ˈsimera / pyos ˈɣatos ˈime ˈsimera] — Какая я сегодня кошка? / Какой я сегодня кот? С «я» прилагательное согласуется с родом говорящего: **Είμαι κουρασμένος / κουρασμένη.** [ˈime kurazˈmenos / kurazˈmeni] — Я устал / устала.

| Форма мужского рода | Произношение | Значение |
|---|---|---|
| νυσταγμένος | [nistazˈmenos] | сонный |
| ενοχλημένος | [enohliˈmenos] | раздражённый, обеспокоенный |
| κουρασμένος | [kurazˈmenos] | уставший |
| έκπληκτος | [ˈekpliktos] | удивлённый |
| στεναχωρημένος | [stenahoriˈmenos] | расстроенный |
| θυμωμένος | [θimoˈmenos] | сердитый |
| αγχωμένος | [aŋhoˈmenos] | напряжённый, встревоженный |
| σοβαρός | [sovaˈros] | серьёзный |
| ενθουσιασμένος | [enθusiazˈmenos] | воодушевлённый |

**Θέλω να κοιμηθώ.** [ˈθelo na kimiˈθo] — Хочу спать. **Έχω μεγάλο στρες / άγχος.** [ˈeho meˈɣalo stres / ˈaŋhos] — Я сильно переживаю, у меня сильный стресс. **η έκπληξη** [i ˈekpliksi] — удивление, сюрприз. Сонный хочет спать, а уставший может просто хотеть отдохнуть.

### Выбираем маршрут и покупаем билет { #tickets }

Три образца из рамок перед диалогом:

| Вопрос | Короткий ответ |
|---|---|
| **Ποιον χάρτη θέλεις; Αυτόν ή εκείνον;** [pyon ˈharti ˈθelis afˈton i eˈkinon] — Какую карту хочешь? Эту или ту? | **Θέλω αυτόν τον μεγάλο χάρτη.** [ˈθelo afˈton ton meˈɣalo ˈharti] — Хочу эту большую карту. |
| **Ποια διαδρομή διαλέγετε; Αυτήν ή εκείνη;** [pya ðiaðroˈmi ðiaˈleyete afˈtin i eˈkini] — Какой маршрут выбираете? Этот или тот? | **Αυτήν τη διαδρομή. Είναι σύντομη.** [afˈtin ti ðiaðroˈmi ˈine ˈsindomi] — Этот маршрут. Он короткий. |
| **Ποιο πλοίο προτιμάς; Αυτό ή εκείνο;** [pyo ˈplio protiˈmas afˈto i eˈkino] — Какое судно предпочитаешь? Это или то? | **Προτιμώ εκείνο το πλοίο με το φτηνό εισιτήριο.** [protiˈmo eˈkino to ˈplio me to ftiˈno isiˈtirio] — Предпочитаю то судно с дешёвым билетом. |

**απλό εισιτήριο** [aˈplo isiˈtirio] — билет в одну сторону; **εισιτήριο με επιστροφή** [isiˈtirio me epistroˈfi] — туда и обратно. Это направление поездки. **κανονικό / φοιτητικό εισιτήριο** [kanoniˈko / fitiˈtiko isiˈtirio] — обычный / студенческий тариф. **οικονομική θέση** [ikonomiˈki ˈθesi] — место экономкласса, категория места.

**Αγοράζω / κλείνω ένα εισιτήριο.** [aɣoˈrazo / ˈklino ˈena isiˈtirio] — Покупаю / бронирую билет. **κλείνω ραντεβού στον γιατρό** [ˈklino randeˈvu ston yaˈtro] — записываюсь к врачу. **Ετοιμάζω / φτιάχνω τη βαλίτσα μου.** [etiˈmazo / ˈftiahno ti vaˈlitsa mu] — Собираю чемодан.

В №11 спрашивают **Πώς πάμε στη χώρα σου από την Ελλάδα;** [pos ˈpame sti ˈhora su aˈpo tin eˈlaða] — Как добраться из Греции в твою страну? Отвечаем через **με** [me]: **με το αυτοκίνητο / αμάξι** [me to aftoˈkinito / aˈmaksi] — на машине; **με το αεροπλάνο / πλοίο / καράβι / τρένο / λεωφορείο** [me to aeroˈplano / ˈplio / kaˈravi / ˈtreno / leoforˈio] — самолётом / судном / кораблём / поездом / автобусом. **στο εσωτερικό / στο εξωτερικό** [sto esoteriˈko / sto eksoteriˈko] — внутри страны / за границу. Места отправления: **το αεροδρόμιο / το λιμάνι / ο σταθμός** [to aeroˈðromio / to liˈmani / o staθˈmos] — аэропорт / порт / станция. **ο αερολιμένας** [o aeroliˈmenas] — аэропорт, официальное название.

**Θα ήθελα** [θa ˈiθela] — вежливое «я хотел бы». **Έχει** [ˈehi] может значить «есть» в расписании и «стоит» в разговоре о цене. **Πόσο κοστίζει;** [ˈposo koˈstizi] — Сколько стоит? **Πόση ώρα διαρκεί;** [ˈposi ˈora ðiarˈki] — Сколько времени длится?

Проверка №10 по пометкам: 1 — неверно, он едет утром; 2 — верно, два судна; 3 — в конспекте отмечено верно, хотя в самом диалоге он прямо не говорит, что студент; 4 — неверно, 26 евро стоит студенческий билет на более медленное судно; 5 — неверно, он выбрал быстрое.

### Время поездки и чтение билета { #schedule }

| Выражение | Произношение | Как понимать |
|---|---|---|
| στις έξι και μισή το πρωί | [stis ˈeksi ke miˈsi to proˈi] | в половине седьмого утра |
| στη μία το μεσημέρι | [sti ˈmia to mesiˈmeri] | в час дня |
| από τις επτά ως / έως / μέχρι τις τρεις και δέκα | [aˈpo tis eˈpta os / ˈeos / ˈmehri tis tris ke ˈðeka] | с семи до трёх десяти |
| κατά τις οκτώ | [kaˈta tis oˈkto] | около восьми |
| περίπου / γύρω στη μία | [peˈripu / ˈyiro sti ˈmia] | примерно в час |
| περίπου / γύρω στις τρεις | [peˈripu / ˈyiro stis tris] | примерно в три |
| στις δέκα παρά είκοσι | [stis ˈðeka paˈra ˈikosi] | без двадцати десять, 9:40 |

**Τι ώρα φεύγει / ξεκινάει / αναχωρεί;** [ti ˈora ˈfevyi / ksiˈkinai / anahoˈri] — Во сколько отправляется? **Τι ώρα φτάνει;** [ti ˈora ˈftani] — Во сколько прибывает? **Κάθε πότε;** [ˈkaθe ˈpote] — Как часто? **Από τι ώρα είσαι στο αεροδρόμιο;** [aˈpo ti ˈora ˈise sto aeroˈðromio] — С которого часа ты в аэропорту? Для вопроса о текущем времени используется **Τι ώρα είναι τώρα;** [ti ˈora ˈine ˈtora] — Который сейчас час? [Справочник по времени](../reference/grammar/time-and-calendar.md).

В №13 у билета на судно читаются название **BLUE STAR ITHAKI**, Пирей → Сирос, отправление **07:35**, цена **21,50 €**. **Πώς λένε το καράβι;** [pos ˈlene to kaˈravi] — Как называется корабль? **Από πού φεύγει και τι ώρα;** [aˈpo pu ˈfevyi ke ti ˈora] — Откуда и во сколько отправляется?

У автобусного билета в пометке подтверждено **Αναχωρεί στις δέκα παρά είκοσι.** [anahoˈri stis ˈðeka paˈra ˈikosi] — Отправляется в 9:40.
