## Распорядок: фото с. 88 и диалог с. 86, упражнение 1.2 { #routine }

| Слово | Транскрипция | Значение | Форма / примечание | Основное |
|---|---|---|---|---|
| `η φορά` | `[i foˈra]` | раз | `οι φορές` `[i foˈres]`; не глагол «носить» | да |
| `η εκδρομή` | `[i ekðroˈmi]` | экскурсия; поездка на отдых | `οι εκδρομές` `[i ekðroˈmes]` | да |
| `παραγγέλνω` | `[paraŋˈgelno]` | заказываю | `παραγγέλνω φαγητό απ’ έξω` `[paraŋˈgelno faɣiˈto ap ˈekso]` — заказываю готовую еду | да |
| `γυρίζω` | `[yiˈrizo]` | возвращаюсь | `γυρίζω στο σπίτι` `[yiˈrizo sto ˈspiti]` — возвращаюсь домой | да |
| `επιστρέφω` | `[epiˈstrefo]` | возвращаюсь | близко к предыдущему глаголу; текст №10 | да |
| `παίρνω` | `[ˈperno]` | беру | не путать с `περνάω` `[perˈnao]` — провожу время | да |
| `ο υπνάκος` | `[o ipˈnakos]` | короткий сон; дрёма | `οι υπνάκοι` `[i ipˈnaki]` | да |
| `κάνω ντους` | `[ˈkano dus]` | принимаю душ | устойчивое сочетание с «делаю» | да |
| `κάνω μπάνιο` | `[ˈkano ˈbanyo]` | моюсь; принимаю ванну / душ | в морском контексте — купаюсь; не обязательно ванна | да |
| `παίρνω έναν υπνάκο` | `[ˈperno ˈenan ipˈnako]` | немного сплю; дремлю | буквально «беру короткий сон» | да |
| `πάω για ύπνο` | `[ˈpao ya ˈipno]` | иду спать | цель движения; не просто состояние «сплю» | да |
| `όταν` | `[ˈotan]` | когда | соединяет части фразы; не вопросительное «когда?» | да |
| `περίπου` | `[peˈripu]` | примерно | о времени и количестве | да |
| `γύρω στις` | `[ˈyiro stis]` | около; примерно в | перед часом; `γύρω στις τρεις` `[ˈyiro stis tris]` | да |
| `ο κόσμος` | `[o ˈkozmos]` | люди; народ; мир | `οι κόσμοι` `[i ˈkozmi]` — миры; в значении «люди» обычно ед. ч. | да |
| `τα νέα` | `[ta ˈnea]` | новости | множественное; в диалоге — слушать новости | да |

## Частотность: фото с. 88, файл с. 131 и тетрадь с. 29 №7 { #frequency }

| Слово | Транскрипция | Значение | Форма / примечание | Основное |
|---|---|---|---|---|
| `πάρα πολλές φορές` | `[ˈpara poˈles foˈres]` | очень много раз | подсказка №7; не «всегда» | да |
| `πολύ λίγες φορές` | `[poˈli ˈliɣes foˈres]` | очень мало раз | подсказка №7 | да |
| `αρκετές φορές` | `[arkeˈtes foˈres]` | довольно много раз | подсказка №7 | да |
| `όλες τις φορές` | `[ˈoles tis foˈres]` | каждый раз; все разы | подсказка №7 | да |
| `σχεδόν πάντα` | `[sheˈðon ˈpanda]` | почти всегда | не то же самое, что «всегда» | да |
| `σχεδόν ποτέ` | `[sheˈðon poˈte]` | почти никогда | с отрицанием; не «иногда» | да |
