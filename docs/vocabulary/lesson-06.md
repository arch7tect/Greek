# Урок 06 — новые слова

## Текущий набор { #current-pass }

[Разбор урока](../lessons/lesson-06-current.md) ·
[Карточки](../memory/lesson-06-current.md) ·
[Домашка](../homework/lesson-06-current.md).

Основное для повторения: шесть форм «говорить», различие страны, национальности
и языка, несколько национальностей из диалога и домашки, оценка владения языком.
Расширенную таблицу стран смотри [в уроке](../lessons/lesson-06-current.md#nationalities),
а не заучивай как один большой список. Имена, улицы и районы не входят в активный набор.

Слова об учёбе, глаголы «помогать», «любить», «спрашивать», «петь» и оценки
владения языком собраны [ниже](#lesson-06-verified-coverage).
Уже знакомые слова не считаются повторно: например, «понимать» и «очень хорошо»
есть [в наборе урока 04](lesson-04.md#lesson-04-verified-coverage).

В активный словарь вошло 64 слов и устойчивых формул. Повторяющиеся слова не считаются заново.
Основные помечены «да»; остальные нужны для понимания упражнений.
