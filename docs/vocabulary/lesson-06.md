# Урок 06 — новые слова

## Текущий набор { #current-pass }

[Разбор урока](../lessons/lesson-06-current.md) ·
[Карточки](../memory/lesson-06-current.md) ·
[Домашка](../homework/lesson-06-current.md).

Основное для повторения: шесть форм «говорить», различие страны, национальности
и языка, несколько национальностей из диалога и домашки, оценка владения языком.
Расширенную таблицу стран смотри [в уроке](../lessons/lesson-06-current.md#nationalities),
а не заучивай как один большой список. Имена, улицы и районы не входят в активный набор.

Уже сохранённые слова не считаются повторно:
[понимать, помогать, учёба](lesson-07.md#lesson-07-studies),
[немного, совсем не, очень хорошо](lesson-07.md#lesson-07-application),
[любить, спрашивать, петь](lesson-08.md#lesson-08-verbs-b1).
Номера словарных страниц обозначают место первого сохранения слова.

В активный словарь вошло 87 единиц: 32 добавлены по текущим материалам,
55 сохранены с исходными привязками. «Да» — основные для повторения;
«—» — для понимания полного материала. Существительные учим с артиклем;
множественное число пока достаточно узнавать.
