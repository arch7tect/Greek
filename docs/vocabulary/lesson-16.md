# Урок 16 — местоимения, предметы и распорядок

В активный словарь вошли 30 новых единиц. Это формы множественного числа и слова из полного упражнения 33,
подписей преподавателя и образца о стране. Имена людей и названия улиц
не входят в число активных слов.

[Урок](../lessons/lesson-16-current.md) · [Домашка](../homework/lesson-16-current.md) ·
[Карточки](../memory/lesson-16-current.md) · [Тренажёр](../training/vocabulary.md?lesson=16).
Знакомые формы «кто / этот / тот» доступны через «С повторением».

## Множественное число: конспект, PDF 2–3 { #plural }

| Слово | Транскрипция | Значение | Форма / примечание | Основное |
|---|---|---|---|---|
| `ποιοι / ποιες / ποια` | `[pyi / pyes / pya]` | кто? какие? — множественное число | мужской / женский / средний род; не личное «они» | да |
| `αυτοί / αυτές / αυτά` | `[afˈti / afˈtes / afˈta]` | эти; они | мужской / женский / средний род; после «эти» перед существительным нужен артикль | да |
| `εκείνοι / εκείνες / εκείνα` | `[eˈkini / eˈkines / eˈkina]` | те | мужской / женский / средний род; дальнее указание | да |
