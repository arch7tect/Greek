# Урок 03 — новые слова

**Статус:** накопительный словарь первого прохода; пересечения с текущим
уроком отмечены ниже. Не весь список автоматически задан заново.

**Связанный урок:** [Урок 03 — местоимения и знакомство в классе](../lessons/lesson-03-pronouns-and-classroom-dialogue.md)

В активный словарь вошла 21 новая единица в первом проходе: 12 из назначенных
тогда упражнений и 9 из диалога. Этот объём сохранён, новых строк при разборе
текущего урока не добавлено.

## Текущий проход { #current-pass }

[Текущий урок 03](../lessons/lesson-03-introductions-and-eimai.md) и
[его домашка](../homework/lesson-03-current.md) повторяют местоимения,
знакомство и часть лексики этой страницы. Но `η Σμύρνη` `[i ˈzmirni]`
в нынешнем упражнении 3 рабочей тетради не встречается: не учить её как
обязательную новую единицу текущего задания.

[Наши карточки для повторения](../memory/lesson-03-current.md) содержат
местоимения, формы глагола, вопросы об имени и происхождении.
Это основной набор для подготовки к домашке.

Обозначения: [как читать транскрипцию](../reference/transcription.md).

**Основное:** «да» — первый проход тренажёра; «—» — только полный набор.

## Рабочая тетрадь, страница 10, упражнение 2 { #lesson-03-ex-2 }

| Слово | Транскрипция | Значение | Форма / примечание | Основное |
|---|---|---|---|---|
| `εγώ` | `[eˈɣo]` | я | личное местоимение | да |
| `εσύ` | `[eˈsi]` | ты | личное местоимение | да |
| `εμείς` | `[eˈmis]` | мы | личное местоимение | да |
| `εσείς` | `[eˈsis]` | вы | вежливо одному человеку или нескольким людям | да |

Формы `αυτός / αυτή / αυτό` `[afˈtos / afˈti / afˈto]` и глагол
`είμαι` `[ˈime]` уже внесены на уроке 02. Упражнение добавляет множественные
формы `αυτοί / αυτές / αυτά` `[afˈti / afˈtes / afˈta]`, но они относятся к той
же словарной статье и не считаются новыми единицами. Имена людей не учитываются.

## Рабочая тетрадь, страница 11, упражнение 3 { #lesson-03-ex-3 }

| Слово | Транскрипция | Значение | Форма / примечание | Основное |
|---|---|---|---|---|
| `η Ιταλία` | `[i itaˈlia]` | Италия | название страны | да |
| `η Βραζιλία` | `[i vraziˈlia]` | Бразилия | название страны | — |
| `η Σμύρνη` | `[i ˈzmirni]` | Смирна; Измир | название города | — |
| `η κυρία` | `[i kiˈria]` | госпожа; вежливое обращение к женщине | `οι κυρίες` `[i kiˈries]` | да |
| `η δασκάλα` | `[i ðaˈskala]` | учительница | `οι δασκάλες` `[i ðaˈskales]` | да |
| `η Τουρκία` | `[i turˈkia]` | Турция | название страны | да |
| `η Βουλγαρία` | `[i vulɣaˈria]` | Болгария | название страны | — |
| `μου` | `[mu]` | мой; моя; моё | ставится после существительного | да |

`Το βιβλίο` `[to viˈvlio]`, `το μολύβι` `[to moˈlivi]` и `είμαι` `[ˈime]`
повторяются из предыдущих уроков. Имена людей из предложений не считаются
активной лексикой.

## Диалог для прослушивания { #lesson-03-dialogue }

| Слово или формула | Транскрипция | Значение | Форма / примечание | Основное |
|---|---|---|---|---|
| `εδώ` | `[eˈðo]` | здесь; сюда | наречие | да |
| `εμένα` | `[eˈmena]` | меня; а меня | ударная форма первого лица | да |
| `εσάς` | `[eˈsas]` | вас; а вас | ударная вежливая или множественная форма | да |
| `η Γερμανία` | `[i yermaˈnia]` | Германия | название страны | да |
| `καλώς ήρθες / καλώς ήρθατε` | `[kaˈlos ˈirθes / kaˈlos ˈirθate]` | добро пожаловать | одному на «ты» / одному на «вы» или группе | да |
| `τέλεια` | `[ˈtelia]` | отлично; замечательно | разговорная реакция | да |
| `ο κύριος` | `[o ˈkirios]` | господин; вежливое обращение к мужчине | `οι κύριοι` `[i ˈkirii]`; обращение `κύριε` `[ˈkirie]` | да |
| `χαίρετε` | `[ˈherete]` | здравствуйте | нейтрально-вежливое приветствие | да |
| `σας` | `[sas]` | вас; ваш | значение определяется конструкцией | да |

Уже известные `η τάξη` `[i ˈtaksi]`, `η Ισπανία` `[i ispaˈnia]`,
`ο καθηγητής` `[o kaθiyiˈtis]`, `το παιδί` `[to peˈði]` и речевые формулы
предыдущих уроков повторно не считаются. Имена участников диалога вынесены за
пределы активного словаря.
