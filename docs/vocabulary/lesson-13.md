## Формулы времени для тренажёра { #time-phrases }

Из разобранных примеров времени (конспект PDF 2 и файл о времени).
Тренируем целиком, чтобы вспоминать не только отдельное слово, но и нужную форму.
[Отдельный набор «Время»](../training/vocabulary.md?topic=time).

| Слово | Транскрипция | Значение | Форма / примечание | Основное |
|---|---|---|---|---|
| `Τι ώρα είναι;` | `[ti ˈora ˈine]` | Который час? | вопрос о времени сейчас | да |
| `Τι ώρα;` | `[ti ˈora]` | Во сколько? | вопрос о времени события | да |
| `δύο ακριβώς` | `[ˈðio akriˈvos]` | ровно два часа (2:00) | время сейчас, без предлога | да |
| `δύο και τέταρτο` | `[ˈðio ke ˈtetarto]` | четверть третьего (2:15) | два плюс четверть часа | да |
| `δύο και μισή` | `[ˈðio ke miˈsi]` | половина третьего (2:30) | два плюс половина часа | да |
| `τρεις παρά τέταρτο` | `[tris paˈra ˈtetarto]` | без четверти три (2:45) | вычитаем из следующего часа | да |
| `στη μία` | `[sti ˈmia]` | в час (1:00) | время события, единственное число | да |
| `στις τρεις` | `[stis tris]` | в три часа (3:00) | время события, множественное число | да |
| `σε μισή ώρα` | `[se miˈsi ˈora]` | через полчаса | отсчёт от сейчас, не «в полчаса» | да |
